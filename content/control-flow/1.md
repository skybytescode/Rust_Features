# Control flow — Fundamente

Control flow înseamnă să decizi ce cod rulează și de câte ori. Rust are `if` pentru decizii și trei feluri de bucle: `loop`, `while` și `for`.

## `if` și `else`

Condiția trebuie să fie de tip `bool`. Nu pui paranteze în jurul ei, dar acoladele sunt obligatorii:

```rust
fn main() {
    let temperatura = 28;

    if temperatura > 30 {
        println!("E foarte cald");
    } else if temperatura > 20 {
        println!("E plăcut");
    } else {
        println!("E răcoare");
    }
}
```

Spre deosebire de C sau JavaScript, Rust nu convertește automat numere în `bool`:

```rust,compile_fail
fn main() {
    let n = 3;
    if n { // eroare E0308: se așteaptă `bool`, s-a găsit un întreg
        println!("nenul");
    }
}
```

Scrie condiția explicit: `if n != 0`.

## `if` produce o valoare

În Rust, `if` este o expresie, deci îl poți folosi direct într-un `let`. Ambele ramuri trebuie să aibă același tip:

```rust
fn main() {
    let varsta = 17;
    let categorie = if varsta >= 18 { "adult" } else { "minor" };
    println!("{categorie}");
}
```

## `loop`: repetă la nesfârșit

`loop` repetă codul până când îl oprești cu `break`:

```rust
fn main() {
    let mut contor = 0;
    loop {
        contor += 1;
        if contor == 3 {
            break;
        }
        println!("pasul {contor}");
    }
}
```

## `while`: repetă cât timp condiția e adevărată

```rust
fn main() {
    let mut numar = 3;
    while numar > 0 {
        println!("{numar}...");
        numar -= 1;
    }
    println!("Start!");
}
```

## `for`: parcurge o colecție sau un interval

`for` este bucla pe care o vei folosi cel mai des:

```rust
fn main() {
    // interval: de la 1 la 4 (5 nu e inclus)
    for i in 1..5 {
        println!("i = {i}");
    }

    // interval inclusiv: de la 1 la 5
    for i in 1..=5 {
        print!("{i} ");
    }
    println!();

    // elementele unui array
    let fructe = ["măr", "pară", "prună"];
    for fruct in fructe {
        println!("{fruct}");
    }
}
```

## `break` și `continue`

`break` iese din buclă, iar `continue` sare direct la următoarea iterație:

```rust
fn main() {
    for n in 1..=10 {
        if n % 2 == 0 {
            continue; // sare peste numerele pare
        }
        if n > 7 {
            break; // se oprește după 7
        }
        println!("{n}");
    }
}
```

> **De reținut:** condiția din `if` trebuie să fie `bool`, iar `if` poate produce o valoare. `for` parcurge intervale și colecții, `while` rulează cât timp condiția e adevărată, iar `loop` rulează până la `break`.
