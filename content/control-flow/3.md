# Control flow — Avansat

În Rust aproape totul este o **expresie**. De aici vin regulile de tip pentru `if`, blocuri și bucle, plus felul în care se compune control flow-ul.

## Blocurile sunt expresii

Un bloc `{ ... }` are valoarea ultimei expresii, dacă aceasta nu se termină cu `;`. Un `;` transformă expresia în instrucțiune și blocul ajunge să aibă valoarea `()`:

```rust
fn main() {
    let x = {
        let a = 3;
        let b = 4;
        a * a + b * b // fără `;`: valoarea blocului
    };
    println!("{x}");
}
```

```rust,compile_fail
fn main() {
    let x: i32 = {
        let a = 3;
        a * a; // `;` face ca blocul să returneze ()
    }; // eroare E0308: se așteaptă i32, s-a găsit ()
}
```

## Ce tip au `if`, `loop` și `while`

- `if` fără `else` are tipul `()`, deci ramura lui trebuie să returneze `()`.
- `while` și `for` au întotdeauna tipul `()`, pentru că s-ar putea să nu ruleze niciodată.
- `loop` are tipul valorii din `break`. Dacă nu are niciun `break`, are tipul `!` și nu se termină niciodată.
- `break`, `continue` și `return` au tipul `!`, deci pot apărea oriunde se așteaptă o valoare:

```rust
fn main() {
    let valori = ["3", "x", "7"];
    let mut suma = 0;
    for v in valori {
        let n: i32 = match v.parse() {
            Ok(n) => n,
            Err(_) => continue, // `!` se potrivește cu i32
        };
        suma += n;
    }
    println!("{suma}");
}
```

## Ieșire dintr-un bloc cu etichetă

Din Rust 1.65, `break` funcționează și pe un bloc obișnuit cu etichetă, nu doar pe bucle. Așa ieși devreme dintr-o secvență de verificări fără să scrii o funcție separată:

```rust
fn main() {
    let input = "42";
    let mesaj = 'validare: {
        if input.is_empty() {
            break 'validare "gol";
        }
        if input.parse::<u32>().is_err() {
            break 'validare "nu e număr";
        }
        "valid"
    };
    println!("{mesaj}");
}
```

## Let chains (ediția 2024)

Din Rust 1.88, în ediția 2024, poți combina `if let` și condiții obișnuite cu `&&`. Variabilele legate mai devreme se pot folosi în condițiile de după:

```rust
fn main() {
    let config: Option<&str> = Some("8080");
    if let Some(text) = config
        && let Ok(port) = text.parse::<u16>()
        && port >= 1024
    {
        println!("port valid: {port}");
    }
}
```

Fără let chains, asta ar fi însemnat trei niveluri de `if` imbricate.

## Cum este tradus `for`

`for` nu e o construcție separată. Compilatorul îl transformă într-un `loop` care cere elementul următor de la un iterator:

```rust
fn main() {
    let v = vec![10, 20, 30];

    // for x in &v { println!("{x}"); } devine aproximativ:
    let mut iter = IntoIterator::into_iter(&v);
    loop {
        match iter.next() {
            Some(x) => println!("{x}"),
            None => break,
        }
    }
}
```

Prin urmare, `for` funcționează pe orice tip care implementează `IntoIterator`, inclusiv pe tipurile tale (vezi capitolul Closures și iteratori).

## Guard-uri în `match`

Un `match` poate avea condiții suplimentare (`if`) pe fiecare ramură. Verificarea exhaustivității nu ține cont de guard-uri, așa că ai nevoie tot de o ramură finală:

```rust
fn main() {
    let n = -4;
    let descriere = match n {
        0 => "zero",
        x if x < 0 && x % 2 == 0 => "negativ par",
        x if x < 0 => "negativ impar",
        _ => "pozitiv",
    };
    println!("{descriere}");
}
```

> **De reținut:** blocurile, `if`, `match` și `loop` produc valori. `;` schimbă tipul în `()`. `break`/`continue`/`return` au tipul `!`. `for` este de fapt un `loop` peste un iterator.
