# Control flow — Practitioner

Idiomatic Rust goes through collections with iterators, not indexes, and combines loops with patterns.

## A `loop` that returns a value

`break` can carry a value out of the loop. That's useful when you repeat an operation until it succeeds:

```rust
fn main() {
    let mut attempt = 0;
    let result = loop {
        attempt += 1;
        if attempt * attempt > 50 {
            break attempt; // the value of the `loop`
        }
    };
    println!("first number whose square exceeds 50: {result}");
}
```

## Labeled loops

In nested loops, a plain `break` only leaves the inner loop. A **label** (`'name:`) lets you leave the outer one directly:

```rust
fn main() {
    let matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]];
    let target = 5;

    'search: for (r, row) in matrix.iter().enumerate() {
        for (c, &value) in row.iter().enumerate() {
            if value == target {
                println!("found at ({r}, {c})");
                break 'search;
            }
        }
    }
}
```

## Iterate over elements, not indexes

Avoid `for i in 0..v.len()`. It is slower (every `v[i]` checks the bounds) and easier to get wrong:

```rust
fn main() {
    let grades = vec![9, 7, 10];

    for grade in &grades {                       // read only
        print!("{grade} ");
    }
    println!();

    for (i, grade) in grades.iter().enumerate() { // you also need the index
        println!("student {i}: {grade}");
    }

    for grade in grades.iter().rev() {           // in reverse order
        print!("{grade} ");
    }
    println!();
}
```

When you want to modify the elements, use `&mut`:

```rust
fn main() {
    let mut prices_cents = vec![1000, 2000, 3000];
    for price in &mut prices_cents {
        *price = *price * 119 / 100; // add 19% VAT
    }
    println!("{prices_cents:?}"); // [1190, 2380, 3570]
}
```

## `match`: several branches

`match` compares a value against several patterns. The compiler forces you to handle **every** case:

```rust
fn main() {
    let day = 6;
    let kind = match day {
        1..=5 => "weekday",
        6 | 7 => "weekend",
        _ => "invalid day",
    };
    println!("{kind}");
}
```

The Pattern matching chapter goes into detail.

## `if let` and `while let`

When you only care about one pattern, `if let` is shorter than a `match`:

```rust
fn main() {
    let config: Option<u32> = Some(8080);
    if let Some(port) = config {
        println!("listening on port {port}");
    } else {
        println!("using the default port");
    }
}
```

`while let` repeats as long as the pattern matches. A typical case is emptying a stack:

```rust
fn main() {
    let mut stack = vec![1, 2, 3];
    while let Some(top) = stack.pop() {
        println!("{top}");
    }
}
```

> **Key takeaway:** iterate over collections with `for x in &v`, `&mut v` or `.iter().enumerate()`, not through indexes. `break` can return a value from `loop`, and labels get you out of nested loops.
