# Control flow — Fundamentals

Control flow means deciding which code runs and how many times. Rust has `if` for decisions and three kinds of loops: `loop`, `while` and `for`.

## `if` and `else`

The condition must be of type `bool`. You don't put parentheses around it, but the curly braces are mandatory:

```rust
fn main() {
    let temperature = 28;

    if temperature > 30 {
        println!("It's very hot");
    } else if temperature > 20 {
        println!("It's pleasant");
    } else {
        println!("It's chilly");
    }
}
```

Unlike C or JavaScript, Rust doesn't automatically convert numbers to `bool`:

```rust,compile_fail
fn main() {
    let n = 3;
    if n { // error E0308: expected `bool`, found an integer
        println!("non-zero");
    }
}
```

Write the condition explicitly: `if n != 0`.

## `if` produces a value

In Rust, `if` is an expression, so you can use it directly in a `let`. Both branches must have the same type:

```rust
fn main() {
    let age = 17;
    let category = if age >= 18 { "adult" } else { "minor" };
    println!("{category}");
}
```

## `loop`: repeat forever

`loop` repeats the code until you stop it with `break`:

```rust
fn main() {
    let mut counter = 0;
    loop {
        counter += 1;
        if counter == 3 {
            break;
        }
        println!("step {counter}");
    }
}
```

## `while`: repeat as long as the condition is true

```rust
fn main() {
    let mut number = 3;
    while number > 0 {
        println!("{number}...");
        number -= 1;
    }
    println!("Liftoff!");
}
```

## `for`: go through a collection or a range

`for` is the loop you'll use most often:

```rust
fn main() {
    // range: from 1 to 4 (5 is not included)
    for i in 1..5 {
        println!("i = {i}");
    }

    // inclusive range: from 1 to 5
    for i in 1..=5 {
        print!("{i} ");
    }
    println!();

    // the elements of an array
    let fruits = ["apple", "pear", "plum"];
    for fruit in fruits {
        println!("{fruit}");
    }
}
```

## `break` and `continue`

`break` leaves the loop, and `continue` jumps straight to the next iteration:

```rust
fn main() {
    for n in 1..=10 {
        if n % 2 == 0 {
            continue; // skips even numbers
        }
        if n > 7 {
            break; // stops after 7
        }
        println!("{n}");
    }
}
```

> **Key takeaway:** the condition in an `if` must be a `bool`, and `if` can produce a value. `for` goes through ranges and collections, `while` runs as long as the condition is true, and `loop` runs until `break`.
