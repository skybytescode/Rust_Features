# Control flow — Practician

Codul Rust idiomatic parcurge colecții cu iteratori, nu cu indecși, și combină buclele cu pattern-uri.

## `loop` care returnează o valoare

`break` poate trimite o valoare în afara buclei. E util când repeți o operație până reușește:

```rust
fn main() {
    let mut incercare = 0;
    let rezultat = loop {
        incercare += 1;
        if incercare * incercare > 50 {
            break incercare; // valoarea lui `loop`
        }
    };
    println!("primul număr cu pătratul peste 50: {rezultat}");
}
```

## Bucle cu etichetă

Într-o buclă imbricată, `break` simplu iese doar din bucla interioară. O **etichetă** (`'nume:`) îți permite să ieși direct din cea exterioară:

```rust
fn main() {
    let matrice = [[1, 2, 3], [4, 5, 6], [7, 8, 9]];
    let tinta = 5;

    'cautare: for (r, rand) in matrice.iter().enumerate() {
        for (c, &valoare) in rand.iter().enumerate() {
            if valoare == tinta {
                println!("găsit la ({r}, {c})");
                break 'cautare;
            }
        }
    }
}
```

## Parcurge elementele, nu indecșii

Evită `for i in 0..v.len()`. E mai lent (fiecare `v[i]` verifică limitele) și mai ușor de greșit:

```rust
fn main() {
    let note = vec![9, 7, 10];

    for nota in &note {                      // doar citire
        print!("{nota} ");
    }
    println!();

    for (i, nota) in note.iter().enumerate() { // ai nevoie și de index
        println!("elevul {i}: {nota}");
    }

    for nota in note.iter().rev() {          // în ordine inversă
        print!("{nota} ");
    }
    println!();
}
```

Când vrei să modifici elementele, folosește `&mut`:

```rust
fn main() {
    let mut preturi_bani = vec![1000, 2000, 3000];
    for pret in &mut preturi_bani {
        *pret = *pret * 119 / 100; // adaugă TVA de 19%
    }
    println!("{preturi_bani:?}"); // [1190, 2380, 3570]
}
```

## `match`: mai multe ramuri

`match` compară o valoare cu mai multe pattern-uri. Compilatorul te obligă să tratezi **toate** cazurile:

```rust
fn main() {
    let zi = 6;
    let tip = match zi {
        1..=5 => "zi lucrătoare",
        6 | 7 => "weekend",
        _ => "zi invalidă",
    };
    println!("{tip}");
}
```

Capitolul Pattern matching intră în detalii.

## `if let` și `while let`

Când te interesează un singur pattern, `if let` e mai scurt decât un `match`:

```rust
fn main() {
    let config: Option<u32> = Some(8080);
    if let Some(port) = config {
        println!("ascult pe portul {port}");
    } else {
        println!("folosesc portul implicit");
    }
}
```

`while let` repetă cât timp pattern-ul se potrivește. Un caz tipic e golirea unei stive:

```rust
fn main() {
    let mut stiva = vec![1, 2, 3];
    while let Some(varf) = stiva.pop() {
        println!("{varf}");
    }
}
```

> **De reținut:** parcurge colecțiile cu `for x in &v`, `&mut v` sau `.iter().enumerate()`, nu prin indecși. `break` poate returna o valoare din `loop`, iar etichetele te scot din buclele imbricate.
