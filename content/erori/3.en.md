# Gestionarea erorilor — Avansat

Când alegi `panic` și când `Result`, cum construiești lanțuri de erori și ce oferă ecosistemul.

## Panic sau `Result`?

| Situația | Alege |
|---|---|
| Datele vin din exterior (utilizator, fișier, rețea) | `Result` |
| Eșecul e un rezultat normal (fișier lipsă, parolă greșită) | `Result` |
| A fost încălcat un invariant intern, deci e un bug | `panic!` |
| Prototip, exemplu, test | `unwrap` / `expect` e în regulă |
| Continuarea ar fi periculoasă (date corupte) | `panic!` |

O regulă bună pentru biblioteci: **nu da panic pe date de intrare**. Lasă apelantul să decidă. Dacă o funcție poate da panic, documentează asta într-o secțiune `# Panics`.

## Lanțuri de erori: `source()`

O eroare de nivel înalt poate păstra eroarea care a cauzat-o. `Error::source()` îți permite să parcurgi tot lanțul:

```rust
use std::error::Error;
use std::fmt;

#[derive(Debug)]
struct EroareIncarcare {
    fisier: String,
    cauza: std::num::ParseIntError,
}

impl fmt::Display for EroareIncarcare {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "nu am putut încărca `{}`", self.fisier)
    }
}

impl Error for EroareIncarcare {
    fn source(&self) -> Option<&(dyn Error + 'static)> {
        Some(&self.cauza)
    }
}

fn incarca() -> Result<u32, EroareIncarcare> {
    "abc".parse().map_err(|cauza| EroareIncarcare { fisier: "config.txt".into(), cauza })
}

fn main() {
    if let Err(e) = incarca() {
        println!("eroare: {e}");
        let mut cauza = e.source();
        while let Some(c) = cauza {
            println!("  cauzată de: {c}");
            cauza = c.source();
        }
    }
}
```

## `thiserror` și `anyhow`

În practică, două crate-uri elimină aproape tot codul repetitiv:

- **`thiserror`** (pentru biblioteci): `#[derive(Error)]` generează `Display`, `Error`, `source()` și `From` din atribute.
- **`anyhow`** (pentru aplicații): `anyhow::Result<T>` acceptă orice eroare, iar `.context("mesaj")` adaugă explicații pe parcurs.

```rust
// Cargo.toml: thiserror = "2", anyhow = "1"
use anyhow::Context;

#[allow(dead_code)]
#[derive(Debug, thiserror::Error)]
enum EroareDb {
    #[error("conexiunea a eșuat")]
    Conexiune(#[from] std::io::Error),
    #[error("utilizatorul {0} nu există")]
    Inexistent(u64),
}

fn citeste_config() -> anyhow::Result<String> {
    std::fs::read_to_string("config.toml").context("nu pot citi configurația")
}

fn main() {
    println!("{}", EroareDb::Inexistent(7));
    if let Err(e) = citeste_config() {
        println!("{e:#}"); // `{:#}` afișează tot lanțul: context + cauză
    }
}
```

## Colectarea erorilor din iteratori

`collect()` poate transforma un iterator de `Result`-uri într-un `Result` de colecție. Se oprește la **prima** eroare:

```rust
fn main() {
    let bune = ["1", "2", "3"];
    let rele = ["1", "x", "3"];

    let a: Result<Vec<i32>, _> = bune.iter().map(|s| s.parse::<i32>()).collect();
    let b: Result<Vec<i32>, _> = rele.iter().map(|s| s.parse::<i32>()).collect();
    println!("{a:?}");
    println!("{b:?}");

    // Ca să păstrezi toate valorile bune și să le ignori pe cele greșite:
    let doar_bune: Vec<i32> = rele.iter().filter_map(|s| s.parse().ok()).collect();
    println!("{doar_bune:?}");
}
```

## `and_then`: înlănțuirea operațiilor care pot eșua

```rust
fn parseaza(s: &str) -> Option<i32> {
    s.parse().ok()
}

fn radical(n: i32) -> Option<f64> {
    if n >= 0 { Some((n as f64).sqrt()) } else { None }
}

fn main() {
    println!("{:?}", parseaza("16").and_then(radical)); // Some(4.0)
    println!("{:?}", parseaza("-4").and_then(radical)); // None
    println!("{:?}", parseaza("x").and_then(radical));  // None
}
```

## Prinderea unui panic

`std::panic::catch_unwind` oprește un panic să ajungă mai sus. **Nu** e un mecanism de excepții: folosește-l doar la granițe, de exemplu ca să nu cadă un întreg server din cauza unei cereri sau la granița FFI.

```rust
use std::panic;

fn main() {
    panic::set_hook(Box::new(|_| {})); // ascunde mesajul implicit, pentru exemplu
    let rezultat = panic::catch_unwind(|| {
        let v: Vec<i32> = Vec::new();
        v[0]
    });
    let _ = panic::take_hook();
    println!("panic prins: {}", rezultat.is_err());
}
```

> **De reținut:** folosește `Result` pentru date din exterior și `panic` pentru bug-uri. Expune cauzele prin `source()`. Alege `thiserror` pentru biblioteci și `anyhow` pentru aplicații. `collect()` adună rezultatele într-un `Result<Vec<_>, _>`.
