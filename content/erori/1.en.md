# Gestionarea erorilor — Fundamente

Rust împarte erorile în două categorii:

- **erori nerecuperabile**, adică bug-uri: programul se oprește cu `panic!`;
- **erori recuperabile**, cum ar fi un fișier lipsă sau un text care nu e număr: funcția returnează un `Result`, iar apelantul decide ce face.

Rust nu are excepții.

## `panic!`: oprește programul

```rust,should_panic
fn main() {
    let v = vec![1, 2, 3];
    println!("început");
    let x = v[10]; // index în afara limitelor: panic
    println!("{x}");
}
```

Programul afișează mesajul de eroare și se oprește. Poți provoca singur un panic cu `panic!("mesaj")`, pentru situații care „nu ar trebui să se întâmple niciodată”.

## `Result`: succes sau eroare

`Result<T, E>` este un enum cu două variante:

- `Ok(valoare)`: operația a reușit, iar `valoare` are tipul `T`;
- `Err(eroare)`: operația a eșuat, iar `eroare` are tipul `E`.

```rust
fn main() {
    let texte = ["42", "abc"];
    for t in texte {
        match t.parse::<i32>() {
            Ok(n) => println!("{t} → număr: {n}"),
            Err(e) => println!("{t} → eroare: {e}"),
        }
    }
}
```

Compilatorul te obligă să tratezi `Result`: nu poți folosi direct un `Result<i32, _>` ca pe un `i32`.

## Propriile funcții care pot eșua

```rust
fn imparte(a: i32, b: i32) -> Result<i32, String> {
    if b == 0 {
        Err(String::from("împărțire la zero"))
    } else {
        Ok(a / b)
    }
}

fn main() {
    match imparte(10, 2) {
        Ok(r) => println!("rezultat: {r}"),
        Err(e) => println!("eroare: {e}"),
    }
    match imparte(1, 0) {
        Ok(r) => println!("rezultat: {r}"),
        Err(e) => println!("eroare: {e}"),
    }
}
```

## `Option` pentru „poate lipsi”

Când un rezultat lipsă nu e o eroare propriu-zisă (de exemplu, căutarea unui element), folosește `Option`:

```rust
fn main() {
    let nume = ["Ana", "Mihai", "Ioana"];
    match nume.iter().position(|&n| n == "Mihai") {
        Some(i) => println!("găsit la poziția {i}"),
        None => println!("nu există"),
    }
}
```

## `unwrap` și `expect`

`unwrap()` scoate valoarea dintr-un `Ok` sau `Some` și dă **panic** dacă găsește o eroare. `expect("mesaj")` face la fel, dar cu un mesaj ales de tine:

```rust
fn main() {
    let port: u16 = "8080".parse().unwrap();
    let timeout: u32 = "30".parse().expect("timeout-ul trebuie să fie un număr");
    println!("{port} {timeout}");
}
```

Folosește-le în exemple, în teste sau când ești **sigur** că eroarea nu poate apărea. În rest, tratează eroarea.

> **De reținut:** `panic!` e pentru bug-uri, `Result` pentru erorile la care te aștepți, iar `Option` pentru valorile care pot lipsi. `unwrap` și `expect` transformă o eroare în panic.
