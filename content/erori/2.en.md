# Gestionarea erorilor — Practician

În codul real, erorile se propagă de la funcția care le produce până la locul unde pot fi tratate. Operatorul `?` face asta fără ceremonie.

## Operatorul `?`

`?` pus după un `Result` returnează valoarea din `Ok`. Dacă găsește un `Err`, **iese imediat** din funcție și returnează eroarea:

```rust
use std::num::ParseIntError;

fn suma_texte(a: &str, b: &str) -> Result<i32, ParseIntError> {
    let x: i32 = a.trim().parse()?; // la eroare, funcția returnează Err aici
    let y: i32 = b.trim().parse()?;
    Ok(x + y)
}

fn main() {
    println!("{:?}", suma_texte("2", " 40 "));
    println!("{:?}", suma_texte("2", "x"));
}
```

`?` funcționează și cu `Option`, într-o funcție care returnează `Option`.

## `main` poate returna `Result`

Dacă `main` returnează o eroare, programul afișează eroarea și iese cu un cod nenul:

```rust
use std::error::Error;

fn main() -> Result<(), Box<dyn Error>> {
    let n: u32 = "12".parse()?;
    let m: f64 = "3.5".parse()?;
    println!("{}", n as f64 * m);
    Ok(())
}
```

`Box<dyn Error>` acceptă orice tip de eroare. E alegerea comodă pentru aplicații și prototipuri.

## Propriul tip de eroare

Într-o bibliotecă sau într-un modul important, un `enum` descrie exact ce poate merge prost. Implementezi `Display` pentru mesaj și `Error` ca să fie o eroare „oficială”:

```rust
use std::fmt;

#[derive(Debug)]
enum EroareConfig {
    Lipsa(String),
    Invalid { cheie: String, valoare: String },
}

impl fmt::Display for EroareConfig {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        match self {
            EroareConfig::Lipsa(cheie) => write!(f, "lipsește cheia `{cheie}`"),
            EroareConfig::Invalid { cheie, valoare } => {
                write!(f, "valoare invalidă pentru `{cheie}`: {valoare}")
            }
        }
    }
}

impl std::error::Error for EroareConfig {}

fn citeste_port(config: &[(&str, &str)]) -> Result<u16, EroareConfig> {
    let (_, valoare) = config
        .iter()
        .find(|(k, _)| *k == "port")
        .ok_or_else(|| EroareConfig::Lipsa("port".into()))?;
    valoare.parse().map_err(|_| EroareConfig::Invalid {
        cheie: "port".into(),
        valoare: valoare.to_string(),
    })
}

fn main() {
    println!("{:?}", citeste_port(&[("port", "8080")]));
    for config in [&[][..], &[("port", "abc")]] {
        if let Err(e) = citeste_port(config) {
            println!("eroare: {e}");
        }
    }
}
```

## Conversia automată cu `From`

Dacă implementezi `From<AltaEroare>` pentru tipul tău, `?` face conversia singur:

```rust
use std::num::ParseIntError;

#[derive(Debug)]
enum EroareAplicatie {
    Numar(ParseIntError),
    Negativ(i64),
}

impl From<ParseIntError> for EroareAplicatie {
    fn from(e: ParseIntError) -> Self {
        EroareAplicatie::Numar(e)
    }
}

fn varsta(text: &str) -> Result<u32, EroareAplicatie> {
    let n: i64 = text.parse()?; // ParseIntError → EroareAplicatie, automat
    if n < 0 {
        return Err(EroareAplicatie::Negativ(n));
    }
    Ok(n as u32)
}

fn main() {
    println!("{:?}", varsta("30"));
    println!("{:?}", varsta("-2"));
    println!("{:?}", varsta("x"));
}
```

## Metode utile

```rust
fn main() {
    let r: Result<i32, String> = Err("eșec".into());
    println!("{}", r.clone().unwrap_or(0));                   // valoare implicită
    println!("{}", r.clone().unwrap_or_else(|e| e.len() as i32)); // calculată din eroare
    println!("{:?}", r.clone().map(|n| n * 2));               // transformă Ok
    println!("{:?}", r.clone().map_err(|e| e.to_uppercase())); // transformă Err
    println!("{:?}", r.ok());                                 // Result → Option

    let o: Option<u8> = None;
    println!("{:?}", o.ok_or("lipsește"));                    // Option → Result
}
```

> **De reținut:** `?` propagă erorile spre apelant. `main` poate returna `Result`. Pentru erori precise, definește un `enum` cu `Display` și `Error`, iar implementarea `From` lasă `?` să facă singur conversia.
