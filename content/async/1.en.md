# Async/await — Fundamente

Programarea **asincronă** îți permite să aștepți mai multe lucruri lente deodată (rețea, fișiere, timere) fără câte un thread pentru fiecare. Cât o operație așteaptă, programul lucrează la altele.

## Problema

Un server care descarcă 1000 de pagini web își petrece aproape tot timpul **așteptând** răspunsuri. Cu un thread per cerere ai 1000 de thread-uri, fiecare cu stiva lui, majoritatea dormind. Async rezolvă problema cu câteva thread-uri care comută între sarcini exact când una trebuie să aștepte.

## `async fn` și `.await`

O funcție `async` nu rulează imediat. Returnează un **future**: o promisiune a unei valori viitoare. Cu `.await` ceri rezultatul. Cât timp aștepți, alte sarcini pot rula:

```rust
use std::time::Duration;

async fn descarca(pagina: &str) -> String {
    tokio::time::sleep(Duration::from_millis(100)).await; // simulează rețeaua
    format!("conținutul paginii {pagina}")
}

#[tokio::main]
async fn main() {
    let rezultat = descarca("acasă").await;
    println!("{rezultat}");
}
```

## Ai nevoie de un runtime

Rust definește doar limbajul (`async`, `.await`, trait-ul `Future`). Ca future-urile să ruleze efectiv, ai nevoie de un **runtime**: o bibliotecă ce decide ce sarcină rulează și când. Cel mai folosit este **tokio**:

```toml
[dependencies]
tokio = { version = "1", features = ["full"] }
```

`#[tokio::main]` transformă `main` într-o funcție obișnuită care pornește runtime-ul și rulează future-ul tău.

## Mai multe operații în paralel

Avantajul real apare când aștepți mai multe lucruri **simultan**. `tokio::join!` le rulează pe toate și așteaptă să termine:

```rust
use std::time::{Duration, Instant};

async fn descarca(pagina: &str, ms: u64) -> String {
    tokio::time::sleep(Duration::from_millis(ms)).await;
    format!("{pagina} ({ms} ms)")
}

#[tokio::main]
async fn main() {
    let start = Instant::now();

    let (a, b, c) = tokio::join!(
        descarca("știri", 300),
        descarca("vreme", 200),
        descarca("sport", 100),
    );

    println!("{a}\n{b}\n{c}");
    // ~300 ms în total, nu 600: cele trei așteptări se suprapun
    println!("durată: ~{} ms", start.elapsed().as_millis() / 100 * 100);
}
```

## Future-urile sunt leneșe

Un future nu face **nimic** până nu e așteptat cu `.await` sau dat unui runtime:

```rust
async fn salut() {
    println!("salut din async");
}

#[tokio::main]
async fn main() {
    let f = salut(); // nu afișează nimic încă
    println!("future creat");
    f.await;         // abia acum rulează
}
```

Compilatorul te avertizează dacă uiți `.await`: „futures do nothing unless you `.await` or poll them”.

## Async sau thread-uri?

| Sarcina ta | Alege |
|---|---|
| multe operații care **așteaptă** (rețea, servere web, baze de date) | async |
| calcule grele care **folosesc procesorul** | thread-uri (sau `rayon`) |
| un program mic, cu câteva operații | cod sincron obișnuit |

> **De reținut:** `async fn` returnează un future, iar `.await` așteaptă rezultatul fără să blocheze alte sarcini. Ai nevoie de un runtime, de obicei tokio. `join!` rulează mai multe future-uri simultan, iar future-urile nu fac nimic până nu sunt așteptate.
