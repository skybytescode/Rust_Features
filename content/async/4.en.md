# Async/await — Expert

Construim de la zero, doar cu biblioteca standard, piesele pe care un runtime ca tokio le ascunde: un `Future` scris manual, un `Waker` și un executor.

## Un future scris manual

Un timer care devine gata după o durată. La primul `poll` pornește un thread care, după ce trece timpul, apelează `waker.wake()`:

```rust
use std::future::Future;
use std::pin::Pin;
use std::sync::{Arc, Mutex};
use std::task::{Context, Poll, Waker};
use std::thread;
use std::time::Duration;

struct Stare {
    gata: bool,
    waker: Option<Waker>,
}

pub struct Timer {
    stare: Arc<Mutex<Stare>>,
}

impl Timer {
    pub fn new(durata: Duration) -> Self {
        let stare = Arc::new(Mutex::new(Stare { gata: false, waker: None }));
        let s = Arc::clone(&stare);
        thread::spawn(move || {
            thread::sleep(durata);
            let mut s = s.lock().unwrap();
            s.gata = true;
            if let Some(w) = s.waker.take() {
                w.wake(); // anunță executorul că merită să ne interogheze din nou
            }
        });
        Timer { stare }
    }
}

impl Future for Timer {
    type Output = ();
    fn poll(self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<()> {
        let mut s = self.stare.lock().unwrap();
        if s.gata {
            Poll::Ready(())
        } else {
            // Păstrăm cel mai recent waker: future-ul poate fi mutat între sarcini.
            s.waker = Some(cx.waker().clone());
            Poll::Pending
        }
    }
}

fn main() {
    // Interogăm manual, cu un waker care nu face nimic: fără un executor
    // care să reacționeze la wake(), trebuie să reîncercăm singuri.
    let mut timer = std::pin::pin!(Timer::new(Duration::from_millis(30)));
    let mut cx = Context::from_waker(Waker::noop());
    let mut interogari = 1;
    while timer.as_mut().poll(&mut cx).is_pending() {
        interogari += 1;
        thread::sleep(Duration::from_millis(10));
    }
    println!("gata după {} interogări", if interogari > 1 { "mai multe" } else { "o singură" });
}
```

Bucla de mai sus „ghicește” când să reîncerce. Un executor adevărat doarme până când waker-ul îl trezește.

**Contractul unui future:** când returnezi `Pending`, trebuie să te asiguri că waker-ul va fi apelat cândva. Altfel, sarcina rămâne blocată pentru totdeauna, fără eroare.

## Un executor minimal

Executorul cel mai simplu rulează un singur future pe thread-ul curent. Între `poll`-uri, thread-ul doarme, iar waker-ul îl trezește:

```rust
use std::future::Future;
use std::pin::pin;
use std::sync::Arc;
use std::task::{Context, Poll, Wake, Waker};
use std::thread::{self, Thread};

struct TrezesteThread(Thread);

impl Wake for TrezesteThread {
    fn wake(self: Arc<Self>) {
        self.0.unpark();
    }
}

fn block_on<F: Future>(fut: F) -> F::Output {
    let mut fut = pin!(fut); // fixat pe stivă
    let waker = Waker::from(Arc::new(TrezesteThread(thread::current())));
    let mut cx = Context::from_waker(&waker);
    loop {
        match fut.as_mut().poll(&mut cx) {
            Poll::Ready(v) => return v,
            Poll::Pending => thread::park(), // doarme până la wake()
        }
    }
}

async fn aduna(a: u32, b: u32) -> u32 {
    a + b
}

fn main() {
    let rezultat = block_on(async {
        let x = aduna(2, 3).await;
        let y = aduna(x, 10).await;
        y * 2
    });
    println!("{rezultat}");
}
```

`thread::park` poate reveni și fără `unpark`. Nu e o problemă, pentru că bucla interoghează din nou, iar un `poll` în plus e întotdeauna permis.

## Executor + timer împreună, cu mai multe sarcini

Un executor cu mai multe sarcini ține o **coadă**. Waker-ul fiecărei sarcini o pune înapoi în coadă:

```rust
use std::collections::VecDeque;
use std::future::Future;
use std::pin::Pin;
use std::sync::{Arc, Mutex};
use std::task::{Context, Poll, Wake, Waker};
use std::time::{Duration, Instant};

type SarcinaFut = Pin<Box<dyn Future<Output = ()> + Send>>;

struct Sarcina {
    fut: Mutex<Option<SarcinaFut>>,
    coada: Arc<Mutex<VecDeque<Arc<Sarcina>>>>,
}

impl Wake for Sarcina {
    fn wake(self: Arc<Self>) {
        let coada = Arc::clone(&self.coada);
        coada.lock().unwrap().push_back(self);
    }
}

// Timer simplificat: un thread per timer, ca în exemplul anterior
struct Timer { gata: Arc<Mutex<(bool, Option<Waker>)>> }

impl Timer {
    fn new(d: Duration) -> Self {
        let gata = Arc::new(Mutex::new((false, None::<Waker>)));
        let g = Arc::clone(&gata);
        std::thread::spawn(move || {
            std::thread::sleep(d);
            let mut s = g.lock().unwrap();
            s.0 = true;
            if let Some(w) = s.1.take() { w.wake(); }
        });
        Timer { gata }
    }
}

impl Future for Timer {
    type Output = ();
    fn poll(self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<()> {
        let mut s = self.gata.lock().unwrap();
        if s.0 { Poll::Ready(()) } else { s.1 = Some(cx.waker().clone()); Poll::Pending }
    }
}

fn main() {
    let coada: Arc<Mutex<VecDeque<Arc<Sarcina>>>> = Arc::new(Mutex::new(VecDeque::new()));
    let start = Instant::now();

    for (id, ms) in [(1, 120), (2, 40), (3, 80)] {
        let fut: SarcinaFut = Box::pin(async move {
            Timer::new(Duration::from_millis(ms)).await;
            println!("sarcina {id} gata după ~{ms} ms");
        });
        let s = Arc::new(Sarcina { fut: Mutex::new(Some(fut)), coada: Arc::clone(&coada) });
        coada.lock().unwrap().push_back(s);
    }

    let mut ramase = 3;
    while ramase > 0 {
        let urmatoarea = coada.lock().unwrap().pop_front();
        let Some(sarcina) = urmatoarea else {
            std::thread::sleep(Duration::from_millis(1)); // un executor real ar folosi park/unpark
            continue;
        };
        let mut slot = sarcina.fut.lock().unwrap();
        if let Some(mut fut) = slot.take() {
            let waker = Waker::from(Arc::clone(&sarcina));
            let mut cx = Context::from_waker(&waker);
            if fut.as_mut().poll(&mut cx).is_pending() {
                *slot = Some(fut); // o punem la loc; waker-ul o va reprograma
            } else {
                ramase -= 1;
            }
        }
    }
    println!("total: ~{} ms (nu 240: timerele s-au suprapus)", start.elapsed().as_millis() / 40 * 40);
}
```

Tokio face exact asta, dar cu un *reactor* care folosește `epoll` / `kqueue` / IOCP în loc de câte un thread per timer, cu cozi per thread și *work stealing* între ele.

## Ce mai adaugă un runtime real

- **Reactor de I/O**: înregistrează socket-urile la sistemul de operare și apelează waker-ul când devin citibile sau scriibile;
- **roată de timere** (*timer wheel*): mii de timere fără mii de thread-uri;
- **work stealing**: thread-urile libere „fură” sarcini din cozile celor ocupate;
- **buget cooperativ**: forțează o sarcină care nu returnează niciodată `Pending` să cedeze din când în când.

> **De reținut:** un future returnează `Pending` doar după ce a păstrat waker-ul, iar `wake()` îl reprogramează. Un executor este o buclă care interoghează sarcinile din coadă. `Wake` + `Arc` construiesc un `Waker` fără `unsafe`. Tokio adaugă un reactor de I/O, timere eficiente și work stealing.
