# Async/await — Practician

Sarcini independente, alegerea primului rezultat, timeout-uri și greșeala cea mai frecventă: blocarea runtime-ului.

## `tokio::spawn`: sarcini independente

`spawn` pornește un future ca **sarcină** separată, pe care runtime-ul o poate rula pe orice thread. Primești un `JoinHandle`, ca la thread-uri:

```rust
use std::time::Duration;

#[tokio::main]
async fn main() {
    let mut sarcini = Vec::new();
    for id in 1..=3 {
        sarcini.push(tokio::spawn(async move {
            tokio::time::sleep(Duration::from_millis(50 * id)).await;
            id * 10
        }));
    }

    let mut total = 0;
    for s in sarcini {
        total += s.await.unwrap(); // Err doar dacă sarcina a dat panic
    }
    println!("total: {total}");
}
```

O sarcină pornită cu `spawn` trebuie să fie `Send + 'static`, pentru că poate rula pe alt thread și poate trăi mai mult decât funcția curentă. De aici vine nevoia de `move` și de `Arc`.

## `join!` vs. `spawn`

| | `join!` | `spawn` |
|---|---|---|
| Rulează pe | sarcina curentă (concurent, nu neapărat paralel) | orice thread al runtime-ului |
| Cere `Send + 'static` | nu, poate împrumuta | da |
| Dacă renunți la ea | se oprește | continuă în fundal |

## `select!`: primul care termină

`select!` așteaptă mai multe future-uri și continuă cu **primul** care termină. Celelalte sunt anulate:

```rust
use std::time::Duration;

async fn server_lent() -> &'static str {
    tokio::time::sleep(Duration::from_millis(300)).await;
    "răspuns lent"
}

async fn server_rapid() -> &'static str {
    tokio::time::sleep(Duration::from_millis(50)).await;
    "răspuns rapid"
}

#[tokio::main]
async fn main() {
    tokio::select! {
        r = server_lent() => println!("primul: {r}"),
        r = server_rapid() => println!("primul: {r}"),
    }
}
```

## Timeout

```rust
use std::time::Duration;
use tokio::time::timeout;

async fn operatie_lunga() -> u32 {
    tokio::time::sleep(Duration::from_secs(10)).await;
    42
}

#[tokio::main]
async fn main() {
    match timeout(Duration::from_millis(100), operatie_lunga()).await {
        Ok(v) => println!("rezultat: {v}"),
        Err(_) => println!("a expirat timpul"),
    }
}
```

## Nu bloca runtime-ul

Runtime-ul are puține thread-uri. Dacă o sarcină face un calcul lung sau apelează o funcție **blocantă** (`std::thread::sleep`, `std::fs`, un client HTTP sincron), blochează și celelalte sarcini de pe acel thread. Folosește:

- versiunile async: `tokio::time::sleep`, `tokio::fs`, `tokio::net`;
- `spawn_blocking` pentru cod blocant sau calcule grele.

```rust
#[tokio::main]
async fn main() {
    let rezultat = tokio::task::spawn_blocking(|| {
        // rulează pe un thread separat, rezervat operațiilor blocante
        (1..=5_000_000u64).filter(|n| n % 7 == 0).count()
    })
    .await
    .unwrap();
    println!("{rezultat}");
}
```

## Canale async

Tokio are canale proprii, care pot fi așteptate cu `.await`:

```rust
use tokio::sync::mpsc;

#[tokio::main]
async fn main() {
    let (tx, mut rx) = mpsc::channel(8); // capacitate 8: `send` așteaptă dacă e plin

    for id in 0..3 {
        let tx = tx.clone();
        tokio::spawn(async move {
            tx.send(format!("mesaj de la {id}")).await.unwrap();
        });
    }
    drop(tx);

    let mut mesaje = Vec::new();
    while let Some(m) = rx.recv().await {
        mesaje.push(m);
    }
    mesaje.sort();
    println!("{mesaje:?}");
}
```

## Mutex în async

`std::sync::Mutex` e în regulă dacă **nu** ții lacătul peste un `.await`. Dacă trebuie să-l ții peste un `.await`, folosește `tokio::sync::Mutex`, al cărui `lock()` se așteaptă cu `.await`:

```rust
use std::sync::Arc;
use tokio::sync::Mutex;

#[tokio::main]
async fn main() {
    let jurnal = Arc::new(Mutex::new(Vec::new()));
    let mut sarcini = Vec::new();
    for i in 0..3 {
        let j = Arc::clone(&jurnal);
        sarcini.push(tokio::spawn(async move {
            let mut g = j.lock().await;
            tokio::task::yield_now().await; // un .await în timp ce ținem lacătul
            g.push(i);
        }));
    }
    for s in sarcini {
        s.await.unwrap();
    }
    println!("{} intrări", jurnal.lock().await.len());
}
```

> **De reținut:** `spawn` pornește sarcini independente (`Send + 'static`), `join!` le rulează concurent pe loc, iar `select!` ia primul rezultat. Nu bloca runtime-ul: folosește API-urile async sau `spawn_blocking`. Pentru lacăte ținute peste `.await`, folosește `tokio::sync::Mutex`.
