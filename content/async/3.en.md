# Async/await — Avansat

Ce este un `Future`, cum devine `async fn` o mașină de stări, de ce apare `Pin`, cum funcționează anularea și ce aduc async în trait-uri și closures `async`.

## Trait-ul `Future`

```rust,ignore
pub trait Future {
    type Output;
    fn poll(self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<Self::Output>;
}

pub enum Poll<T> {
    Ready(T),
    Pending,
}
```

Runtime-ul apelează `poll`. Dacă rezultatul e gata, future-ul returnează `Ready(valoare)`. Dacă nu, returnează `Pending` și **promite** să anunțe runtime-ul (prin `cx.waker()`) când merită să fie apelat din nou. Runtime-ul nu reîncearcă orbește: așteaptă semnalul.

## `async fn` devine o mașină de stări

Compilatorul transformă fiecare `async fn` într-un enum anonim. Fiecare variantă e un punct de `.await`, iar variabilele care trăiesc peste acel punct sunt câmpurile ei:

```rust,ignore
async fn exemplu() -> usize {
    let a = String::from("salut");
    pas_unu().await;          // starea 1: păstrează `a`
    let b = a.len();
    pas_doi().await;          // starea 2: păstrează `b`
    b
}
// ≈ enum ExempluFuture { Start, Asteapta1 { a, f1 }, Asteapta2 { b, f2 }, Gata }
```

Mărimea future-ului este mărimea celei mai mari stări. Poți vedea efectul direct:

```rust
async fn mic() -> u8 {
    tokio::task::yield_now().await;
    1
}

async fn mare() -> u8 {
    let buffer = [0u8; 4096]; // trăiește peste .await, deci intră în future
    tokio::task::yield_now().await;
    buffer[0]
}

#[tokio::main]
async fn main() {
    println!("mic: {} octeți", size_of_val(&mic()));
    println!("mare: {} octeți", size_of_val(&mare()));
    println!("{} {}", mic().await, mare().await);
}
```

Un future mare înseamnă copii mari la fiecare mutare. Valorile mari care trebuie să trăiască peste `.await` stau mai bine într-un `Box` sau într-un `Vec`.

## De ce `Pin`

O stare poate conține o **referință către o altă variabilă din aceeași stare**: de exemplu, `let r = &a; x.await; use(r);`. Future-ul devine *self-referential*. Dacă ar fi mutat în memorie după primul `poll`, `r` ar indica spre vechea adresă. De aceea `poll` primește `Pin<&mut Self>`: după ce a fost fixat, future-ul nu mai poate fi mutat.

În practică: `Box::pin(fut)` sau `std::pin::pin!(fut)` când ai nevoie de un future fixat, de exemplu ca să-l poți folosi într-un `select!` în buclă.

## Anularea prin drop

Un future anulat nu primește o excepție. Este pur și simplu **distrus** (`drop`) și nu mai e apelat niciodată. Execuția se oprește la ultimul `.await` atins, iar destructorii variabilelor rulează normal:

```rust
use std::time::Duration;

struct Garda(&'static str);
impl Drop for Garda {
    fn drop(&mut self) {
        println!("curăț: {}", self.0);
    }
}

async fn lucru_lung() {
    let _g = Garda("resursă temporară");
    println!("încep");
    tokio::time::sleep(Duration::from_secs(10)).await;
    println!("nu ajung aici");
}

#[tokio::main]
async fn main() {
    let r = tokio::time::timeout(Duration::from_millis(50), lucru_lung()).await;
    println!("anulat: {}", r.is_err());
}
```

Consecința importantă este **cancellation safety**: dacă un future e anulat în `select!` între două `.await`-uri, orice stare intermediară se pierde. Documentația tokio marchează metodele sigure la anulare.

## `async fn` în trait-uri

Din Rust 1.75, trait-urile pot avea metode `async`:

```rust
trait Depozit {
    async fn gaseste(&self, id: u32) -> Option<String>;
}

struct Memorie;

impl Depozit for Memorie {
    async fn gaseste(&self, id: u32) -> Option<String> {
        tokio::task::yield_now().await;
        (id == 1).then(|| "Ana".to_string())
    }
}

#[tokio::main]
async fn main() {
    let d = Memorie;
    println!("{:?} {:?}", d.gaseste(1).await, d.gaseste(2).await);
}
```

Limitări: un astfel de trait nu e încă dyn-compatible, iar apelantul nu poate cere ca future-ul returnat să fie `Send`. Pentru `dyn` sau pentru constrângeri `Send`, crate-ul `async-trait` (care folosește `Box<dyn Future>`) e încă util.

## Closures `async`

Din Rust 1.85, `async || { ... }` creează un closure ale cărui future-uri pot împrumuta din capturile lui. Trait-urile corespunzătoare sunt `AsyncFn`, `AsyncFnMut` și `AsyncFnOnce`:

```rust
async fn de_doua_ori(f: impl AsyncFn(u32) -> u32) -> u32 {
    f(1).await + f(2).await
}

#[tokio::main]
async fn main() {
    let factor = 10;
    let inmulteste = async |x: u32| {
        tokio::task::yield_now().await;
        x * factor
    };
    println!("{}", de_doua_ori(inmulteste).await);
}
```

> **De reținut:** un `Future` e interogat cu `poll` și anunță prin `Waker` când poate continua. `async fn` devine o mașină de stări, iar valorile care trec peste `.await` îi cresc mărimea. `Pin` protejează future-urile self-referential. Anularea înseamnă drop. Async în trait-uri și closures `async` sunt stabile.
