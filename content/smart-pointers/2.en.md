# Smart pointers — Practician

Ce face un tip să fie „smart pointer” (`Deref` și `Drop`), cum eviți ciclurile cu `Weak` și când alegi `Cell` în loc de `RefCell`.

## `Deref`: comportament de referință

Un tip care implementează `Deref` poate fi folosit cu `*` și primește **deref coercion**: `&TipulTau` se convertește automat în `&Tinta` acolo unde e nevoie:

```rust
use std::ops::Deref;

struct Nume(String);

impl Deref for Nume {
    type Target = String;
    fn deref(&self) -> &String {
        &self.0
    }
}

fn lungime(s: &str) -> usize {
    s.len()
}

fn main() {
    let n = Nume(String::from("Ioana"));
    println!("{}", n.to_uppercase()); // metodele lui String, prin Deref
    println!("{}", lungime(&n));      // &Nume → &String → &str, automat
}
```

Folosește `Deref` doar pentru tipuri care chiar sunt „pointeri către” ceva. Nu e un mecanism de moștenire.

## `Drop`: cod rulat la distrugere

`Drop` îți permite să eliberezi resurse când o valoare iese din scope: fișiere, conexiuni, lacăte:

```rust
struct Conexiune {
    adresa: String,
}

impl Drop for Conexiune {
    fn drop(&mut self) {
        println!("închid conexiunea la {}", self.adresa);
    }
}

fn main() {
    let _a = Conexiune { adresa: "db:5432".into() };
    {
        let _b = Conexiune { adresa: "cache:6379".into() };
        println!("lucrez cu ambele");
    } // _b e închisă aici
    let c = Conexiune { adresa: "api:443".into() };
    drop(c); // închidere explicită, înainte de finalul scope-ului
    println!("sfârșit");
} // _a e închisă aici
```

Nu poți apela direct `x.drop()`. Folosești `drop(x)` (sau `std::mem::drop`), care mută valoarea și o distruge.

## Cicluri și `Weak`

Două `Rc` care se referă unul pe altul nu ajung niciodată la contor 0, așa că memoria nu mai e eliberată (*memory leak*). `Weak` este o referință care **nu** ține valoarea în viață. Pentru relațiile părinte–copil, copiii țin `Weak` spre părinte:

```rust
use std::cell::RefCell;
use std::rc::{Rc, Weak};

struct Nod {
    nume: String,
    parinte: RefCell<Weak<Nod>>,
    copii: RefCell<Vec<Rc<Nod>>>,
}

fn main() {
    let radacina = Rc::new(Nod { nume: "rădăcină".into(), parinte: RefCell::new(Weak::new()), copii: RefCell::new(vec![]) });
    let frunza = Rc::new(Nod { nume: "frunză".into(), parinte: RefCell::new(Weak::new()), copii: RefCell::new(vec![]) });

    *frunza.parinte.borrow_mut() = Rc::downgrade(&radacina);
    radacina.copii.borrow_mut().push(Rc::clone(&frunza));

    if let Some(p) = frunza.parinte.borrow().upgrade() {
        println!("părintele frunzei: {}", p.nume);
    }
    println!("copii: {}", radacina.copii.borrow().len());
    println!("strong rădăcină: {}, weak rădăcină: {}", Rc::strong_count(&radacina), Rc::weak_count(&radacina));
}
```

`upgrade()` returnează `Option<Rc<T>>`: `None` dacă valoarea a fost deja eliberată.

## `Cell` vs. `RefCell`

| | `Cell<T>` | `RefCell<T>` |
|---|---|---|
| Acces | copiezi valoarea înăuntru / în afară (`get`, `set`) | împrumuți (`borrow`, `borrow_mut`) |
| Cost | zero | un contor verificat la fiecare împrumut |
| Poate da panic | nu | da, la împrumuturi conflictuale |
| Potrivit pentru | contoare, flag-uri, tipuri `Copy` mici | structuri mai mari (`Vec`, `String`) |

```rust
use std::cell::Cell;

struct Pagina {
    vizualizari: Cell<u32>,
}

impl Pagina {
    fn afiseaza(&self) { // doar &self, dar putem incrementa
        self.vizualizari.set(self.vizualizari.get() + 1);
    }
}

fn main() {
    let p = Pagina { vizualizari: Cell::new(0) };
    p.afiseaza();
    p.afiseaza();
    println!("vizualizări: {}", p.vizualizari.get());
}
```

## Panic la runtime cu `RefCell`

Dacă încalci regulile de împrumut, `RefCell` dă panic:

```rust,should_panic
use std::cell::RefCell;

fn main() {
    let date = RefCell::new(vec![1, 2, 3]);
    let citire = date.borrow();
    date.borrow_mut().push(4); // panic: already borrowed
    println!("{citire:?}");
}
```

`try_borrow_mut()` returnează un `Result` în loc să dea panic, ca să poți trata situația.

> **De reținut:** `Deref` dă comportament de referință și coerciție automată, iar `Drop` eliberează resurse. `Weak` sparge ciclurile dintre `Rc`-uri. Alege `Cell` pentru valori `Copy` mici și `RefCell` pentru restul, știind că poate da panic.
