# Smart pointers — Avansat

Cum alegi pointerul potrivit, cum eviți copiile inutile cu `Cow` și ce garantează `Pin`.

## Tabel de alegere

| Ai nevoie de | Folosește |
|---|---|
| o valoare pe heap, un singur proprietar | `Box<T>` |
| proprietari multipli, același thread | `Rc<T>` |
| proprietari multipli, mai multe thread-uri | `Arc<T>` |
| modificare prin `&`, același thread | `Cell<T>` / `RefCell<T>` |
| modificare prin `&`, mai multe thread-uri | `Mutex<T>` / `RwLock<T>` / atomice |
| inițializare o singură dată | `OnceCell<T>` / `OnceLock<T>` |
| „împrumut sau dețin”, după caz | `Cow<'a, T>` |
| o valoare care nu se mai mută în memorie | `Pin<Box<T>>` |

## `Rc` vs. `Arc`

`Arc` (*atomically reference counted*) face același lucru ca `Rc`, dar cu operații atomice pe contor, deci e sigur între thread-uri. Costul atomic e mic, dar real. Folosește `Rc` când nu ai nevoie de thread-uri, iar compilatorul îți va spune dacă ai greșit (`Rc` nu e `Send`).

```rust
use std::sync::Arc;
use std::thread;

fn main() {
    let date = Arc::new(vec![1, 2, 3]);
    let mut fire = Vec::new();
    for i in 0..3 {
        let d = Arc::clone(&date);
        fire.push(thread::spawn(move || d[i] * 10));
    }
    let rezultate: Vec<i32> = fire.into_iter().map(|h| h.join().unwrap()).collect();
    println!("{rezultate:?}");
}
```

## `Rc::make_mut` și clone-on-write

`Rc::make_mut` îți dă `&mut T` dacă ești **singurul** proprietar. Dacă nu ești, clonează mai întâi valoarea. Așa obții structuri de date persistente ieftine:

```rust
use std::rc::Rc;

fn main() {
    let original = Rc::new(vec![1, 2, 3]);
    let mut copie = Rc::clone(&original);

    Rc::make_mut(&mut copie).push(4); // există 2 proprietari, deci clonează

    println!("{original:?} {copie:?}");

    let mut unic = Rc::new(vec![9]);
    Rc::make_mut(&mut unic).push(10); // proprietar unic, modifică pe loc
    println!("{unic:?}");
}
```

## `Cow`: împrumută când poți, copiază când trebuie

`Cow<'a, str>` (*clone on write*) poate fi fie un `&'a str` împrumutat, fie un `String` propriu. E ideal pentru funcții care **de obicei** nu modifică datele:

```rust
use std::borrow::Cow;

fn normalizeaza(text: &str) -> Cow<'_, str> {
    if text.contains('\t') {
        Cow::Owned(text.replace('\t', "    ")) // alocare doar dacă e nevoie
    } else {
        Cow::Borrowed(text) // fără alocare
    }
}

fn main() {
    for t in ["fără tab-uri", "cu\ttab"] {
        let n = normalizeaza(t);
        let tip = match n {
            Cow::Borrowed(_) => "împrumutat",
            Cow::Owned(_) => "alocat",
        };
        println!("{n:?} ({tip})");
    }
}
```

## `OnceCell` și `LazyLock`

```rust
use std::cell::OnceCell;
use std::sync::LazyLock;

static TABEL: LazyLock<Vec<u64>> = LazyLock::new(|| {
    (0..10).map(|n| n * n).collect() // calculat la prima folosire
});

struct Raport {
    sumar: OnceCell<String>,
}

impl Raport {
    fn sumar(&self) -> &str {
        self.sumar.get_or_init(|| {
            println!("(calculez sumarul o singură dată)");
            "totul e în regulă".to_string()
        })
    }
}

fn main() {
    println!("{}", TABEL[7]);
    let r = Raport { sumar: OnceCell::new() };
    println!("{}", r.sumar());
    println!("{}", r.sumar());
}
```

## `Pin`: valori care nu se mai mută

Unele valori conțin pointeri **către ele însele** (*self-referential*). Dacă ar fi mutate în memorie, acei pointeri ar deveni invalizi. `Pin<P>` garantează că valoarea spre care arată `P` **nu va mai fi mutată**, cu excepția tipurilor `Unpin`, pentru care mutarea e oricum sigură.

În practică, întâlnești `Pin` aproape numai la **async**: viitorii generați de `async fn` pot fi self-referential, de aceea `Future::poll` primește `Pin<&mut Self>`.

```rust
use std::pin::Pin;

fn main() {
    let viitor = async { 42 };
    let fixat: Pin<Box<_>> = Box::pin(viitor); // pus pe heap și fixat acolo
    println!("{}", std::mem::size_of_val(&fixat)); // doar un pointer
    // pentru majoritatea tipurilor obișnuite (care sunt Unpin), Pin nu restricționează nimic:
    let mut x = 5;
    let p = Pin::new(&mut x);
    *Pin::into_inner(p) += 1;
    println!("{x}");
}
```

> **De reținut:** `Arc` = `Rc` atomic, pentru thread-uri. `make_mut` și `Cow` copiază doar când e nevoie. `OnceCell` și `LazyLock` inițializează leneș. `Pin` garantează că valoarea nu se mai mută și e necesar mai ales la async.
