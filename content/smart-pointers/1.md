# Smart pointers — Fundamente

Un **smart pointer** este un tip care se comportă ca o referință, dar are în plus date și comportament. De obicei **deține** valoarea spre care arată. `String` și `Vec` sunt deja smart pointers. Aici le întâlnești pe cele mai folosite: `Box`, `Rc` și `RefCell`.

## `Box<T>`: o valoare pe heap

`Box::new(x)` mută valoarea `x` pe heap. Pe stivă rămâne doar un pointer. Când `Box`-ul iese din scope, memoria e eliberată automat:

```rust
fn main() {
    let b = Box::new(5);
    println!("b = {b}"); // îl folosești ca pe valoarea însăși
    let suma = *b + 1;   // `*` accesează valoarea
    println!("{suma}");
}
```

## De ce ai nevoie de `Box`: tipuri recursive

Un tip nu se poate conține pe sine direct, pentru că ar avea mărime infinită:

```rust,compile_fail
enum Lista {
    Element(i32, Lista), // eroare E0072: tip recursiv de mărime infinită
    Gol,
}

fn main() {}
```

Cu `Box`, următorul element e doar un pointer, deci tipul are o mărime fixă:

```rust
#[derive(Debug)]
enum Lista {
    Element(i32, Box<Lista>),
    Gol,
}

use Lista::{Element, Gol};

fn main() {
    let lista = Element(1, Box::new(Element(2, Box::new(Element(3, Box::new(Gol))))));
    println!("{lista:?}");
}
```

Același principiu se aplică arborilor: fiecare nod ține copiii într-un `Box` sau într-un `Vec`.

## `Rc<T>`: mai mulți proprietari

Uneori o valoare trebuie să aibă **mai mulți** proprietari. `Rc` (*reference counted*) numără câți proprietari există și eliberează valoarea când ultimul dispare:

```rust
use std::rc::Rc;

fn main() {
    let configuratie = Rc::new(String::from("mod întunecat"));

    let fereastra1 = Rc::clone(&configuratie); // nu copiază string-ul, doar crește contorul
    let fereastra2 = Rc::clone(&configuratie);

    println!("{fereastra1} / {fereastra2}");
    println!("proprietari: {}", Rc::strong_count(&configuratie)); // 3
}
```

`Rc::clone` e ieftin: incrementează un număr. `Rc` permite doar **citire**, iar datele nu pot fi modificate prin el.

## `RefCell<T>`: modificare prin referință partajată

`RefCell` îți permite să modifici o valoare chiar dacă ai doar o referință `&` la ea. Regulile de împrumut sunt verificate **la runtime** în loc de compilare:

```rust
use std::cell::RefCell;

fn main() {
    let jurnal = RefCell::new(Vec::new());

    jurnal.borrow_mut().push("pornit");   // împrumut mutabil
    jurnal.borrow_mut().push("procesat");

    println!("{:?}", jurnal.borrow());     // împrumut partajat
}
```

## `Rc<RefCell<T>>`: partajat și modificabil

Combinația apare frecvent: mai mulți proprietari, oricare dintre ei poate modifica:

```rust
use std::cell::RefCell;
use std::rc::Rc;

fn main() {
    let cos = Rc::new(RefCell::new(Vec::new()));

    let ana = Rc::clone(&cos);
    let mihai = Rc::clone(&cos);

    ana.borrow_mut().push("mere");
    mihai.borrow_mut().push("pâine");

    println!("coș comun: {:?}", cos.borrow());
}
```

> **De reținut:** `Box` pune o valoare pe heap și face posibile tipurile recursive. `Rc` permite mai mulți proprietari, cu acces doar pentru citire. `RefCell` permite modificarea prin `&`, cu verificare la runtime. Pentru date partajate și modificabile folosești `Rc<RefCell<T>>`.
