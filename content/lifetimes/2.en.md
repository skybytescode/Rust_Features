# Lifetimes — Practician

Regulile prin care compilatorul deduce lifetimes, structurile care țin referințe și cum citești erorile frecvente.

## Regulile de elision

Când nu scrii lifetimes în semnătura unei funcții, compilatorul aplică trei reguli:

1. Fiecare referință din parametri primește propriul lifetime.
2. Dacă există **exact un** lifetime de intrare, el se aplică tuturor referințelor returnate.
3. Dacă unul dintre parametri e `&self` sau `&mut self`, lifetime-ul lui se aplică referințelor returnate.

Dacă după aceste reguli rezultatul tot nu are lifetime, trebuie să-l scrii tu.

```rust
struct Document {
    titlu: String,
    continut: String,
}

impl Document {
    // regula 3: rezultatul trăiește cât `self`
    fn titlu(&self) -> &str {
        &self.titlu
    }

    // tot regula 3, chiar dacă există și alt parametru referință
    fn cauta(&self, _cuvant: &str) -> &str {
        &self.continut
    }
}

fn main() {
    let d = Document { titlu: "Raport".into(), continut: "...".into() };
    println!("{} {}", d.titlu(), d.cauta("x"));
}
```

## Structuri care țin referințe

Un struct care conține o referință are nevoie de un parametru de lifetime. Instanța nu poate trăi mai mult decât datele împrumutate:

```rust
struct Parser<'a> {
    text: &'a str,
    poz: usize,
}

impl<'a> Parser<'a> {
    fn new(text: &'a str) -> Self {
        Parser { text, poz: 0 }
    }

    // returnează o bucată din textul original, nu din parser
    fn urmatorul_cuvant(&mut self) -> Option<&'a str> {
        let rest = self.text[self.poz..].trim_start();
        if rest.is_empty() {
            return None;
        }
        let inceput = self.text.len() - rest.len();
        let sfarsit = rest.find(' ').map_or(self.text.len(), |i| inceput + i);
        self.poz = sfarsit;
        Some(&self.text[inceput..sfarsit])
    }
}

fn main() {
    let text = String::from("unu doi trei");
    let mut p = Parser::new(&text);
    let mut cuvinte = Vec::new();
    while let Some(c) = p.urmatorul_cuvant() {
        cuvinte.push(c);
    }
    drop(p); // cuvintele rămân valide: aparțin lui `text`, nu parserului
    println!("{cuvinte:?}");
}
```

Lifetime-ul explicit `'a` din tipul returnat contează: cu `&str` simplu, regula 3 ar lega cuvintele de `&mut self`, iar cât timp ai ține un cuvânt nu ai mai putea apela din nou parserul.

## Referințe sau date proprii?

Structurile cu referințe sunt potrivite pentru obiecte **de scurtă durată**: parsere, iteratori, vederi peste date. Pentru obiecte care trăiesc mult sau trec dintr-o parte în alta a programului, folosește date proprii (`String`, `Vec`). Codul devine mult mai simplu, iar o copie costă de obicei mai puțin decât crezi.

## Erori frecvente

**„borrowed value does not live long enough” (E0597).** Valoarea împrumutată e distrusă înainte de ultima folosire a referinței. Mută declarația valorii mai sus sau returnează date proprii.

**„missing lifetime specifier” (E0106).** O funcție returnează o referință, iar regulile de elision nu pot decide de unde provine. Adaugă `<'a>` și leagă rezultatul de parametrul corect.

**„lifetime may not live long enough”.** Ai promis în semnătură o relație pe care codul nu o respectă:

```rust,compile_fail
fn alege<'a, 'b>(x: &'a str, y: &'b str) -> &'a str {
    if x.is_empty() { y } else { x } // eroare: `y` are lifetime 'b, nu 'a
}

fn main() {
    println!("{}", alege("", "b"));
}
```

## `'static` ca constrângere

`T: 'static` **nu** înseamnă „T trăiește pe toată durata programului”. Înseamnă „T nu conține referințe care ar putea expira”. Un `String` respectă `'static`, chiar dacă e creat la runtime și distrus oricând. `thread::spawn` cere `'static` din acest motiv:

```rust
fn main() {
    let mesaj = String::from("din alt thread");
    let h = std::thread::spawn(move || {
        println!("{mesaj}"); // String: 'static, deoarece e mutat, nu împrumutat
    });
    h.join().unwrap();
}
```

> **De reținut:** trei reguli de elision acoperă majoritatea funcțiilor. Un struct cu referințe are nevoie de `<'a>` și nu poate trăi mai mult decât datele lui. `T: 'static` înseamnă „fără referințe temporare”, nu „trăiește veșnic”.
