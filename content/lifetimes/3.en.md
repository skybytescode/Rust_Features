# Lifetimes — Avansat

Lifetimes sunt tipuri, iar între tipuri există relații de **subtipare**. De aici vin variance, constrângerile `T: 'a`, HRTB și regulile de capturare pentru `impl Trait`.

## Subtipare: un lifetime mai lung poate fi folosit ca unul mai scurt

Dacă `'lung` include `'scurt`, atunci `&'lung T` poate fi folosit oriunde se cere `&'scurt T`. Din acest motiv poți trimite un `&'static str` unei funcții care cere `&'a str`:

```rust
fn mai_lung<'a>(a: &'a str, b: &'a str) -> &'a str {
    if a.len() >= b.len() { a } else { b }
}

fn main() {
    let local = String::from("local");
    let r = mai_lung("static, din binar", &local); // 'static se scurtează la lifetime-ul lui `local`
    println!("{r}");
}
```

## Variance

**Variance** spune cum se propagă subtiparea prin tipuri compuse:

| Tip | Față de `'a` | Față de `T` |
|---|---|---|
| `&'a T` | covariant | covariant |
| `&'a mut T` | covariant | **invariant** |
| `Box<T>`, `Vec<T>` | — | covariant |
| `Cell<T>`, `RefCell<T>` | — | **invariant** |
| `fn(T) -> U` | — | **contravariant** în `T`, covariant în `U` |

De ce e `&mut T` invariant în `T`? Dacă ar fi covariant, ai putea strecura o referință scurtă într-un loc care promite una lungă:

```rust,compile_fail
fn adauga<'a>(v: &mut Vec<&'a str>, s: &'a str) {
    v.push(s);
}

fn main() {
    let mut permanente: Vec<&'static str> = vec!["unu"];
    {
        let temporar = String::from("doi");
        adauga(&mut permanente, &temporar); // eroare: `temporar` ar trebui să fie 'static
    }
    println!("{permanente:?}"); // altfel, aici am citi memorie eliberată
}
```

## Constrângeri `T: 'a`

`T: 'a` înseamnă „toate referințele din interiorul lui `T` trăiesc cel puțin cât `'a`”. Un struct care ține `&'a T` o cere implicit: compilatorul o deduce și n-o mai scrii.

```rust
struct Referinta<'a, T> {
    valoare: &'a T, // implică T: 'a
}

fn construieste<'a, T: std::fmt::Debug>(x: &'a T) -> Referinta<'a, T> {
    Referinta { valoare: x }
}

fn main() {
    let n = vec![1, 2];
    println!("{:?}", construieste(&n).valoare);
}
```

## Higher-ranked trait bounds: `for<'a>`

Uneori o funcție primește un closure care trebuie să meargă pentru **orice** lifetime, nu pentru unul anume ales de apelant. Sintaxa este `for<'a>`:

```rust
fn aplica_pe_toate<F>(texte: &[String], f: F) -> Vec<usize>
where
    F: for<'a> Fn(&'a str) -> &'a str, // pentru orice 'a
{
    texte.iter().map(|t| f(t).len()).collect()
}

fn main() {
    let texte = vec!["  rust  ".to_string(), " e  ".to_string()];
    println!("{:?}", aplica_pe_toate(&texte, str::trim));
}
```

`Fn(&str) -> &str` este de fapt o prescurtare pentru `for<'a> Fn(&'a str) -> &'a str`. Regulile de elision se aplică și aici.

## `impl Trait` și capturarea lifetimes (ediția 2024)

Un tip returnat `impl Trait` poate folosi parametrii generici ai funcției. Întrebarea este pe care îi **capturează**. În ediția 2024, implicit îi capturează pe **toți** parametrii din scope, inclusiv lifetimes. Asta e aproape întotdeauna ce vrei:

```rust
fn cuvinte_lungi(text: &str, minim: usize) -> impl Iterator<Item = &str> {
    // iteratorul împrumută `text`; în 2024 e capturat automat
    text.split_whitespace().filter(move |c| c.len() >= minim)
}

fn main() {
    let t = String::from("un exemplu de iterator lung");
    println!("{:?}", cuvinte_lungi(&t, 4).collect::<Vec<_>>());
}
```

Când vrei să capturezi **mai puțin**, de exemplu ca rezultatul să nu depindă de un argument împrumutat, folosești `use<...>` (*precise capturing*, Rust 1.82):

```rust
fn lungimi<'a>(texte: &'a [String]) -> impl Iterator<Item = usize> + use<> {
    let l: Vec<usize> = texte.iter().map(|t| t.len()).collect();
    l.into_iter() // nu mai împrumută `texte`
}

fn main() {
    let mut texte = vec!["ab".to_string(), "cde".to_string()];
    let it = lungimi(&texte);
    texte.clear(); // permis: `it` nu capturează împrumutul
    println!("{:?}", it.collect::<Vec<_>>());
}
```

## Extinderea duratei temporarelor

Un temporar al cărui împrumut e legat direct printr-un `let` trăiește până la sfârșitul blocului, nu doar până la `;`:

```rust
fn main() {
    let s = &String::from("temporar extins"); // temporarul trăiește cât `s`
    let t = &[1, 2, 3].map(|x| x * 2);         // la fel
    println!("{s} {t:?}");
}
```

Extinderea are loc doar în anumite forme sintactice (`&expr`, struct-uri și tupluri cu `&expr`, blocuri). Nu se aplică argumentelor de funcții: `let x = f(&String::new());` nu extinde temporarul.

> **De reținut:** lifetimes au subtipare. `&mut T` și `Cell<T>` sunt invariante ca să nu permită strecurarea referințelor scurte. `for<'a>` cere „pentru orice lifetime”. `impl Trait` capturează totul în 2024, iar `use<>` restrânge capturarea.
