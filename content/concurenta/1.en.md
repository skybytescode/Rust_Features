# Concurrency — Fundamentals

Concurrency means doing several things at the same time. The most direct way in Rust is **threads**: threads of execution that run in parallel, on different cores of the processor.

## Starting a thread

`std::thread::spawn` starts a new thread that runs the closure it receives:

```rust
use std::thread;
use std::time::Duration;

fn main() {
    let worker = thread::spawn(|| {
        for i in 1..=3 {
            println!("  secondary thread: step {i}");
            thread::sleep(Duration::from_millis(10));
        }
    });

    for i in 1..=3 {
        println!("main thread: step {i}");
        thread::sleep(Duration::from_millis(10));
    }

    worker.join().unwrap(); // waits for the secondary thread to finish
}
```

The order of the messages can differ from one run to the next: the operating system decides who runs and when.

## `join`: wait for the result

`spawn` returns a *handle*. With `join()` you wait for the thread to finish and get the value it returned:

```rust
use std::thread;

fn main() {
    let computation = thread::spawn(|| (1..=100u64).sum::<u64>());
    let result = computation.join().unwrap();
    println!("sum: {result}");
}
```

If `main` finishes, the program stops, even if other threads are still running. Use `join` to wait for them.

## `move`: the data goes into the thread

A thread can outlive the function that started it, so it can't borrow local variables. With `move`, you give it ownership:

```rust
use std::thread;

fn main() {
    let names = vec!["Ana", "Mike", "Joan"];
    let worker = thread::spawn(move || {
        println!("got {} names", names.len());
    });
    worker.join().unwrap();
    // `names` can no longer be used here: it was moved into the thread
}
```

Without `move`, the compiler warns you:

```rust,compile_fail
use std::thread;

fn main() {
    let v = vec![1, 2, 3];
    let worker = thread::spawn(|| {
        println!("{v:?}"); // error E0373: the closure may outlive `v`
    });
    worker.join().unwrap();
}
```

## Communicating through channels

A **channel** sends messages from one thread to another. It has a sending end (`tx`) and a receiving end (`rx`):

```rust
use std::sync::mpsc;
use std::thread;

fn main() {
    let (tx, rx) = mpsc::channel();

    thread::spawn(move || {
        for message in ["hello", "from", "a thread"] {
            tx.send(message).unwrap();
        }
    });

    for received in rx { // stops when the thread finishes and `tx` is destroyed
        println!("received: {received}");
    }
}
```

## Several producers

`mpsc` means *multiple producers, single consumer*. You clone the sending end for each thread:

```rust
use std::sync::mpsc;
use std::thread;

fn main() {
    let (tx, rx) = mpsc::channel();
    for id in 0..3 {
        let tx = tx.clone();
        thread::spawn(move || {
            tx.send(format!("worker {id} is done")).unwrap();
        });
    }
    drop(tx); // close the original, so the loop below stops

    let mut messages: Vec<String> = rx.iter().collect();
    messages.sort();
    for m in messages {
        println!("{m}");
    }
}
```

> **Key takeaway:** `thread::spawn` starts a thread, and `join` waits for it and gets its result. `move` moves data into the thread. `mpsc` channels send messages between threads.
