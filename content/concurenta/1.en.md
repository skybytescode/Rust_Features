# Concurență — Fundamente

Concurența înseamnă să faci mai multe lucruri în același timp. Cea mai directă cale în Rust sunt **thread-urile**: fire de execuție care rulează în paralel, pe nuclee diferite ale procesorului.

## Pornirea unui thread

`std::thread::spawn` pornește un thread nou care rulează closure-ul primit:

```rust
use std::thread;
use std::time::Duration;

fn main() {
    let fir = thread::spawn(|| {
        for i in 1..=3 {
            println!("  thread secundar: pasul {i}");
            thread::sleep(Duration::from_millis(10));
        }
    });

    for i in 1..=3 {
        println!("thread principal: pasul {i}");
        thread::sleep(Duration::from_millis(10));
    }

    fir.join().unwrap(); // așteaptă să termine thread-ul secundar
}
```

Ordinea mesajelor poate diferi de la o rulare la alta: sistemul de operare decide cine rulează și când.

## `join`: așteaptă rezultatul

`spawn` returnează un *handle*. Cu `join()` aștepți ca thread-ul să termine și primești valoarea returnată de el:

```rust
use std::thread;

fn main() {
    let calcul = thread::spawn(|| (1..=100u64).sum::<u64>());
    let rezultat = calcul.join().unwrap();
    println!("suma: {rezultat}");
}
```

Dacă `main` se termină, programul se oprește, chiar dacă alte thread-uri încă rulează. Folosește `join` ca să le aștepți.

## `move`: datele trec în thread

Un thread poate trăi mai mult decât funcția care l-a pornit, așa că nu poate împrumuta variabile locale. Cu `move`, îi dai ownership-ul:

```rust
use std::thread;

fn main() {
    let nume = vec!["Ana", "Mihai", "Ioana"];
    let fir = thread::spawn(move || {
        println!("am primit {} nume", nume.len());
    });
    fir.join().unwrap();
    // `nume` nu mai poate fi folosit aici: a fost mutat în thread
}
```

Fără `move`, compilatorul te avertizează:

```rust,compile_fail
use std::thread;

fn main() {
    let v = vec![1, 2, 3];
    let fir = thread::spawn(|| {
        println!("{v:?}"); // eroare E0373: closure-ul ar putea trăi mai mult decât `v`
    });
    fir.join().unwrap();
}
```

## Comunicare prin canale

Un **canal** trimite mesaje de la un thread la altul. Are un capăt de trimitere (`tx`) și unul de primire (`rx`):

```rust
use std::sync::mpsc;
use std::thread;

fn main() {
    let (tx, rx) = mpsc::channel();

    thread::spawn(move || {
        for mesaj in ["salut", "din", "thread"] {
            tx.send(mesaj).unwrap();
        }
    });

    for primit in rx { // se oprește când thread-ul termină și `tx` e distrus
        println!("primit: {primit}");
    }
}
```

## Mai mulți producători

`mpsc` înseamnă *multiple producers, single consumer*. Clonezi capătul de trimitere pentru fiecare thread:

```rust
use std::sync::mpsc;
use std::thread;

fn main() {
    let (tx, rx) = mpsc::channel();
    for id in 0..3 {
        let tx = tx.clone();
        thread::spawn(move || {
            tx.send(format!("lucrătorul {id} a terminat")).unwrap();
        });
    }
    drop(tx); // închidem originalul, ca bucla de mai jos să se oprească

    let mut mesaje: Vec<String> = rx.iter().collect();
    mesaje.sort();
    for m in mesaje {
        println!("{m}");
    }
}
```

> **De reținut:** `thread::spawn` pornește un thread, iar `join` îl așteaptă și îi primește rezultatul. `move` mută datele în thread. Canalele `mpsc` trimit mesaje între thread-uri.
