# Rust la nivel jos — Fundamente

Rust nu rulează doar pe calculatoare cu sistem de operare. Același limbaj e folosit pe microcontrolere de câțiva kilobytes, în nucleul Linux, în bootloadere și în browser, prin WebAssembly. Diferența o face cât din biblioteca standard îți permiți.

## Cele trei straturi ale bibliotecii standard

| Strat | Conține | Are nevoie de |
|---|---|---|
| `core` | tipuri primitive, `Option`, `Result`, iteratori, trait-uri, `mem`, `ptr`, atomice | nimic: merge oriunde |
| `alloc` | `Box`, `Vec`, `String`, `Rc`, `BTreeMap` | un alocator de memorie |
| `std` | fișiere, rețea, thread-uri, timp, `HashMap`, `println!` | un sistem de operare |

`std` reexportă tot ce e în `core` și în `alloc`. De aceea `std::mem::size_of` și `core::mem::size_of` sunt aceeași funcție:

```rust
fn main() {
    // aceleași elemente, accesate prin straturi diferite
    let a = core::mem::size_of::<u64>();
    let b = std::mem::size_of::<u64>();
    let maxim = core::cmp::max(3, 7);
    let optiune: core::option::Option<i32> = Some(1);
    println!("{a} {b} {maxim} {optiune:?}");
}
```

## Ce înseamnă `no_std`

Un crate marcat `#![no_std]` folosește doar `core` (și, opțional, `alloc`). Nu poate deschide fișiere și nu are `println!`, dar poate rula pe hardware fără sistem de operare. Multe biblioteci populare (`serde`, `hashbrown`, `heapless`) au variante `no_std`, ca să poată fi folosite și în embedded.

Codul care folosește doar `core` merge identic oriunde:

```rust
// Doar elemente din `core`: ar compila și într-un crate #![no_std]
fn crc8(date: &[u8]) -> u8 {
    let mut crc = 0u8;
    for &octet in date {
        crc ^= octet;
        for _ in 0..8 {
            crc = if crc & 0x80 != 0 { (crc << 1) ^ 0x07 } else { crc << 1 };
        }
    }
    crc
}

fn main() {
    println!("{:#04x}", crc8(b"123456789"));
}
```

## Ținte de compilare (*targets*)

Compilatorul Rust poate genera cod pentru zeci de platforme. Fiecare e identificată de un **target triple**:

| Target | Pentru |
|---|---|
| `x86_64-unknown-linux-gnu` | Linux pe PC |
| `aarch64-apple-darwin` | Mac cu procesor Apple |
| `x86_64-pc-windows-msvc` | Windows |
| `thumbv7em-none-eabihf` | microcontrolere ARM Cortex-M4/M7, fără sistem de operare |
| `riscv32imac-unknown-none-elf` | microcontrolere RISC-V |
| `wasm32-unknown-unknown` | WebAssembly în browser |

`none` din nume înseamnă „fără sistem de operare”: acolo merge doar `no_std`.

```bash
rustup target list --installed          # ce ținte ai instalate
rustup target add wasm32-unknown-unknown
cargo build --target wasm32-unknown-unknown
```

## Unde întâlnești Rust la nivel jos

- **WebAssembly**: chiar acest site e scris în Rust și compilat în WebAssembly (`wasm32-unknown-unknown`), cu framework-ul Leptos;
- **embedded**: microcontrolere ARM și RISC-V, cu ecosistemul `embedded-hal`, `embassy` și `probe-rs`;
- **nuclee de sisteme de operare**: Linux acceptă drivere scrise în Rust, iar proiecte ca Redox și Asterinas sunt scrise integral în Rust;
- **firmware și bootloadere**, unde controlul total asupra memoriei e obligatoriu.

> **De reținut:** biblioteca standard are trei straturi: `core` (oriunde), `alloc` (cu alocator) și `std` (cu sistem de operare). `#![no_std]` înseamnă doar `core` și, opțional, `alloc`. Un *target triple* alege platforma, iar `none` în nume înseamnă fără sistem de operare.
