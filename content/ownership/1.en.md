# Ownership and borrowing — Fundamentals

Rust manages memory without a garbage collector and without manual `free`. Ownership makes that possible: a set of rules the compiler checks before the program runs.

## The three rules

1. Every value has an **owner**: the variable that holds it.
2. A value has **exactly one owner** at a time.
3. When the owner goes out of scope, the value is **freed** automatically.

```rust
fn main() {
    {
        let s = String::from("hello"); // `s` becomes the owner of the string
        println!("{s}");
    } // here `s` goes out of scope and the memory is freed
}
```

## Move: the owner changes

When you assign a `String` to another variable, ownership **moves**. The old variable can no longer be used.

```rust,compile_fail
fn main() {
    let a = String::from("hello");
    let b = a; // ownership moves from `a` to `b`
    println!("{a}"); // error: `a` has been moved
}
```

The compiler objects because if both `a` and `b` owned the same string, both would try to free it at the end.

## Clone: an explicit copy

If you need two independent values, ask for a copy with `.clone()`:

```rust
fn main() {
    let a = String::from("hello");
    let b = a.clone(); // new data, allocated separately
    println!("{a} and {b}");
}
```

## Copy: simple types copy themselves

Numbers, `bool`, `char` and other small types stored entirely on the stack are copied automatically. They don't move.

```rust
fn main() {
    let x = 5;
    let y = x; // a copy, `x` stays valid
    println!("{x} and {y}");
}
```

## Functions take ownership

When you pass a `String` to a function, ownership moves to the function's parameter:

```rust
fn print(text: String) {
    println!("{text}");
} // `text` is freed here

fn main() {
    let message = String::from("hello");
    print(message);
    // `message` can no longer be used here
}
```

For a function to *use* a value without *taking* it, you give it a reference. That's called **borrowing**, and it is the subject of the next level.

> **Key takeaway:** a value has a single owner. Assignment and function calls move ownership, except for `Copy` types. `.clone()` makes an explicit copy.
