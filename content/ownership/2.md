# Ownership și borrowing — Practician

În codul real nu muți și nu clonezi valori peste tot. De cele mai multe ori le **împrumuți** prin referințe.

## Referințe: `&T` și `&mut T`

O referință îți dă acces la o valoare fără să preiei ownership-ul.

```rust
fn lungime(text: &String) -> usize {
    text.len()
}

fn adauga_semn(text: &mut String) {
    text.push('!');
}

fn main() {
    let mut s = String::from("salut");
    adauga_semn(&mut s);
    println!("{s} are {} caractere", lungime(&s));
}
```

## Regula de aur a borrowing-ului

La un moment dat poți avea **ori**:

- oricâte referințe **partajate** (`&T`), **ori**
- **o singură** referință **mutabilă** (`&mut T`).

Nu le poți avea pe amândouă în același timp. Regula asta elimină la compilare o întreagă clasă de bug-uri: data races, iteratori invalidați, modificări „pe la spate”.

```rust,compile_fail
fn main() {
    let mut v = vec![1, 2, 3];
    let primul = &v[0];   // împrumut partajat
    v.push(4);            // eroare E0502: împrumut mutabil cât timp `primul` e activ
    println!("{primul}");
}
```

Eroarea nu e o pedanterie: `push` poate realoca vectorul, iar `primul` ar ajunge să indice spre memorie eliberată.

## Parametri idiomatici: `&str` în loc de `&String`

O funcție care doar citește text ar trebui să primească `&str`. Așa acceptă și `String`, și literali:

```rust
fn saluta(nume: &str) {
    println!("Salut, {nume}!");
}

fn main() {
    let owned = String::from("Ana");
    saluta(&owned);  // &String se convertește automat în &str
    saluta("Mihai"); // literalul este deja &str
}
```

Același principiu se aplică la `&[T]` în loc de `&Vec<T>`.

## Cum alegi tipul parametrului

| Funcția trebuie să… | Folosește |
|---|---|
| doar citească valoarea | `&T` / `&str` / `&[T]` |
| modifice valoarea | `&mut T` |
| o păstreze (de ex. într-un struct) | `T`, prin ownership |

## Erori frecvente și cum le rezolvi

**E0382: folosire după move.** De obicei ai trimis prin valoare ceva ce voiai doar să împrumuți. Schimbă parametrul în `&T` înainte să adaugi un `.clone()`.

**E0502 / E0499: împrumuturi suprapuse.** Restrânge durata împrumutului: citește valoarea de care ai nevoie într-o variabilă, apoi modifică.

```rust
fn main() {
    let mut v = vec![1, 2, 3];
    let primul = v[0]; // copie a lui i32, nu referință
    v.push(primul * 10);
    println!("{v:?}");
}
```

**E0106 / E0515: întorci o referință la o variabilă locală.** Valoarea locală dispare la ieșirea din funcție, deci întoarce valoarea însăși:

```rust,compile_fail
fn creeaza() -> &String {
    let s = String::from("salut");
    &s // `s` este eliberat la finalul funcției
}

fn main() {
    creeaza();
}
```

```rust
fn creeaza() -> String {
    String::from("salut") // ownership-ul trece la apelant
}

fn main() {
    println!("{}", creeaza());
}
```

> **De reținut:** împrumută implicit, mută doar când funcția trebuie să păstreze valoarea și clonează doar când ai cu adevărat nevoie de două copii.
