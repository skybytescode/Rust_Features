# Ownership și borrowing — Fundamente

Rust gestionează memoria fără garbage collector și fără `free` manual. Ownership-ul face asta posibil: un set de reguli pe care compilatorul le verifică înainte ca programul să ruleze.

## Cele trei reguli

1. Fiecare valoare are un **owner** (proprietar): variabila care o deține.
2. O valoare are **un singur owner** la un moment dat.
3. Când owner-ul iese din scope, valoarea este **eliberată** automat.

```rust
fn main() {
    {
        let s = String::from("salut"); // `s` devine owner-ul string-ului
        println!("{s}");
    } // aici `s` iese din scope și memoria e eliberată
}
```

## Move: owner-ul se schimbă

Când atribui un `String` altei variabile, ownership-ul **se mută**. Variabila veche nu mai poate fi folosită.

```rust,compile_fail
fn main() {
    let a = String::from("salut");
    let b = a; // ownership-ul trece de la `a` la `b`
    println!("{a}"); // eroare: `a` a fost mutat
}
```

Compilatorul se opune pentru că, dacă și `a`, și `b` ar deține același string, amândouă ar încerca să-l elibereze la final.

## Clone: o copie explicită

Dacă ai nevoie de două valori independente, cere o copie cu `.clone()`:

```rust
fn main() {
    let a = String::from("salut");
    let b = a.clone(); // date noi, alocate separat
    println!("{a} și {b}");
}
```

## Copy: tipurile simple se copiază singure

Numerele, `bool`, `char` și alte tipuri mici, stocate în întregime pe stivă, se copiază automat. Pentru ele nu există move.

```rust
fn main() {
    let x = 5;
    let y = x; // copie, `x` rămâne valid
    println!("{x} și {y}");
}
```

## Funcțiile preiau ownership-ul

Când trimiți un `String` unei funcții, ownership-ul trece la parametrul funcției:

```rust
fn afiseaza(text: String) {
    println!("{text}");
} // `text` este eliberat aici

fn main() {
    let mesaj = String::from("salut");
    afiseaza(mesaj);
    // `mesaj` nu mai poate fi folosit aici
}
```

Ca funcția să *folosească* valoarea fără să o *preia*, îi dai o referință. Asta se numește **borrowing** și este subiectul nivelului următor.

> **De reținut:** o valoare are un singur owner. Atribuirea și apelul de funcție mută ownership-ul, cu excepția tipurilor `Copy`. `.clone()` face o copie explicită.
