# Module și Cargo — Fundamente

Pe măsură ce un program crește, îl împarți în **module**. **Cargo** este unealta care creează, compilează și rulează proiectele Rust și le gestionează dependențele.

## Primul proiect cu Cargo

```bash
cargo new salut     # creează un proiect nou
cd salut
cargo run           # compilează și rulează
```

Cargo creează următoarea structură:

```text
salut/
├── Cargo.toml      # descrierea proiectului și dependențele
└── src/
    └── main.rs     # punctul de pornire
```

## Comenzile de bază

| Comandă | Ce face |
|---|---|
| `cargo build` | compilează (în `target/debug`) |
| `cargo build --release` | compilează optimizat (în `target/release`) |
| `cargo run` | compilează și rulează |
| `cargo check` | verifică erorile, fără să genereze binar; e foarte rapid |
| `cargo test` | rulează testele |
| `cargo doc --open` | generează documentația și o deschide |
| `cargo fmt` | formatează codul |
| `cargo clippy` | sugestii de îmbunătățire a codului |

## Dependențe

Ca să folosești o bibliotecă (în Rust, *crate*) de pe [crates.io](https://crates.io), o adaugi în `Cargo.toml`:

```toml
[package]
name = "salut"
version = "0.1.0"
edition = "2024"

[dependencies]
rand = "0.9"
```

Sau direct din terminal:

```bash
cargo add rand
```

La următorul `cargo build`, Cargo descarcă și compilează automat biblioteca.

## Module: împarte codul

Un modul grupează funcții, structuri și alte elemente sub un nume. Tot ce e într-un modul este **privat** implicit. Cu `pub` faci elementul vizibil din afară:

```rust
mod geometrie {
    pub fn aria_cerc(raza: f64) -> f64 {
        PI * raza * raza
    }

    const PI: f64 = 3.14159; // privat: vizibil doar în `geometrie`
}

fn main() {
    println!("{:.2}", geometrie::aria_cerc(2.0));
    // geometrie::PI; // eroare: constanta e privată
}
```

## `use`: scurtează căile

```rust
mod magazin {
    pub mod produse {
        pub fn pret(nume: &str) -> u32 {
            if nume == "pâine" { 5 } else { 10 }
        }
    }
}

use magazin::produse;
use magazin::produse::pret;

fn main() {
    println!("{}", produse::pret("lapte"));
    println!("{}", pret("pâine"));
}
```

Pentru tipuri, convenția este să importi tipul însuși (`use std::collections::HashMap;`). Pentru funcții, imporți modulul părinte (`use magazin::produse;`), ca la apel să fie clar de unde vine funcția.

## Module în fișiere separate

Când un modul devine mare, îl muți în propriul fișier. În `main.rs` scrii doar `mod nume;`, iar Rust caută codul în `nume.rs`:

```text
src/
├── main.rs         // conține: mod geometrie;
└── geometrie.rs    // conține: pub fn aria_cerc(...) { ... }
```

```rust,ignore
// src/main.rs
mod geometrie;

fn main() {
    println!("{}", geometrie::aria_cerc(1.0));
}
```

> **De reținut:** `cargo new`, `run`, `build`, `check` și `test` acoperă munca de zi cu zi. Dependențele se adaugă în `Cargo.toml`. Modulele sunt private implicit, `pub` le deschide, iar `use` scurtează căile.
