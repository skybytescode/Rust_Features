# Modules and Cargo — Fundamentals

As a program grows, you split it into **modules**. **Cargo** is the tool that creates, builds and runs Rust projects and manages their dependencies.

## Your first project with Cargo

```bash
cargo new hello     # creates a new project
cd hello
cargo run           # builds and runs
```

Cargo creates the following structure:

```text
hello/
├── Cargo.toml      # the project description and dependencies
└── src/
    └── main.rs     # the starting point
```

## The basic commands

| Command | What it does |
|---|---|
| `cargo build` | builds (into `target/debug`) |
| `cargo build --release` | builds with optimizations (into `target/release`) |
| `cargo run` | builds and runs |
| `cargo check` | checks for errors without producing a binary; very fast |
| `cargo test` | runs the tests |
| `cargo doc --open` | generates the documentation and opens it |
| `cargo fmt` | formats the code |
| `cargo clippy` | suggestions for improving the code |

## Dependencies

To use a library (in Rust, a *crate*) from [crates.io](https://crates.io), you add it to `Cargo.toml`:

```toml
[package]
name = "hello"
version = "0.1.0"
edition = "2024"

[dependencies]
rand = "0.9"
```

Or directly from the terminal:

```bash
cargo add rand
```

On the next `cargo build`, Cargo downloads and builds the library automatically.

## Modules: split up your code

A module groups functions, structs and other items under a name. Everything in a module is **private** by default. With `pub` you make an item visible from outside:

```rust
mod geometry {
    pub fn circle_area(radius: f64) -> f64 {
        PI * radius * radius
    }

    const PI: f64 = 3.14159; // private: visible only in `geometry`
}

fn main() {
    println!("{:.2}", geometry::circle_area(2.0));
    // geometry::PI; // error: the constant is private
}
```

## `use`: shorten paths

```rust
mod shop {
    pub mod products {
        pub fn price(name: &str) -> u32 {
            if name == "bread" { 5 } else { 10 }
        }
    }
}

use shop::products;
use shop::products::price;

fn main() {
    println!("{}", products::price("milk"));
    println!("{}", price("bread"));
}
```

For types, the convention is to import the type itself (`use std::collections::HashMap;`). For functions, you import the parent module (`use shop::products;`), so at the call site it's clear where the function comes from.

## Modules in separate files

When a module gets big, you move it into its own file. In `main.rs` you write only `mod name;`, and Rust looks for the code in `name.rs`:

```text
src/
├── main.rs         // contains: mod geometry;
└── geometry.rs     // contains: pub fn circle_area(...) { ... }
```

```rust,ignore
// src/main.rs
mod geometry;

fn main() {
    println!("{}", geometry::circle_area(1.0));
}
```

> **Key takeaway:** `cargo new`, `run`, `build`, `check` and `test` cover day-to-day work. Dependencies go in `Cargo.toml`. Modules are private by default, `pub` opens them up, and `use` shortens paths.
