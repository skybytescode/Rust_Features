# I/O și sistem — Avansat

Pornirea altor programe, cod generic peste orice sursă sau destinație de octeți, performanța stdout și testarea codului de I/O fără fișiere reale.

## Pornirea altor procese

`std::process::Command` pornește un program extern și îi controlează argumentele, mediul și fluxurile:

```rust
use std::process::Command;

fn main() -> std::io::Result<()> {
    // Rulează și așteaptă rezultatul complet
    let iesire = Command::new("echo").arg("salut").arg("din copil").output()?;
    println!("cod: {}", iesire.status);
    println!("stdout: {}", String::from_utf8_lossy(&iesire.stdout).trim());

    // Doar codul de ieșire; fluxurile sunt moștenite de la părinte
    let status = Command::new("sh").args(["-c", "exit 3"]).status()?;
    println!("a reușit? {} (cod {:?})", status.success(), status.code());
    Ok(())
}
```

Argumentele se transmit separat, nu printr-un shell. `Command::new("ls").arg("fișier cu spații")` e sigur, fără probleme de escaping. Shell-ul (`sh -c`) intră în joc doar dacă îl chemi explicit.

## Comunicare prin pipe-uri

```rust
use std::io::Write;
use std::process::{Command, Stdio};

fn main() -> std::io::Result<()> {
    let mut copil = Command::new("sort")
        .stdin(Stdio::piped())
        .stdout(Stdio::piped())
        .spawn()?;

    {
        let mut intrare = copil.stdin.take().unwrap();
        intrare.write_all(b"pere\nmere\nkiwi\n")?;
    } // stdin e închis aici: `sort` află că intrarea s-a terminat

    let iesire = copil.wait_with_output()?;
    print!("{}", String::from_utf8_lossy(&iesire.stdout));
    Ok(())
}
```

Dacă nu închizi stdin-ul copilului, programe ca `sort` așteaptă la nesfârșit restul intrării, iar al tău așteaptă după ele.

## Cod generic peste `Read` și `Write`

O funcție care primește `impl Read` sau `impl Write` merge cu fișiere, socket-uri, stdout, buffere din memorie sau date comprimate:

```rust
use std::io::{self, BufRead, BufReader, Read, Write};

fn numara_cuvinte(sursa: impl Read) -> io::Result<usize> {
    let mut total = 0;
    for linie in BufReader::new(sursa).lines() {
        total += linie?.split_whitespace().count();
    }
    Ok(total)
}

fn scrie_raport(dest: &mut impl Write, cuvinte: usize) -> io::Result<()> {
    writeln!(dest, "cuvinte: {cuvinte}")
}

fn main() -> io::Result<()> {
    // `&[u8]` implementează Read: perfect pentru teste
    let n = numara_cuvinte("unu doi\ntrei patru cinci".as_bytes())?;

    // `Vec<u8>` implementează Write
    let mut buffer = Vec::new();
    scrie_raport(&mut buffer, n)?;
    print!("{}", String::from_utf8_lossy(&buffer));

    // aceeași funcție, direct pe stdout
    scrie_raport(&mut io::stdout(), n)
}
```

## `Cursor` și `Seek`

`io::Cursor` învelește un buffer din memorie și adaugă o poziție curentă. Așa poți testa cod care folosește `Seek`, ca la un fișier:

```rust
use std::io::{Cursor, Read, Seek, SeekFrom, Write};

fn main() -> std::io::Result<()> {
    let mut c = Cursor::new(Vec::new());
    c.write_all(b"antet:DATE-UTILE")?;

    c.seek(SeekFrom::Start(6))?;          // sare peste "antet:"
    let mut rest = String::new();
    c.read_to_string(&mut rest)?;
    println!("{rest}");

    c.seek(SeekFrom::End(-5))?;           // ultimii 5 octeți
    let mut coada = [0u8; 5];
    c.read_exact(&mut coada)?;
    println!("{}", String::from_utf8_lossy(&coada));
    Ok(())
}
```

## Performanța stdout

`println!` blochează `stdout` la fiecare apel, iar `stdout` e golit la fiecare newline. Pentru mii de linii, diferența se simte. Ia lacătul o singură dată și pune un buffer mare:

```rust
use std::io::{self, BufWriter, Write};

fn main() -> io::Result<()> {
    let stdout = io::stdout();
    let mut out = BufWriter::new(stdout.lock()); // un lacăt, un buffer mare
    for i in 0..5 {
        writeln!(out, "linia {i}")?;
    }
    out.flush()
}
```

## Fișiere temporare și curățenie

Crate-ul `tempfile` creează fișiere și directoare temporare cu nume unice, șterse automat la `drop`. Este standardul în teste. Fără el, poți construi un nume unic din `std::process::id()` și din timpul curent, ca în exemplul de mai jos:

```rust
use std::time::{SystemTime, UNIX_EPOCH};

fn main() {
    let unic = SystemTime::now().duration_since(UNIX_EPOCH).unwrap().as_nanos();
    let cale = std::env::temp_dir().join(format!("test_{}_{unic}.tmp", std::process::id()));
    std::fs::write(&cale, "date").unwrap();
    println!("{}", std::fs::read_to_string(&cale).unwrap());
    std::fs::remove_file(&cale).unwrap();
}
```

> **De reținut:** `Command` pornește procese, cu argumentele transmise separat, fără shell. Închide stdin-ul copilului când ai terminat de scris. Scrie funcții peste `impl Read` / `impl Write` și testează-le cu `&[u8]`, `Vec<u8>` și `Cursor`. Pentru output mare, blochează `stdout` o dată și pune un `BufWriter`.
