# I/O și sistem — Fundamente

Un program util comunică cu lumea: citește de la tastatură, primește argumente, citește și scrie fișiere și raportează dacă a reușit. Toate acestea sunt în biblioteca standard.

## Afișare: stdout și stderr

```rust
fn main() {
    println!("rezultatul normal");           // stdout: ieșirea programului
    eprintln!("un mesaj de diagnostic");     // stderr: erori și jurnale
    print!("fără newline, ");
    println!("apoi cu newline");
}
```

Separarea contează: `program > rezultat.txt` redirecționează doar stdout, iar mesajele de pe stderr rămân vizibile în terminal.

## Citirea unei linii de la tastatură

```rust
use std::io;

fn main() {
    println!("Cum te cheamă?");
    let mut nume = String::new();
    io::stdin().read_line(&mut nume).expect("citirea a eșuat");

    let nume = nume.trim(); // elimină newline-ul de la final
    if nume.is_empty() {
        println!("Salut, necunoscutule!");
    } else {
        println!("Salut, {nume}!");
    }
}
```

`read_line` **adaugă** la string, inclusiv caracterul `\n`. De aceea se folosește aproape întotdeauna cu `trim()`.

## Argumente din linia de comandă

```rust
use std::env;

fn main() {
    let args: Vec<String> = env::args().collect();
    println!("programul: {}", args[0]);
    println!("argumente: {:?}", &args[1..]);

    match args.get(1) {
        Some(primul) => println!("primul argument: {primul}"),
        None => println!("rulează cu: program <nume>"),
    }
}
```

Primul element e întotdeauna numele programului. Pentru aplicații reale, crate-ul `clap` interpretează argumentele (opțiuni, `--help`, validare).

## Scrierea și citirea unui fișier

```rust
use std::fs;

fn main() {
    let cale = std::env::temp_dir().join("rust_features_exemplu.txt");

    fs::write(&cale, "prima linie\na doua linie\n").expect("nu pot scrie");
    let continut = fs::read_to_string(&cale).expect("nu pot citi");

    println!("{} octeți citiți", continut.len());
    for linie in continut.lines() {
        println!("> {linie}");
    }

    fs::remove_file(&cale).unwrap();
}
```

`fs::write` creează fișierul sau îl **suprascrie** dacă există. `fs::read_to_string` citește tot fișierul într-un `String`.

## Erorile de I/O sunt normale

Un fișier poate lipsi, iar un disc se poate umple. Operațiile de I/O returnează `Result`, iar codul bun le tratează:

```rust
use std::fs;

fn main() {
    match fs::read_to_string("/fisier/care/nu/exista.txt") {
        Ok(text) => println!("{text}"),
        Err(e) => println!("eroare: {e}"),
    }
}
```

## Codul de ieșire

Programele raportează succesul sau eșecul printr-un **cod de ieșire**: 0 înseamnă succes, orice altă valoare înseamnă eșec. Scripturile și sistemele de CI se bazează pe el:

```rust
use std::process::ExitCode;

fn main() -> ExitCode {
    let configuratie_valida = true;
    if configuratie_valida {
        println!("totul e în regulă");
        ExitCode::SUCCESS
    } else {
        eprintln!("configurație invalidă");
        ExitCode::from(2)
    }
}
```

Dacă `main` returnează `Result` și ajunge la `Err`, codul de ieșire este 1.

> **De reținut:** `println!` scrie pe stdout, iar `eprintln!` pe stderr. `stdin().read_line` citește o linie, care se folosește cu `trim()`. `env::args()` dă argumentele, `fs::read_to_string` și `fs::write` lucrează cu fișiere întregi, iar `ExitCode` raportează rezultatul.
