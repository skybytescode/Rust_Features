# I/O and the system — Advanced

Starting other programs, generic code over any source or destination of bytes, stdout performance, and testing I/O code without real files.

## Starting other processes

`std::process::Command` starts an external program and controls its arguments, environment and streams:

```rust
use std::process::Command;

fn main() -> std::io::Result<()> {
    // Run and wait for the complete result
    let output = Command::new("echo").arg("hello").arg("from the child").output()?;
    println!("code: {}", output.status);
    println!("stdout: {}", String::from_utf8_lossy(&output.stdout).trim());

    // Only the exit code; the streams are inherited from the parent
    let status = Command::new("sh").args(["-c", "exit 3"]).status()?;
    println!("succeeded? {} (code {:?})", status.success(), status.code());
    Ok(())
}
```

Arguments are passed separately, not through a shell. `Command::new("ls").arg("file with spaces")` is safe, with no escaping problems. A shell (`sh -c`) comes into play only if you call it explicitly.

## Communicating through pipes

```rust
use std::io::Write;
use std::process::{Command, Stdio};

fn main() -> std::io::Result<()> {
    let mut child = Command::new("sort")
        .stdin(Stdio::piped())
        .stdout(Stdio::piped())
        .spawn()?;

    {
        let mut input = child.stdin.take().unwrap();
        input.write_all(b"pears\napples\nkiwi\n")?;
    } // stdin is closed here: `sort` learns that the input has ended

    let output = child.wait_with_output()?;
    print!("{}", String::from_utf8_lossy(&output.stdout));
    Ok(())
}
```

If you don't close the child's stdin, programs like `sort` wait forever for the rest of the input, and yours waits for them.

## Generic code over `Read` and `Write`

A function that takes `impl Read` or `impl Write` works with files, sockets, stdout, in-memory buffers or compressed data:

```rust
use std::io::{self, BufRead, BufReader, Read, Write};

fn count_words(source: impl Read) -> io::Result<usize> {
    let mut total = 0;
    for line in BufReader::new(source).lines() {
        total += line?.split_whitespace().count();
    }
    Ok(total)
}

fn write_report(dest: &mut impl Write, words: usize) -> io::Result<()> {
    writeln!(dest, "words: {words}")
}

fn main() -> io::Result<()> {
    // `&[u8]` implements Read: perfect for tests
    let n = count_words("one two\nthree four five".as_bytes())?;

    // `Vec<u8>` implements Write
    let mut buffer = Vec::new();
    write_report(&mut buffer, n)?;
    print!("{}", String::from_utf8_lossy(&buffer));

    // the same function, straight to stdout
    write_report(&mut io::stdout(), n)
}
```

## `Cursor` and `Seek`

`io::Cursor` wraps an in-memory buffer and adds a current position. That way you can test code that uses `Seek`, as with a file:

```rust
use std::io::{Cursor, Read, Seek, SeekFrom, Write};

fn main() -> std::io::Result<()> {
    let mut c = Cursor::new(Vec::new());
    c.write_all(b"header:USEFUL-DATA")?;

    c.seek(SeekFrom::Start(7))?;          // skips "header:"
    let mut rest = String::new();
    c.read_to_string(&mut rest)?;
    println!("{rest}");

    c.seek(SeekFrom::End(-4))?;           // the last 4 bytes
    let mut tail = [0u8; 4];
    c.read_exact(&mut tail)?;
    println!("{}", String::from_utf8_lossy(&tail));
    Ok(())
}
```

## Stdout performance

`println!` locks `stdout` on every call, and `stdout` is flushed on every newline. For thousands of lines, the difference is noticeable. Take the lock once and add a large buffer:

```rust
use std::io::{self, BufWriter, Write};

fn main() -> io::Result<()> {
    let stdout = io::stdout();
    let mut out = BufWriter::new(stdout.lock()); // one lock, one large buffer
    for i in 0..5 {
        writeln!(out, "line {i}")?;
    }
    out.flush()
}
```

## Temporary files and cleanup

The `tempfile` crate creates temporary files and directories with unique names, deleted automatically on `drop`. It's the standard in tests. Without it, you can build a unique name from `std::process::id()` and the current time, as in the example below:

```rust
use std::time::{SystemTime, UNIX_EPOCH};

fn main() {
    let unique = SystemTime::now().duration_since(UNIX_EPOCH).unwrap().as_nanos();
    let path = std::env::temp_dir().join(format!("test_{}_{unique}.tmp", std::process::id()));
    std::fs::write(&path, "data").unwrap();
    println!("{}", std::fs::read_to_string(&path).unwrap());
    std::fs::remove_file(&path).unwrap();
}
```

> **Key takeaway:** `Command` starts processes, with arguments passed separately, without a shell. Close the child's stdin when you're done writing. Write functions over `impl Read` / `impl Write` and test them with `&[u8]`, `Vec<u8>` and `Cursor`. For large output, lock `stdout` once and add a `BufWriter`.
