# I/O and the system — Fundamentals

A useful program talks to the world: it reads from the keyboard, receives arguments, reads and writes files, and reports whether it succeeded. All of that is in the standard library.

## Output: stdout and stderr

```rust
fn main() {
    println!("the normal result");           // stdout: the program's output
    eprintln!("a diagnostic message");       // stderr: errors and logs
    print!("no newline, ");
    println!("then a newline");
}
```

The separation matters: `program > result.txt` redirects only stdout, and the messages on stderr stay visible in the terminal.

## Reading a line from the keyboard

```rust
use std::io;

fn main() {
    println!("What's your name?");
    let mut name = String::new();
    io::stdin().read_line(&mut name).expect("reading failed");

    let name = name.trim(); // removes the trailing newline
    if name.is_empty() {
        println!("Hello, stranger!");
    } else {
        println!("Hello, {name}!");
    }
}
```

`read_line` **appends** to the string, including the `\n` character. That's why it's almost always used with `trim()`.

## Command-line arguments

```rust
use std::env;

fn main() {
    let args: Vec<String> = env::args().collect();
    println!("program: {}", args[0]);
    println!("arguments: {:?}", &args[1..]);

    match args.get(1) {
        Some(first) => println!("first argument: {first}"),
        None => println!("run it with: program <name>"),
    }
}
```

The first element is always the program's name. For real applications, the `clap` crate parses arguments (options, `--help`, validation).

## Writing and reading a file

```rust
use std::fs;

fn main() {
    let path = std::env::temp_dir().join("rust_futures_example.txt");

    fs::write(&path, "first line\nsecond line\n").expect("can't write");
    let contents = fs::read_to_string(&path).expect("can't read");

    println!("{} bytes read", contents.len());
    for line in contents.lines() {
        println!("> {line}");
    }

    fs::remove_file(&path).unwrap();
}
```

`fs::write` creates the file or **overwrites** it if it exists. `fs::read_to_string` reads the whole file into a `String`.

## I/O errors are normal

A file can be missing, and a disk can fill up. I/O operations return `Result`, and good code handles them:

```rust
use std::fs;

fn main() {
    match fs::read_to_string("/file/that/does/not/exist.txt") {
        Ok(text) => println!("{text}"),
        Err(e) => println!("error: {e}"),
    }
}
```

## The exit code

Programs report success or failure through an **exit code**: 0 means success, any other value means failure. Scripts and CI systems rely on it:

```rust
use std::process::ExitCode;

fn main() -> ExitCode {
    let config_is_valid = true;
    if config_is_valid {
        println!("all is well");
        ExitCode::SUCCESS
    } else {
        eprintln!("invalid configuration");
        ExitCode::from(2)
    }
}
```

If `main` returns a `Result` and ends with `Err`, the exit code is 1.

> **Key takeaway:** `println!` writes to stdout, and `eprintln!` to stderr. `stdin().read_line` reads a line, used with `trim()`. `env::args()` gives the arguments, `fs::read_to_string` and `fs::write` work with whole files, and `ExitCode` reports the outcome.
