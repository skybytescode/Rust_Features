# I/O and the system — Practitioner

The `Read` and `Write` traits, efficient line-by-line reading, working with paths and directories, plus handling each kind of error.

## `Read`, `Write` and buffering

`File` implements `Read` and `Write`, but every call goes straight to the operating system. For many small operations, wrap the file in a buffer:

```rust
use std::fs::File;
use std::io::{BufRead, BufReader, BufWriter, Write};

fn main() -> std::io::Result<()> {
    let path = std::env::temp_dir().join("rust_futures_numbers.txt");

    // Writing: BufWriter gathers the data and sends it in large chunks
    let mut w = BufWriter::new(File::create(&path)?);
    for i in 1..=5 {
        writeln!(w, "{i},{}", i * i)?;
    }
    w.flush()?; // empty the buffer before reading the file

    // Reading line by line, without loading the whole file into memory
    let r = BufReader::new(File::open(&path)?);
    let mut sum = 0;
    for line in r.lines() {
        let line = line?;
        let (_, square) = line.split_once(',').unwrap();
        sum += square.parse::<u32>().unwrap();
    }
    println!("sum of squares: {sum}");

    std::fs::remove_file(&path)?;
    Ok(())
}
```

A `BufWriter` also empties its buffer when it's destroyed, but errors that happen then are ignored. Call `flush()` explicitly when it matters.

## Appending: `OpenOptions`

```rust
use std::fs::OpenOptions;
use std::io::Write;

fn main() -> std::io::Result<()> {
    let path = std::env::temp_dir().join("rust_futures_log.txt");
    let _ = std::fs::remove_file(&path);

    for message in ["started", "processed", "stopped"] {
        let mut f = OpenOptions::new().create(true).append(true).open(&path)?;
        writeln!(f, "{message}")?;
    }
    print!("{}", std::fs::read_to_string(&path)?);
    std::fs::remove_file(&path)
}
```

| You want to… | Use |
|---|---|
| read the whole file | `fs::read_to_string` / `fs::read` |
| write the whole file (overwrites) | `fs::write` / `File::create` |
| append at the end | `OpenOptions::new().append(true).create(true)` |
| create only if it doesn't exist | `OpenOptions::new().write(true).create_new(true)` |

## Paths: `Path` and `PathBuf`

Don't build paths by gluing strings with `/`. `Path` knows each operating system's separator:

```rust
use std::path::{Path, PathBuf};

fn main() {
    let base = PathBuf::from("/home/ana");
    let photo = base.join("photos").join("big.jpg");

    println!("{}", photo.display());
    println!("{:?} {:?}", photo.file_name(), photo.extension());
    println!("{:?}", photo.parent());
    println!("{}", photo.with_extension("png").display());
    println!("{}", Path::new("relative/path").is_absolute());
}
```

## Directories

```rust
use std::fs;

fn main() -> std::io::Result<()> {
    let dir = std::env::temp_dir().join("rust_futures_demo_en");
    fs::create_dir_all(dir.join("sub"))?; // also creates the intermediate directories
    fs::write(dir.join("a.txt"), "1")?;
    fs::write(dir.join("b.md"), "2")?;

    let mut names: Vec<String> = fs::read_dir(&dir)?
        .filter_map(|e| e.ok())
        .map(|e| {
            let kind = if e.path().is_dir() { "dir" } else { "file" };
            format!("{} ({kind})", e.file_name().to_string_lossy())
        })
        .collect();
    names.sort(); // the order from read_dir isn't guaranteed
    println!("{names:?}");

    fs::remove_dir_all(&dir) // deletes everything, recursively
}
```

## Handling kinds of errors

`io::Error` has a `kind()` you can test, so you can react differently to each problem:

```rust
use std::fs;
use std::io::ErrorKind;

fn read_config(path: &str) -> String {
    match fs::read_to_string(path) {
        Ok(text) => text,
        Err(e) if e.kind() == ErrorKind::NotFound => {
            eprintln!("{path} is missing, using the defaults");
            String::from("port=8080")
        }
        Err(e) => panic!("can't read {path}: {e}"),
    }
}

fn main() {
    println!("{}", read_config("/does/not/exist/config.toml"));
}
```

## Environment variables

```rust
use std::env;

fn main() {
    let home = env::var("HOME").unwrap_or_else(|_| "(unknown)".into());
    println!("HOME = {home}");

    let level = env::var("LOG_LEVEL").unwrap_or_else(|_| "info".into());
    println!("log level: {level}");

    println!("current directory: {}", env::current_dir().unwrap().display());
}
```

`env::var` returns `Err` if the variable is missing **or** if it isn't valid UTF-8. `env::var_os` returns an `OsString`, without the UTF-8 check.

> **Key takeaway:** use `BufReader` / `BufWriter` for many small operations, and `flush()` at the end. `OpenOptions` controls exactly how a file is opened. Build paths with `Path::join`. `ErrorKind` lets you handle each error separately, for example a missing file.
