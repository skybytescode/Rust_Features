# I/O și sistem — Practician

Trait-urile `Read` și `Write`, citirea eficientă linie cu linie, lucrul cu căi și directoare, plus tratarea fiecărui tip de eroare.

## `Read`, `Write` și buffering

`File` implementează `Read` și `Write`, dar fiecare apel ajunge direct la sistemul de operare. Pentru multe operații mici, învelește fișierul într-un buffer:

```rust
use std::fs::File;
use std::io::{BufRead, BufReader, BufWriter, Write};

fn main() -> std::io::Result<()> {
    let cale = std::env::temp_dir().join("rust_features_numere.txt");

    // Scriere: BufWriter adună datele și le trimite în bucăți mari
    let mut w = BufWriter::new(File::create(&cale)?);
    for i in 1..=5 {
        writeln!(w, "{i},{}", i * i)?;
    }
    w.flush()?; // golește buffer-ul înainte de a citi fișierul

    // Citire linie cu linie, fără să încarci tot fișierul în memorie
    let r = BufReader::new(File::open(&cale)?);
    let mut suma = 0;
    for linie in r.lines() {
        let linie = linie?;
        let (_, patrat) = linie.split_once(',').unwrap();
        suma += patrat.parse::<u32>().unwrap();
    }
    println!("suma pătratelor: {suma}");

    std::fs::remove_file(&cale)?;
    Ok(())
}
```

Un `BufWriter` golește buffer-ul și când e distrus, dar erorile apărute atunci sunt ignorate. Apelează `flush()` explicit când contează.

## Adăugare la final: `OpenOptions`

```rust
use std::fs::OpenOptions;
use std::io::Write;

fn main() -> std::io::Result<()> {
    let cale = std::env::temp_dir().join("rust_features_jurnal.txt");
    let _ = std::fs::remove_file(&cale);

    for mesaj in ["pornit", "procesat", "oprit"] {
        let mut f = OpenOptions::new().create(true).append(true).open(&cale)?;
        writeln!(f, "{mesaj}")?;
    }
    print!("{}", std::fs::read_to_string(&cale)?);
    std::fs::remove_file(&cale)
}
```

| Vrei să… | Folosește |
|---|---|
| citești tot fișierul | `fs::read_to_string` / `fs::read` |
| scrii tot fișierul (suprascrie) | `fs::write` / `File::create` |
| adaugi la final | `OpenOptions::new().append(true).create(true)` |
| creezi doar dacă nu există | `OpenOptions::new().write(true).create_new(true)` |

## Căi: `Path` și `PathBuf`

Nu construi căi lipind string-uri cu `/`. `Path` știe separatorul fiecărui sistem de operare:

```rust
use std::path::{Path, PathBuf};

fn main() {
    let baza = PathBuf::from("/home/ana");
    let poza = baza.join("poze").join("mare.jpg");

    println!("{}", poza.display());
    println!("{:?} {:?}", poza.file_name(), poza.extension());
    println!("{:?}", poza.parent());
    println!("{}", poza.with_extension("png").display());
    println!("{}", Path::new("relativ/cale").is_absolute());
}
```

## Directoare

```rust
use std::fs;

fn main() -> std::io::Result<()> {
    let dir = std::env::temp_dir().join("rust_features_demo");
    fs::create_dir_all(dir.join("sub"))?; // creează și directoarele intermediare
    fs::write(dir.join("a.txt"), "1")?;
    fs::write(dir.join("b.md"), "2")?;

    let mut nume: Vec<String> = fs::read_dir(&dir)?
        .filter_map(|e| e.ok())
        .map(|e| {
            let tip = if e.path().is_dir() { "dir" } else { "fișier" };
            format!("{} ({tip})", e.file_name().to_string_lossy())
        })
        .collect();
    nume.sort(); // ordinea din read_dir nu e garantată
    println!("{nume:?}");

    fs::remove_dir_all(&dir) // șterge tot, recursiv
}
```

## Tratarea tipurilor de eroare

`io::Error` are un `kind()` pe care îl poți testa, ca să reacționezi diferit la fiecare problemă:

```rust
use std::fs;
use std::io::ErrorKind;

fn citeste_config(cale: &str) -> String {
    match fs::read_to_string(cale) {
        Ok(text) => text,
        Err(e) if e.kind() == ErrorKind::NotFound => {
            eprintln!("{cale} lipsește, folosesc valorile implicite");
            String::from("port=8080")
        }
        Err(e) => panic!("nu pot citi {cale}: {e}"),
    }
}

fn main() {
    println!("{}", citeste_config("/nu/exista/config.toml"));
}
```

## Variabile de mediu

```rust
use std::env;

fn main() {
    let home = env::var("HOME").unwrap_or_else(|_| "(necunoscut)".into());
    println!("HOME = {home}");

    let nivel = env::var("NIVEL_LOG").unwrap_or_else(|_| "info".into());
    println!("nivel de jurnal: {nivel}");

    println!("director curent: {}", env::current_dir().unwrap().display());
}
```

`env::var` returnează `Err` dacă variabila lipsește **sau** dacă nu e UTF-8 valid. `env::var_os` returnează un `OsString`, fără verificarea UTF-8.

> **De reținut:** folosește `BufReader` / `BufWriter` pentru multe operații mici și `flush()` la final. `OpenOptions` controlează exact cum se deschide un fișier. Construiește căile cu `Path::join`. `ErrorKind` te lasă să tratezi separat fiecare eroare, de exemplu un fișier lipsă.
