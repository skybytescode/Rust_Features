# Unsafe și FFI — Practician

Principiul central: **încapsulează** codul `unsafe` în spatele unei interfețe sigure. Plus cum transmiți text și date între Rust și C.

## Abstracțiuni sigure peste cod `unsafe`

`split_at_mut` din biblioteca standard împarte un slice în două părți mutabile. Borrow checker-ul nu poate demonstra singur că părțile nu se suprapun, deci implementarea folosește `unsafe`. Interfața rămâne însă **complet sigură**:

```rust
fn imparte_mut(s: &mut [i32], mijloc: usize) -> (&mut [i32], &mut [i32]) {
    let len = s.len();
    assert!(mijloc <= len); // verificarea care face codul de mai jos corect
    let p = s.as_mut_ptr();
    // SAFETY: cele două intervale [0, mijloc) și [mijloc, len) sunt disjuncte
    // și ambele sunt în limitele slice-ului original.
    unsafe {
        (
            std::slice::from_raw_parts_mut(p, mijloc),
            std::slice::from_raw_parts_mut(p.add(mijloc), len - mijloc),
        )
    }
}

fn main() {
    let mut v = [1, 2, 3, 4, 5];
    let (a, b) = imparte_mut(&mut v, 2);
    a[0] = 100;
    b[0] = 300;
    println!("{v:?}");
}
```

Cine apelează `imparte_mut` nu poate provoca comportament nedefinit, indiferent de argumente: `assert!` oprește un `mijloc` invalid. Așa arată o abstracțiune sigură corectă.

## `unsafe fn` și documentarea condițiilor

Dacă o funcție are condiții pe care nu le poate verifica singură, o marchezi `unsafe fn` și le documentezi în secțiunea `# Safety`:

```rust
/// Returnează elementul de la `i` fără verificarea limitelor.
///
/// # Safety
///
/// `i` trebuie să fie mai mic decât `v.len()`.
unsafe fn ia_rapid(v: &[u64], i: usize) -> u64 {
    // SAFETY: apelantul garantează că `i < v.len()`
    unsafe { *v.get_unchecked(i) }
}

fn main() {
    let v = [5, 6, 7];
    // SAFETY: 2 < 3
    println!("{}", unsafe { ia_rapid(&v, 2) });
}
```

În ediția 2024, chiar și în interiorul unei `unsafe fn` trebuie să scrii explicit `unsafe { ... }` în jurul operațiilor nesigure (lint-ul `unsafe_op_in_unsafe_fn`). Așa e clar exact care linii au nevoie de atenție.

## Text între Rust și C

String-urile Rust nu se termină cu `\0` și pot conține `\0` în mijloc. String-urile C sunt opusul. Biblioteca standard are tipuri dedicate:

| Rust | C | Rol |
|---|---|---|
| `CString` | `char*` alocat | creezi un string C din Rust |
| `&CStr` | `const char*` | împrumuți un string C |
| `c"text"` | literal C | `&'static CStr`, din Rust 1.77 |

```rust
use std::ffi::{CStr, CString, c_char};

unsafe extern "C" {
    fn strlen(s: *const c_char) -> usize;
}

fn main() {
    let rust = String::from("salut");
    let c = CString::new(rust).expect("conține \\0 în mijloc");
    // SAFETY: `c` e un string C valid, terminat cu \0, și trăiește pe durata apelului
    let n = unsafe { strlen(c.as_ptr()) };
    println!("lungime C: {n}");

    let literal: &CStr = c"din literal";
    println!("{:?} → {}", literal, literal.to_str().unwrap());
}
```

Greșeala clasică: `CString::new(s).unwrap().as_ptr()` într-o singură expresie. `CString`-ul temporar e distrus la finalul instrucțiunii, iar pointerul rămâne invalid. Păstrează mereu `CString`-ul într-o variabilă.

## Structuri compatibile cu C

Pentru o structură trimisă către C, folosește `#[repr(C)]`, ca ordinea și alinierea câmpurilor să fie cele din C:

```rust
#[repr(C)]
#[derive(Debug, Clone, Copy)]
struct Punct {
    x: f64,
    y: f64,
}

// O funcție Rust apelabilă din C
#[unsafe(no_mangle)]
pub extern "C" fn distanta(a: Punct, b: Punct) -> f64 {
    ((a.x - b.x).powi(2) + (a.y - b.y).powi(2)).sqrt()
}

fn main() {
    println!("{}", distanta(Punct { x: 0.0, y: 0.0 }, Punct { x: 3.0, y: 4.0 }));
}
```

## Funcții externe marcate `safe`

Din Rust 1.82, într-un bloc `unsafe extern` poți marca drept `safe` funcțiile care nu au condiții speciale. Apoi le apelezi fără `unsafe`:

```rust
unsafe extern "C" {
    safe fn labs(x: i64) -> i64; // promisiune: orice valoare e acceptată
}

fn main() {
    println!("{}", labs(-7)); // fără bloc unsafe
}
```

Responsabilitatea se mută în locul declarației: dacă marchezi greșit o funcție ca `safe`, ai introdus un bug de siguranță.

> **De reținut:** ascunde `unsafe` în spatele unei interfețe sigure, care verifică tot ce poate. Documentează condițiile în `# Safety` și justifică fiecare bloc cu `// SAFETY:`. Pentru text folosești `CString` / `CStr` / `c"..."`, iar pentru structuri, `#[repr(C)]`.
