# Pattern matching — Fundamente

Un **pattern** descrie forma unei valori. Cu `match` compari o valoare cu mai multe pattern-uri și rulezi codul primului care se potrivește.

## `match` cu valori simple

```rust
fn main() {
    let zar = 4;
    match zar {
        1 => println!("unu"),
        6 => println!("șase, mai aruncă o dată"),
        _ => println!("ai dat {zar}"),
    }
}
```

`_` înseamnă „orice altceva”. Fiecare ramură are forma `pattern => expresie`.

## `match` trebuie să acopere toate cazurile

Compilatorul verifică dacă ai tratat **toate** valorile posibile. Dacă uiți un caz, programul nu compilează:

```rust,compile_fail
enum Moneda {
    Ban,
    Leu,
    Euro,
}

fn main() {
    let m = Moneda::Leu;
    let valoare = match m {
        Moneda::Ban => 1,
        Moneda::Leu => 100,
        // eroare E0004: lipsește `Moneda::Euro`
    };
    println!("{valoare}");
}
```

Garanția asta contează mai ales când adaugi o variantă nouă unui enum: compilatorul îți arată fiecare `match` care trebuie actualizat.

## Mai multe valori și intervale

`|` înseamnă „sau”, iar `..=` descrie un interval inclusiv:

```rust
fn main() {
    let nota = 8;
    let calificativ = match nota {
        10 => "excelent",
        8 | 9 => "foarte bine",
        5..=7 => "bine",
        1..=4 => "insuficient",
        _ => "notă invalidă",
    };
    println!("{calificativ}");

    let c = 'k';
    match c {
        'a' | 'e' | 'i' | 'o' | 'u' => println!("vocală"),
        'a'..='z' => println!("consoană"),
        _ => println!("altceva"),
    }
}
```

## Extragerea datelor dintr-un enum

Un pattern poate „despacheta” datele dintr-o variantă și le poate lega de variabile:

```rust
fn main() {
    let rezultat: Option<i32> = Some(42);

    match rezultat {
        Some(n) => println!("valoarea este {n}"),
        None => println!("nu există valoare"),
    }
}
```

## `match` produce o valoare

Ca `if`, `match` e o expresie. Toate ramurile trebuie să aibă același tip:

```rust
fn main() {
    let ora = 14;
    let salut = match ora {
        5..=11 => "Bună dimineața",
        12..=17 => "Bună ziua",
        _ => "Bună seara",
    };
    println!("{salut}!");
}
```

## `if let`: când te interesează un singur caz

Dacă vrei să tratezi doar un pattern și să ignori restul, `if let` e mai scurt:

```rust
fn main() {
    let favorit: Option<&str> = Some("Rust");

    if let Some(limbaj) = favorit {
        println!("Limbajul preferat: {limbaj}");
    }
}
```

## Destructurarea tuplurilor

Pattern-urile funcționează și în `let`:

```rust
fn main() {
    let punct = (3, -7);
    let (x, y) = punct;
    println!("x = {x}, y = {y}");

    match punct {
        (0, 0) => println!("origine"),
        (0, _) => println!("pe axa Y"),
        (_, 0) => println!("pe axa X"),
        _ => println!("în altă parte"),
    }
}
```

> **De reținut:** `match` compară o valoare cu pattern-uri, în ordine, și trebuie să acopere toate cazurile. `_` prinde orice, `|` înseamnă „sau”, `..=` descrie un interval, iar `if let` tratează un singur caz.
