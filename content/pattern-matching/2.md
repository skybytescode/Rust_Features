# Pattern matching — Practician

Pattern-urile pot destructura structuri imbricate, pot avea condiții suplimentare și pot lega valori de nume în același timp.

## Destructurarea structurilor

```rust
struct Punct {
    x: i32,
    y: i32,
}

fn main() {
    let p = Punct { x: 0, y: 7 };

    let Punct { x, y } = p; // câmpurile devin variabile
    println!("{x} {y}");

    match p {
        Punct { x: 0, y } => println!("pe axa Y, la înălțimea {y}"),
        Punct { y: 0, .. } => println!("pe axa X"),  // `..` ignoră restul câmpurilor
        Punct { x, y } => println!("({x}, {y})"),
    }
}
```

## Enums imbricate

Pattern-urile pot coborî la orice adâncime:

```rust
enum Culoare {
    Rgb(u8, u8, u8),
    Gri(u8),
}

enum Comanda {
    Deseneaza { forma: String, culoare: Culoare },
    Sterge,
}

fn main() {
    let comenzi = [
        Comanda::Deseneaza { forma: "cerc".into(), culoare: Culoare::Rgb(255, 0, 0) },
        Comanda::Deseneaza { forma: "pătrat".into(), culoare: Culoare::Gri(128) },
        Comanda::Sterge,
    ];

    for c in &comenzi {
        match c {
            Comanda::Deseneaza { forma, culoare: Culoare::Rgb(r, g, b) } => {
                println!("{forma} RGB({r}, {g}, {b})")
            }
            Comanda::Deseneaza { forma, culoare: Culoare::Gri(n) } => println!("{forma} gri {n}"),
            Comanda::Sterge => println!("șterge tot"),
        }
    }
}
```

## Guard-uri: condiții suplimentare

După pattern poți adăuga `if condiție`. Ramura se alege doar dacă se potrivește pattern-ul **și** condiția e adevărată:

```rust
fn main() {
    let temperaturi = [Some(-5), Some(22), Some(38), None];
    for t in temperaturi {
        let mesaj = match t {
            Some(g) if g < 0 => "îngheț",
            Some(g) if g > 35 => "caniculă",
            Some(_) => "normal",
            None => "senzor defect",
        };
        println!("{t:?}: {mesaj}");
    }
}
```

## Legare cu `@`

`nume @ pattern` verifică pattern-ul și, în același timp, păstrează valoarea într-o variabilă:

```rust
fn main() {
    let varsta = 15;
    match varsta {
        copil @ 0..=12 => println!("copil de {copil} ani"),
        adolescent @ 13..=17 => println!("adolescent de {adolescent} ani"),
        adult => println!("adult de {adult} ani"),
    }
}
```

## `matches!`: un `match` care returnează `bool`

```rust
#[derive(Debug)]
enum Stare {
    Activ,
    Suspendat { zile: u32 },
    Sters,
}

fn main() {
    let stari = [Stare::Activ, Stare::Suspendat { zile: 3 }, Stare::Sters];
    let poate_reveni = stari
        .iter()
        .filter(|s| matches!(s, Stare::Activ | Stare::Suspendat { zile: 0..=7 }))
        .count();
    println!("{poate_reveni} conturi pot reveni");
}
```

## `while let` și `let-else`

`while let` repetă cât timp pattern-ul se potrivește, iar `let-else` extrage valoarea sau iese din funcție:

```rust
fn primul_cuvant_lung(text: &str) -> &str {
    let Some(cuvant) = text.split_whitespace().find(|c| c.len() > 4) else {
        return "(niciunul)";
    };
    cuvant
}

fn main() {
    let mut coada = vec!["a", "b", "c"];
    while let Some(element) = coada.pop() {
        print!("{element} ");
    }
    println!();
    println!("{}", primul_cuvant_lung("un exemplu scurt"));
}
```

## Exhaustivitatea te ajută la refactorizare

Evită `_` pe enum-urile tale când nu e nevoie de el. Cu `_`, compilatorul nu te mai anunță când adaugi o variantă nouă. Fără el, primești o eroare în fiecare loc care trebuie actualizat.

> **De reținut:** pattern-urile destructurează structuri și enums imbricate. `if` adaugă condiții, `@` păstrează valoarea, iar `matches!` returnează `bool`. Evită `_` ca să păstrezi verificarea de exhaustivitate.
