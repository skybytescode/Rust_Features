# Pattern matching — Fundamentals

A **pattern** describes the shape of a value. With `match` you compare a value against several patterns and run the code of the first one that matches.

## `match` with simple values

```rust
fn main() {
    let die = 4;
    match die {
        1 => println!("one"),
        6 => println!("six, roll again"),
        _ => println!("you rolled {die}"),
    }
}
```

`_` means "anything else". Each branch has the form `pattern => expression`.

## `match` must cover every case

The compiler checks that you've handled **every** possible value. If you forget a case, the program doesn't compile:

```rust,compile_fail
enum Coin {
    Cent,
    Dollar,
    Euro,
}

fn main() {
    let c = Coin::Dollar;
    let value = match c {
        Coin::Cent => 1,
        Coin::Dollar => 100,
        // error E0004: `Coin::Euro` is not covered
    };
    println!("{value}");
}
```

This guarantee matters most when you add a new variant to an enum: the compiler points out every `match` that needs updating.

## Several values and ranges

`|` means "or", and `..=` describes an inclusive range:

```rust
fn main() {
    let grade = 8;
    let rating = match grade {
        10 => "excellent",
        8 | 9 => "very good",
        5..=7 => "good",
        1..=4 => "insufficient",
        _ => "invalid grade",
    };
    println!("{rating}");

    let c = 'k';
    match c {
        'a' | 'e' | 'i' | 'o' | 'u' => println!("vowel"),
        'a'..='z' => println!("consonant"),
        _ => println!("something else"),
    }
}
```

## Extracting data from an enum

A pattern can "unpack" the data from a variant and bind it to variables:

```rust
fn main() {
    let result: Option<i32> = Some(42);

    match result {
        Some(n) => println!("the value is {n}"),
        None => println!("there is no value"),
    }
}
```

## `match` produces a value

Like `if`, `match` is an expression. All branches must have the same type:

```rust
fn main() {
    let hour = 14;
    let greeting = match hour {
        5..=11 => "Good morning",
        12..=17 => "Good afternoon",
        _ => "Good evening",
    };
    println!("{greeting}!");
}
```

## `if let`: when you care about a single case

If you only want to handle one pattern and ignore the rest, `if let` is shorter:

```rust
fn main() {
    let favorite: Option<&str> = Some("Rust");

    if let Some(language) = favorite {
        println!("Favorite language: {language}");
    }
}
```

## Destructuring tuples

Patterns also work in `let`:

```rust
fn main() {
    let point = (3, -7);
    let (x, y) = point;
    println!("x = {x}, y = {y}");

    match point {
        (0, 0) => println!("origin"),
        (0, _) => println!("on the Y axis"),
        (_, 0) => println!("on the X axis"),
        _ => println!("somewhere else"),
    }
}
```

> **Key takeaway:** `match` compares a value against patterns, in order, and must cover every case. `_` catches anything, `|` means "or", `..=` describes a range, and `if let` handles a single case.
