# Text și formatare — Practician

Specificatorii de formatare pentru tabele și rapoarte, plus metodele de pe `str` pe care le folosești zilnic.

## Lățime, aliniere și completare

După `:` poți controla cum arată valoarea: `{:[completare][aliniere][lățime]}`.

```rust
fn main() {
    println!("[{:10}]", "stânga");    // text: aliniat implicit la stânga
    println!("[{:>10}]", "dreapta");
    println!("[{:^10}]", "centru");
    println!("[{:*^10}]", "stele");   // completare cu `*`
    println!("[{:5}]", 42);           // numere: aliniate implicit la dreapta
    println!("[{:<5}]", 42);
    println!("[{:05}]", 42);          // completare cu zerouri
    println!("[{:+}]", 42);           // semnul mereu afișat
}
```

Lățimea și precizia pot veni și din variabile:

```rust
fn main() {
    let latime = 12;
    let zecimale = 3;
    let x = 2.0_f64.sqrt();
    println!("[{x:>latime$.zecimale$}]");
    println!("[{:>1$.2$}]", x, 8, 1);
}
```

## Un tabel aliniat

```rust
fn main() {
    let produse = [("Mere", 12, 4.5), ("Portocale", 3, 7.25), ("Kiwi", 40, 0.9)];
    println!("{:<12}{:>6}{:>10}", "Produs", "Buc.", "Preț");
    println!("{}", "-".repeat(28));
    for (nume, bucati, pret) in produse {
        println!("{nume:<12}{bucati:>6}{pret:>10.2}");
    }
}
```

## Baze numerice și notație științifică

```rust
fn main() {
    let n = 255;
    println!("{n:b} {n:o} {n:x} {n:X}");     // binar, octal, hex
    println!("{n:#b} {n:#x}");               // cu prefix: 0b..., 0x...
    println!("{n:#010b}");                   // prefix + completare la 10 caractere
    println!("{:e} {:E}", 1234.5, 0.00012);  // notație științifică
}
```

## Metode utile pe `str`

```rust
fn main() {
    let text = "  Rust este Rapid, Rust este Sigur  ";

    println!("[{}]", text.trim());
    println!("{}", text.to_lowercase());
    println!("{}", text.replace("Rust", "🦀"));
    println!("{}", text.contains("Sigur"));
    println!("{:?}", text.find("este"));               // poziția în octeți
    println!("{}", text.trim().starts_with("Rust"));

    let cuvinte: Vec<&str> = text.split_whitespace().collect();
    println!("{cuvinte:?}");

    let (cheie, valoare) = "port=8080".split_once('=').unwrap();
    println!("{cheie} → {valoare}");

    for (i, linie) in "unu\ndoi\ntrei".lines().enumerate() {
        println!("{i}: {linie}");
    }
}
```

## Caractere

```rust
fn main() {
    for c in ['a', 'Ș', '7', ' ', '🦀'] {
        println!(
            "{c:?}: literă {}, cifră {}, majusculă {}, spațiu {}, {} octeți",
            c.is_alphabetic(),
            c.is_ascii_digit(),
            c.is_uppercase(),
            c.is_whitespace(),
            c.len_utf8()
        );
    }
    println!("{:?}", '7'.to_digit(10));
    println!("{}", 'ș'.to_uppercase());
}
```

## Construirea eficientă a unui `String`

`format!` în buclă alocă de fiecare dată un string nou. Când construiești un text mare, scrie direct în același `String`:

```rust
use std::fmt::Write;

fn main() {
    let mut raport = String::with_capacity(256);
    for i in 1..=3 {
        writeln!(raport, "rândul {i}: {}", i * i).unwrap(); // scrie în String, fără alocări noi
    }
    raport.push_str("gata");
    print!("{raport}\n");
}
```

`write!` și `writeln!` funcționează pe orice tip care implementează `std::fmt::Write`, inclusiv `String`.

> **De reținut:** `{:>10}`, `{:^10}`, `{:05}`, `{:.2}` și `{:#x}` acoperă aproape orice raport. Lățimea poate veni din variabile, cu `$`. Pe `str` ai `trim`, `split_once`, `lines`, `replace` și `find`, iar `write!` într-un `String` evită alocările repetate.
