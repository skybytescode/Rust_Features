# Text și formatare — Avansat

Cum scrii un `Display` care respectă lățimea și precizia cerute, regulile UTF-8 pentru indexare și ce tipuri de text există dincolo de `String`.

## `Display` care respectă opțiunile de formatare

Un `Display` scris cu `write!` ignoră lățimea și alinierea cerute de apelant. `Formatter` îți dă acces la ele:

```rust
use std::fmt;

struct Culoare(u8, u8, u8);

impl fmt::Display for Culoare {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        let text = if f.alternate() {
            format!("rgb({}, {}, {})", self.0, self.1, self.2) // pentru {:#}
        } else {
            format!("#{:02x}{:02x}{:02x}", self.0, self.1, self.2)
        };
        f.pad(&text) // aplică lățimea, alinierea și completarea cerute
    }
}

fn main() {
    let c = Culoare(255, 128, 0);
    println!("[{c}]");
    println!("[{c:>12}]");
    println!("[{c:-^12}]");
    println!("[{c:#}]");
}
```

Pentru numere, `f.precision()`, `f.width()` și `f.sign_plus()` îți dau restul opțiunilor. `f.pad_integral` aplică regulile pentru numere (semn, prefix, zerouri).

## Unde poate fi tăiat un `str`

Un `str` e UTF-8, iar un caracter ocupă 1–4 octeți. Poți tăia un slice doar la **granița unui caracter**, altfel apare un panic:

```rust,should_panic
fn main() {
    let s = "mâță";
    println!("{}", &s[0..1]);                 // „m”: OK
    println!("{}", s.is_char_boundary(2));    // false: „â” ocupă octeții 1–2
    println!("{}", &s[0..2]);                 // panic: 2 nu e graniță de caracter
}
```

Metodele care lucrează cu poziții (`find`, `char_indices`) returnează mereu granițe valide, deci le poți folosi direct pentru tăiere:

```rust
fn primele_n(s: &str, n: usize) -> &str {
    match s.char_indices().nth(n) {
        Some((poz, _)) => &s[..poz],
        None => s,
    }
}

fn main() {
    println!("{}", primele_n("Brașov", 4));
    println!("{}", primele_n("ok", 10));
}
```

## Caractere vs. ce vede utilizatorul

Un `char` e un *Unicode scalar value*, nu neapărat o „literă” vizibilă. Unele simboluri sunt formate din mai multe `char`-uri:

```rust
fn main() {
    let compus = "e\u{0301}";      // „e” + accent combinat = é
    let steag = "🇷🇴";               // două simboluri regionale
    let familie = "👨‍👩‍👧";            // trei persoane unite prin ZWJ

    for s in [compus, steag, familie] {
        println!("{s}: {} char-uri, {} octeți", s.chars().count(), s.len());
    }
}
```

Pentru „caractere așa cum le vede omul” (*grapheme clusters*) folosești crate-ul `unicode-segmentation`. Biblioteca standard nu le include.

## Comparații fără diferențe de majuscule

```rust
fn main() {
    let a = "RUST";
    let b = "rust";
    println!("{}", a.eq_ignore_ascii_case(b));          // doar ASCII, rapid
    println!("{}", a.to_lowercase() == b.to_lowercase()); // Unicode, alocă
    println!("{}", "ȘTIU".to_lowercase());
}
```

`to_lowercase` respectă regulile Unicode, așa că lungimea textului se poate schimba. De exemplu, „ß” devine „SS” la `to_uppercase`.

## Alte tipuri de text

| Tip | Conține | Când apare |
|---|---|---|
| `String` / `&str` | UTF-8 valid | textul obișnuit |
| `Vec<u8>` / `&[u8]` | orice octeți | date binare, protocoale |
| `OsString` / `&OsStr` | textul nativ al sistemului de operare | argumente, variabile de mediu |
| `PathBuf` / `&Path` | căi de fișiere | sistemul de fișiere |
| `CString` / `&CStr` | octeți terminați cu `\0` | FFI cu C |

```rust
use std::path::Path;

fn main() {
    let octeti: &[u8] = b"ASCII \x00 binar";  // literal de octeți
    println!("{octeti:?}");

    let invalid = [0x66, 0x6f, 0xff, 0x6f];
    println!("{:?}", std::str::from_utf8(&invalid).is_err());
    println!("{}", String::from_utf8_lossy(&invalid)); // înlocuiește cu �

    let cale = Path::new("/home/ana/poze/vacanta.jpg");
    println!("{:?} {:?}", cale.file_stem(), cale.extension());
}
```

> **De reținut:** `f.pad` face ca `Display`-ul tău să respecte lățimea și alinierea. Taie un `str` doar la granițe de caracter, obținute din `char_indices` sau `find`. Un `char` nu e neapărat o literă vizibilă. Pentru octeți, căi și texte de sistem există tipuri dedicate.
