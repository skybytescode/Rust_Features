# Text and formatting — Fundamentals

Rust has two main types for text: `String`, text you own and can modify, and `&str`, a "view" of text that belongs to someone else. On top of them, the formatting macros turn any value into text.

## `String` and `&str`

```rust
fn main() {
    let literal: &str = "hello";            // stored in the binary, can't be modified
    let mut owned: String = String::from("hello");
    owned.push_str(", world");              // a String can grow

    let view: &str = &owned;                // a &str looking into the String
    println!("{literal} | {owned} | {view}");
}
```

The practical rule: function parameters take `&str`, while structs and new results use `String`.

## Special characters and raw strings

```rust
fn main() {
    println!("new line:\nsecond line");
    println!("tab:\tafter the tab");
    println!("quotes: \"quoted\" and backslash: \\");
    println!("unicode: \u{1F980}");

    // Raw string: the backslash has no special meaning
    let path = r"C:\Users\ana\file.txt";
    let with_quotes = r#"she said "hello""#;
    println!("{path}\n{with_quotes}");
}
```

## Text over several lines

```rust
fn main() {
    let poem = "First line
second line";
    println!("{poem}");

    // `\` at the end of a line joins the lines and skips the leading spaces
    let long = "This is a very long text \
                written over two lines of code.";
    println!("{long}");
}
```

## Joining texts

```rust
fn main() {
    let first = "Ana";
    let last = "Smith";

    let a = String::from(first) + " " + last;  // `+` consumes the String on the left
    let b = format!("{first} {last}");          // clearer, and consumes nothing
    let c = [first, last].join(" ");            // for lists of texts

    println!("{a} | {b} | {c}");
}
```

`format!` is usually the most readable option.

## Basic formatting

`println!`, `format!` and the other formatting macros replace `{}` with values:

```rust
fn main() {
    let name = "Mike";
    let age = 31;
    let height = 1.8234;

    println!("{} is {} years old", name, age); // by position
    println!("{name} is {age} years old");     // the variable directly in the text
    println!("{0} and {0} again", name);       // the same argument twice
    println!("{n} cm", n = 180);               // a named argument
    println!("height: {height:.2} m");         // 2 decimals
    println!("{:?}", vec![1, 2, 3]);           // Debug: for structs and collections
}
```

| Written | Uses the trait | For |
|---|---|---|
| `{}` | `Display` | users: nice text |
| `{:?}` | `Debug` | programmers: debugging |
| `{:#?}` | `Debug`, over several lines | large structures |

## Text to number and number to text

```rust
fn main() {
    let n: i32 = "42".parse().unwrap();
    let text = n.to_string();
    let pi = 3.14159_f64.to_string();
    println!("{} {} {}", n + 1, text.len(), pi);
}
```

> **Key takeaway:** `String` is your text, and `&str` is a borrow. `r"..."` writes raw strings. `format!` joins texts, and `{}`, `{name}`, `{:.2}` and `{:?}` cover everyday formatting.
