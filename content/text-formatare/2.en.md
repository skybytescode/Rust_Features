# Text and formatting — Practitioner

Format specifiers for tables and reports, plus the `str` methods you use every day.

## Width, alignment and fill

After `:` you control how the value looks: `{:[fill][alignment][width]}`.

```rust
fn main() {
    println!("[{:10}]", "left");      // text: left-aligned by default
    println!("[{:>10}]", "right");
    println!("[{:^10}]", "center");
    println!("[{:*^10}]", "stars");   // filled with `*`
    println!("[{:5}]", 42);           // numbers: right-aligned by default
    println!("[{:<5}]", 42);
    println!("[{:05}]", 42);          // padded with zeros
    println!("[{:+}]", 42);           // the sign always shown
}
```

The width and precision can also come from variables:

```rust
fn main() {
    let width = 12;
    let decimals = 3;
    let x = 2.0_f64.sqrt();
    println!("[{x:>width$.decimals$}]");
    println!("[{:>1$.2$}]", x, 8, 1);
}
```

## An aligned table

```rust
fn main() {
    let products = [("Apples", 12, 4.5), ("Oranges", 3, 7.25), ("Kiwi", 40, 0.9)];
    println!("{:<12}{:>6}{:>10}", "Product", "Qty", "Price");
    println!("{}", "-".repeat(28));
    for (name, qty, price) in products {
        println!("{name:<12}{qty:>6}{price:>10.2}");
    }
}
```

## Number bases and scientific notation

```rust
fn main() {
    let n = 255;
    println!("{n:b} {n:o} {n:x} {n:X}");     // binary, octal, hex
    println!("{n:#b} {n:#x}");               // with a prefix: 0b..., 0x...
    println!("{n:#010b}");                   // prefix + padding to 10 characters
    println!("{:e} {:E}", 1234.5, 0.00012);  // scientific notation
}
```

## Useful `str` methods

```rust
fn main() {
    let text = "  Rust is Fast, Rust is Safe  ";

    println!("[{}]", text.trim());
    println!("{}", text.to_lowercase());
    println!("{}", text.replace("Rust", "🦀"));
    println!("{}", text.contains("Safe"));
    println!("{:?}", text.find("is"));                 // position in bytes
    println!("{}", text.trim().starts_with("Rust"));

    let words: Vec<&str> = text.split_whitespace().collect();
    println!("{words:?}");

    let (key, value) = "port=8080".split_once('=').unwrap();
    println!("{key} → {value}");

    for (i, line) in "one\ntwo\nthree".lines().enumerate() {
        println!("{i}: {line}");
    }
}
```

## Characters

```rust
fn main() {
    for c in ['a', 'Ü', '7', ' ', '🦀'] {
        println!(
            "{c:?}: letter {}, digit {}, uppercase {}, whitespace {}, {} bytes",
            c.is_alphabetic(),
            c.is_ascii_digit(),
            c.is_uppercase(),
            c.is_whitespace(),
            c.len_utf8()
        );
    }
    println!("{:?}", '7'.to_digit(10));
    println!("{}", 'ü'.to_uppercase());
}
```

## Building a `String` efficiently

`format!` in a loop allocates a new string every time. When you build a large text, write directly into the same `String`:

```rust
use std::fmt::Write;

fn main() {
    let mut report = String::with_capacity(256);
    for i in 1..=3 {
        writeln!(report, "row {i}: {}", i * i).unwrap(); // writes into the String, no new allocations
    }
    report.push_str("done");
    print!("{report}\n");
}
```

`write!` and `writeln!` work on any type that implements `std::fmt::Write`, including `String`.

> **Key takeaway:** `{:>10}`, `{:^10}`, `{:05}`, `{:.2}` and `{:#x}` cover almost any report. The width can come from variables, with `$`. On `str` you have `trim`, `split_once`, `lines`, `replace` and `find`, and `write!` into a `String` avoids repeated allocations.
