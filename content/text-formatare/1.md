# Text și formatare — Fundamente

Rust are două tipuri principale pentru text: `String`, textul pe care îl deții și îl poți modifica, și `&str`, o „privire” asupra unui text care aparține altcuiva. Pe lângă ele, macro-urile de formatare transformă orice valoare în text.

## `String` și `&str`

```rust
fn main() {
    let literal: &str = "salut";            // stocat în binar, nu poate fi modificat
    let mut propriu: String = String::from("salut");
    propriu.push_str(", lume");             // un String poate crește

    let vedere: &str = &propriu;            // un &str care privește în String
    println!("{literal} | {propriu} | {vedere}");
}
```

Regula practică: parametrii funcțiilor primesc `&str`, iar structurile și rezultatele noi folosesc `String`.

## Caractere speciale și string-uri brute

```rust
fn main() {
    println!("linie nouă:\nal doilea rând");
    println!("tab:\tdupă tab");
    println!("ghilimele: \"citat\" și backslash: \\");
    println!("unicode: \u{1F980}");

    // String brut: backslash-ul nu mai are rol special
    let cale = r"C:\Utilizatori\ana\fisier.txt";
    let cu_ghilimele = r#"el a spus "salut""#;
    println!("{cale}\n{cu_ghilimele}");
}
```

## Text pe mai multe rânduri

```rust
fn main() {
    let poezie = "Primul rând
al doilea rând";
    println!("{poezie}");

    // `\` la final de rând unește rândurile și sare peste spațiile de la început
    let lung = "Acesta este un text foarte lung \
                scris pe două rânduri în cod.";
    println!("{lung}");
}
```

## Lipirea textelor

```rust
fn main() {
    let prenume = "Ana";
    let nume = "Popescu";

    let a = String::from(prenume) + " " + nume;  // `+` consumă String-ul din stânga
    let b = format!("{prenume} {nume}");          // mai clar și nu consumă nimic
    let c = [prenume, nume].join(" ");            // pentru liste de texte

    println!("{a} | {b} | {c}");
}
```

`format!` e de obicei cea mai lizibilă variantă.

## Formatarea de bază

`println!`, `format!` și celelalte macro-uri de formatare înlocuiesc `{}` cu valori:

```rust
fn main() {
    let nume = "Mihai";
    let varsta = 31;
    let inaltime = 1.8234;

    println!("{} are {} ani", nume, varsta);   // după poziție
    println!("{nume} are {varsta} ani");       // variabila direct în text
    println!("{0} și {0} din nou", nume);      // același argument de două ori
    println!("{n} cm", n = 180);               // argument cu nume
    println!("înălțime: {inaltime:.2} m");     // 2 zecimale
    println!("{:?}", vec![1, 2, 3]);           // Debug: pentru structuri și colecții
}
```

| Scriere | Folosește trait-ul | Pentru |
|---|---|---|
| `{}` | `Display` | utilizatori: text frumos |
| `{:?}` | `Debug` | programatori: depanare |
| `{:#?}` | `Debug`, pe mai multe rânduri | structuri mari |

## Text în număr și număr în text

```rust
fn main() {
    let n: i32 = "42".parse().unwrap();
    let text = n.to_string();
    let pi = 3.14159_f64.to_string();
    println!("{} {} {}", n + 1, text.len(), pi);
}
```

> **De reținut:** `String` e textul tău, iar `&str` e un împrumut. `r"..."` scrie string-uri brute. `format!` lipește texte, iar `{}`, `{nume}`, `{:.2}` și `{:?}` acoperă formatarea de zi cu zi.
