# Traits și generics — Practician

Cum combini constrângerile, cum implementezi trait-urile standard pentru tipurile tale și cum îți faci tipurile să se integreze natural în limbaj.

## Mai multe constrângeri și `where`

Când constrângerile devin lungi, mută-le într-o clauză `where`:

```rust
use std::fmt::{Debug, Display};

fn raport<T, U>(eticheta: T, valori: &[U]) -> String
where
    T: Display,
    U: Debug + Clone,
{
    format!("{eticheta}: {:?}", valori.to_vec())
}

fn main() {
    println!("{}", raport("temperaturi", &[21.5, 23.0]));
}
```

## Structuri și implementări generice

```rust
#[derive(Debug)]
struct Stiva<T> {
    elemente: Vec<T>,
}

impl<T> Stiva<T> {
    fn new() -> Self {
        Stiva { elemente: Vec::new() }
    }
    fn push(&mut self, x: T) {
        self.elemente.push(x);
    }
    fn pop(&mut self) -> Option<T> {
        self.elemente.pop()
    }
    fn varf(&self) -> Option<&T> {
        self.elemente.last()
    }
}

fn main() {
    let mut s = Stiva::new();
    s.push("a");
    s.push("b");
    println!("vârf: {:?}", s.varf());
    println!("scos: {:?}", s.pop());
    println!("{s:?}");
}
```

## `Display`: afișare pentru utilizatori

`Debug` e pentru programatori și se poate deriva. `Display` e pentru utilizatori și trebuie scris manual:

```rust
use std::fmt;

struct Bani {
    bani: u64,
}

impl fmt::Display for Bani {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "{}.{:02} lei", self.bani / 100, self.bani % 100)
    }
}

fn main() {
    let pret = Bani { bani: 12_345 };
    println!("Total: {pret}");
    let text = pret.to_string(); // `to_string` vine gratuit din Display
    println!("{}", text.len());
}
```

## `From` și `Into`: conversii

Implementezi `From`, iar `Into` vine automat:

```rust
struct Celsius(f64);
struct Fahrenheit(f64);

impl From<Celsius> for Fahrenheit {
    fn from(c: Celsius) -> Self {
        Fahrenheit(c.0 * 9.0 / 5.0 + 32.0)
    }
}

fn main() {
    let f = Fahrenheit::from(Celsius(100.0));
    let g: Fahrenheit = Celsius(0.0).into();
    println!("{} {}", f.0, g.0);
}
```

## Supraîncărcarea operatorilor

Operatorii sunt trait-uri din `std::ops`: `+` este `Add`, `*` este `Mul`, `[]` este `Index`, iar `-x` este `Neg`:

```rust
use std::ops::{Add, Mul};

#[derive(Debug, Clone, Copy, PartialEq)]
struct Vector2 {
    x: f64,
    y: f64,
}

impl Add for Vector2 {
    type Output = Vector2;
    fn add(self, alt: Vector2) -> Vector2 {
        Vector2 { x: self.x + alt.x, y: self.y + alt.y }
    }
}

impl Mul<f64> for Vector2 {
    type Output = Vector2;
    fn mul(self, k: f64) -> Vector2 {
        Vector2 { x: self.x * k, y: self.y * k }
    }
}

fn main() {
    let a = Vector2 { x: 1.0, y: 2.0 };
    let b = Vector2 { x: 3.0, y: -1.0 };
    println!("{:?}", a + b);
    println!("{:?}", a * 3.0);
}
```

## `impl Trait` în tipul returnat

Când tipul concret e complicat sau imposibil de scris (un closure, un iterator compus), returnezi `impl Trait`:

```rust
fn multiplicator(k: i32) -> impl Fn(i32) -> i32 {
    move |x| x * k
}

fn patrate_impare(n: u32) -> impl Iterator<Item = u32> {
    (1..=n).filter(|x| x % 2 == 1).map(|x| x * x)
}

fn main() {
    let triplu = multiplicator(3);
    println!("{}", triplu(7));
    println!("{:?}", patrate_impare(9).collect::<Vec<_>>());
}
```

## `Default` și `PartialOrd` manual

Uneori comportamentul derivat nu e cel dorit, iar atunci implementezi trait-ul manual:

```rust
use std::cmp::Ordering;

#[derive(Debug, PartialEq)]
struct Versiune {
    major: u32,
    minor: u32,
}

impl Default for Versiune {
    fn default() -> Self {
        Versiune { major: 1, minor: 0 } // nu 0.0
    }
}

impl PartialOrd for Versiune {
    fn partial_cmp(&self, alta: &Self) -> Option<Ordering> {
        Some(self.major.cmp(&alta.major).then(self.minor.cmp(&alta.minor)))
    }
}

fn main() {
    let a = Versiune::default();
    let b = Versiune { major: 1, minor: 4 };
    println!("{a:?} < {b:?}: {}", a < b);
}
```

> **De reținut:** `where` face constrângerile lungi lizibile. Implementează `Display` pentru utilizatori, `From` pentru conversii și `std::ops` pentru operatori. `impl Trait` în tipul returnat ascunde tipurile greu de scris.
