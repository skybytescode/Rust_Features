# Traits și generics — Fundamente

Un **trait** descrie un comportament comun: un set de metode pe care un tip promite să le aibă. **Genericele** îți permit să scrii cod o singură dată pentru mai multe tipuri.

## Definirea unui trait

```rust
trait Descriere {
    fn descrie(&self) -> String;
}

struct Caine {
    nume: String,
}

struct Masina {
    marca: String,
    an: u16,
}

impl Descriere for Caine {
    fn descrie(&self) -> String {
        format!("câinele {}", self.nume)
    }
}

impl Descriere for Masina {
    fn descrie(&self) -> String {
        format!("un {} din {}", self.marca, self.an)
    }
}

fn main() {
    let c = Caine { nume: "Rex".into() };
    let m = Masina { marca: "Dacia".into(), an: 2020 };
    println!("{}", c.descrie());
    println!("{}", m.descrie());
}
```

## Metode cu implementare implicită

Un trait poate oferi o implementare implicită, pe care tipurile o pot păstra sau înlocui:

```rust
trait Salut {
    fn nume(&self) -> String;

    fn salut(&self) -> String {
        format!("Salut, {}!", self.nume()) // folosește metoda obligatorie
    }
}

struct Persoana(String);

impl Salut for Persoana {
    fn nume(&self) -> String {
        self.0.clone()
    }
    // `salut` vine gratuit din trait
}

fn main() {
    println!("{}", Persoana("Ana".into()).salut());
}
```

## Funcții generice

În loc să scrii câte o funcție pentru fiecare tip, scrii una generică. `<T>` este un tip care va fi stabilit la apel:

```rust
fn primul<T>(lista: &[T]) -> Option<&T> {
    lista.first()
}

fn main() {
    println!("{:?}", primul(&[10, 20, 30]));
    println!("{:?}", primul(&["a", "b"]));
    println!("{:?}", primul::<f64>(&[]));
}
```

## Constrângeri: „orice tip care știe să…”

Ca să faci ceva cu `T`, de exemplu să compari două valori, trebuie să ceri ca `T` să implementeze trait-ul potrivit:

```rust
fn cel_mai_mare<T: PartialOrd>(a: T, b: T) -> T {
    if a > b { a } else { b }
}

fn main() {
    println!("{}", cel_mai_mare(3, 9));
    println!("{}", cel_mai_mare(2.5, -1.0));
    println!("{}", cel_mai_mare("mere", "pere"));
}
```

Fără `T: PartialOrd`, compilatorul refuză `a > b`, pentru că nu orice tip poate fi comparat:

```rust,compile_fail
fn cel_mai_mare<T>(a: T, b: T) -> T {
    if a > b { a } else { b } // eroare E0369: `>` nu e definit pentru orice T
}

fn main() {
    println!("{}", cel_mai_mare(1, 2));
}
```

## Trait-uri ca parametri

Poți primi „orice tip care implementează un trait” cu `impl Trait`:

```rust
trait Arie {
    fn arie(&self) -> f64;
}

struct Patrat(f64);
struct Cerc(f64);

impl Arie for Patrat {
    fn arie(&self) -> f64 { self.0 * self.0 }
}

impl Arie for Cerc {
    fn arie(&self) -> f64 { 3.14159 * self.0 * self.0 }
}

fn afiseaza_aria(forma: &impl Arie) {
    println!("aria: {:.2}", forma.arie());
}

fn main() {
    afiseaza_aria(&Patrat(2.0));
    afiseaza_aria(&Cerc(1.0));
}
```

## Trait-uri din biblioteca standard

Multe operații obișnuite sunt de fapt trait-uri: `Display` pentru afișarea cu `{}`, `Debug` pentru `{:?}`, `Clone`, `PartialEq` pentru `==` și altele. Le poți implementa automat cu `#[derive]` sau manual, ca pe orice alt trait.

> **De reținut:** un trait e un set de metode pe care tipurile le implementează cu `impl Trait for Tip`. Genericele (`<T>`) scriu cod o singură dată, iar constrângerile (`T: Trait`) spun ce trebuie să știe să facă `T`.
