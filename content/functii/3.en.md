# Funcții — Avansat

Funcțiile sunt valori: le poți păstra în variabile, trimite ca argumente și returna. Asta deschide drumul spre generice, closures și funcții evaluate la compilare.

## Funcții ca valori

O funcție poate fi trimisă oriunde se așteaptă un **pointer la funcție**, cu tipul `fn(param) -> ret`:

```rust
fn dublu(x: i32) -> i32 { x * 2 }
fn patrat(x: i32) -> i32 { x * x }

fn aplica_de_doua_ori(f: fn(i32) -> i32, x: i32) -> i32 {
    f(f(x))
}

fn main() {
    let operatii: [(&str, fn(i32) -> i32); 2] = [("dublu", dublu), ("pătrat", patrat)];
    for (nume, op) in operatii {
        println!("{nume}: {}", aplica_de_doua_ori(op, 3));
    }
}
```

Closures care nu capturează nimic se pot converti și ele în `fn`. Cele care capturează nu se pot converti, iar pentru ele folosești genericele cu `Fn` (vezi capitolul Closures și iteratori).

## Funcții generice

O funcție generică e scrisă o singură dată și merge pentru orice tip care respectă constrângerile (trait bounds):

```rust
fn cel_mai_mare<T: PartialOrd + Copy>(valori: &[T]) -> Option<T> {
    let mut max = *valori.first()?;
    for &v in valori {
        if v > max { max = v; }
    }
    Some(max)
}

fn main() {
    println!("{:?}", cel_mai_mare(&[3, 9, 2]));
    println!("{:?}", cel_mai_mare(&[1.5, -0.5]));
    println!("{:?}", cel_mai_mare(&['a', 'z', 'm']));
}
```

## `impl Trait` în argumente și în tipul returnat

- În **argumente**, `impl Trait` e o prescurtare pentru un parametru generic: `fn f(x: impl Display)` înseamnă `fn f<T: Display>(x: T)`.
- În **tipul returnat**, `impl Trait` ascunde tipul concret. E singurul mod de a returna un closure sau un iterator compus fără `Box`.

```rust
use std::fmt::Display;

fn afiseaza(x: impl Display) {
    println!("[{x}]");
}

fn numere_pare(limita: u32) -> impl Iterator<Item = u32> {
    (0..limita).filter(|n| n % 2 == 0)
}

fn main() {
    afiseaza(42);
    afiseaza("text");
    let v: Vec<_> = numere_pare(10).collect();
    println!("{v:?}");
}
```

## Funcții care nu se întorc niciodată

O funcție cu tipul returnat `!` nu revine niciodată la apelant: dă panic, iese din proces sau rulează la nesfârșit. Apelul ei se potrivește cu orice tip:

```rust
fn eroare_fatala(mesaj: &str) -> ! {
    eprintln!("eroare: {mesaj}");
    std::process::exit(1)
}

fn main() {
    let port: u16 = match "8080".parse() {
        Ok(p) => p,
        Err(_) => eroare_fatala("port invalid"),
    };
    println!("{port}");
}
```

## `const fn`

O `const fn` poate fi apelată și la compilare, în `const`, `static` sau lungimi de array:

```rust
const fn kib(n: usize) -> usize {
    n * 1024
}

const BUFFER: usize = kib(4);

fn main() {
    let buffer = [0u8; BUFFER]; // lungimea e calculată la compilare
    println!("{} octeți; la runtime: {}", buffer.len(), kib(2));
}
```

Restricția: în corpul unei `const fn` poți folosi doar operații pe care compilatorul le poate evalua. Lista lor crește de la o versiune la alta.

## Recursivitate

Rust permite recursivitatea, dar **nu garantează** tail-call optimization. O recursivitate adâncă poate depăși stiva (stack overflow), așa că pentru adâncimi mari transformă algoritmul într-o buclă:

```rust
fn fibonacci(n: u32) -> u64 {
    let (mut a, mut b) = (0u64, 1u64);
    for _ in 0..n {
        (a, b) = (b, a + b);
    }
    a
}

fn main() {
    println!("{}", fibonacci(90));
}
```

> **De reținut:** funcțiile sunt valori de tip `fn(...)`. Genericele și `impl Trait` scriu cod o singură dată pentru mai multe tipuri. `-> !` marchează funcții care nu revin, `const fn` rulează și la compilare, iar recursivitatea nu are TCO garantat.
