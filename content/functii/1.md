# Funcții — Fundamente

O funcție grupează cod sub un nume, ca să-l poți folosi de mai multe ori. Ai folosit deja una: `main`, punctul de pornire al oricărui program.

## Definirea și apelul

O funcție se definește cu `fn`. Prin convenție, numele se scrie cu litere mici și underscore (`snake_case`):

```rust
fn saluta() {
    println!("Salut!");
}

fn main() {
    saluta();
    saluta();
}
```

Ordinea în fișier nu contează: poți apela o funcție definită mai jos.

## Parametri

Fiecare parametru are **obligatoriu** un tip. Compilatorul nu deduce tipurile parametrilor:

```rust
fn aria_dreptunghi(latime: u32, inaltime: u32) {
    println!("Aria este {}", latime * inaltime);
}

fn main() {
    aria_dreptunghi(3, 4);
}
```

## Valoarea returnată

Tipul returnat se scrie după `->`. Valoarea returnată este **ultima expresie** din corpul funcției, fără `;`:

```rust
fn patrat(x: i32) -> i32 {
    x * x // fără `;`: asta returnează funcția
}

fn main() {
    let rezultat = patrat(7);
    println!("{rezultat}");
}
```

Dacă pui `;` după ultima expresie, funcția nu mai returnează nimic, iar compilatorul îți spune exact unde e problema:

```rust,compile_fail
fn patrat(x: i32) -> i32 {
    x * x; // eroare E0308: `;` transformă expresia în instrucțiune
}

fn main() {
    println!("{}", patrat(7));
}
```

## `return` pentru ieșire devreme

`return` iese imediat din funcție. E util când vrei să tratezi un caz special la început:

```rust
fn imparte(a: f64, b: f64) -> f64 {
    if b == 0.0 {
        return 0.0;
    }
    a / b
}

fn main() {
    println!("{} {}", imparte(10.0, 4.0), imparte(1.0, 0.0));
}
```

## Instrucțiuni și expresii

- O **expresie** produce o valoare: `5`, `x + 1`, `patrat(3)`, chiar și un bloc `{ ... }`.
- O **instrucțiune** face o acțiune și nu produce valoare: `let x = 5;`, sau orice expresie urmată de `;`.

Diferența explică de ce `;` contează la finalul unei funcții.

## Funcțiile care nu returnează nimic

O funcție fără `->` returnează `()`, tipul „gol”. `fn saluta()` și `fn saluta() -> ()` înseamnă același lucru.

> **De reținut:** parametrii au întotdeauna tip explicit, iar tipul returnat vine după `->`. Ultima expresie fără `;` este valoarea returnată, iar `return` iese devreme.
