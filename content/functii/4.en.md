# Funcții — Expert

Ce este de fapt o funcție pentru compilator: un tip unic de mărime zero, un simbol în binar, o convenție de apel și o unitate de inlining.

## Fiecare funcție are propriul tip

Numele unei funcții nu are tipul `fn(i32) -> i32`. Are un **function item type** unic și anonim, de mărime zero. Conversia la pointer la funcție are loc abia când tipul o cere:

```rust
fn dublu(x: i32) -> i32 { x * 2 }
fn triplu(x: i32) -> i32 { x * 3 }

fn main() {
    let item = dublu;               // tip unic: fn(i32) -> i32 {dublu}
    let ptr: fn(i32) -> i32 = dublu; // pointer la funcție

    println!("item: {} octeți", size_of_val(&item)); // 0
    println!("ptr:  {} octeți", size_of_val(&ptr));  // 8 pe 64 de biți

    // `if` are nevoie de un tip comun, așa că cele două item-uri devin pointeri
    let f = if std::env::args().count() > 5 { dublu } else { triplu };
    println!("{}", f(10));
}
```

Fiindcă item-ul are mărime zero și tipul îl identifică exact, un generic `F: Fn(i32) -> i32` instanțiat cu `dublu` poate fi inline-uit complet. Un `fn(i32) -> i32` trece printr-un apel indirect, dacă optimizatorul nu reușește să-l elimine.

## Monomorphization

O funcție generică e compilată **separat pentru fiecare tip** cu care e folosită. Codul rezultat e rapid, fără apeluri indirecte, dar binarul crește. O tehnică frecventă în biblioteca standard este un „strat subțire” generic peste o funcție interioară non-generică:

```rust
use std::path::Path;

pub fn citeste<P: AsRef<Path>>(cale: P) -> std::io::Result<String> {
    // doar conversia e generică, restul se compilează o singură dată
    fn interior(cale: &Path) -> std::io::Result<String> {
        std::fs::read_to_string(cale)
    }
    interior(cale.as_ref())
}

fn main() {
    println!("{}", citeste("/fisier/inexistent").is_err());
}
```

`std::fs::read_to_string` este scris exact așa.

## Inlining între crate-uri

O funcție non-generică poate fi inline-uită în alt crate doar dacă e marcată cu `#[inline]` sau dacă e activat LTO. Funcțiile generice sunt instanțiate în crate-ul care le folosește, deci pot fi inline-uite oricum.

| Atribut | Efect |
|---|---|
| `#[inline]` | pune corpul la dispoziția altor crate-uri; e doar o sugestie |
| `#[inline(always)]` | sugestie puternică; tot nu e garantat |
| `#[inline(never)]` | împiedică inlining-ul (util la profilare și pentru căi reci) |

## Convenții de apel (ABI)

`extern "Rust"`, implicit, **nu are un ABI stabil**: modul în care sunt transmiși parametrii se poate schimba între versiunile compilatorului. Ca să comunici cu C sau cu alt limbaj, declari explicit `extern "C"`:

```rust
#[unsafe(no_mangle)]
pub extern "C" fn aduna(a: i32, b: i32) -> i32 {
    a + b
}

fn main() {
    // poate fi apelată și din Rust, ca orice funcție
    println!("{}", aduna(2, 3));
}
```

`#[no_mangle]` păstrează numele exact al simbolului în binar. În ediția 2024 trebuie scris `#[unsafe(no_mangle)]`, pentru că două simboluri cu același nume pot produce comportament nedefinit la linkare.

Un detaliu de ABI: valorile mari returnate de o funcție nu încap în registre. Apelantul rezervă spațiu pe stiva lui și trimite un pointer ascuns către el (*sret*), iar funcția scrie rezultatul direct acolo. De aceea returnarea unui struct mare prin valoare este, de obicei, ieftină.

## Name mangling

Ca să permită funcții cu același nume în module diferite și instanțe generice distincte, compilatorul codifică în simbol calea completă și parametrii generici. Schema implicită este încă cea „legacy”. Schema nouă, **v0**, se activează cu `-C symbol-mangling-version=v0` și păstrează mai multă informație, inclusiv tipurile generice. Uneltele ca `rustfilt` traduc simbolurile înapoi.

## `#[track_caller]` și `#[must_use]`

`#[track_caller]` face ca un panic să raporteze locația **apelantului**, nu pe cea din interiorul funcției. Așa funcționează `unwrap()`: mesajul arată linia ta, nu o linie din biblioteca standard.

```rust,should_panic
#[track_caller]
fn verifica_pozitiv(x: i32) -> i32 {
    if x <= 0 {
        panic!("se aștepta un număr pozitiv, s-a primit {x}");
    }
    x
}

fn main() {
    println!("{}", verifica_pozitiv(5));
    verifica_pozitiv(-1); // panic-ul raportează linia aceasta
}
```

`#[must_use]` produce un warning dacă rezultatul funcției e ignorat. Biblioteca standard îl pune pe `Result`, pe iteratori și pe multe metode care returnează o valoare nouă în loc să modifice ceva, de exemplu `str::trim`.

> **De reținut:** fiecare funcție are propriul tip de mărime zero, iar `fn(...)` e un pointer obișnuit. Genericele sunt monomorfizate, `#[inline]` contează la granița dintre crate-uri, iar `extern "C"` dă singurul ABI stabil.
