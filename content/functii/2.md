# Funcții — Practician

Cum îți proiectezi funcțiile: ce primesc, ce returnează și cum le legi de tipurile tale prin metode.

## Returnarea mai multor valori

O funcție returnează o singură valoare, dar aceasta poate fi un tuplu:

```rust
fn min_max(valori: &[i32]) -> (i32, i32) {
    let mut min = valori[0];
    let mut max = valori[0];
    for &v in valori {
        if v < min { min = v; }
        if v > max { max = v; }
    }
    (min, max)
}

fn main() {
    let (mic, mare) = min_max(&[4, -2, 9, 3]);
    println!("min {mic}, max {mare}");
}
```

Dacă valorile au o semnificație clară, un struct cu câmpuri numite e de obicei mai lizibil decât un tuplu.

## Când rezultatul poate lipsi

Funcția de mai sus dă panic pe o listă goală. Mai bine returnezi `Option`:

```rust
fn maxim(valori: &[i32]) -> Option<i32> {
    let mut iter = valori.iter();
    let mut max = *iter.next()?; // `?` returnează None dacă lista e goală
    for &v in iter {
        if v > max { max = v; }
    }
    Some(max)
}

fn main() {
    println!("{:?} {:?}", maxim(&[3, 8, 1]), maxim(&[]));
}
```

`Option` și `Result` sunt explicate pe larg în capitolul Gestionarea erorilor.

## Metode și funcții asociate

Funcțiile legate de un tip se pun într-un bloc `impl`:

- o **metodă** are ca prim parametru `self`, `&self` sau `&mut self` și se apelează cu punct: `cont.depune(50)`;
- o **funcție asociată** nu are `self` și se apelează cu `::`, de exemplu `Cont::nou()`. Prin convenție, constructorul se numește `new`.

```rust
struct Cont {
    titular: String,
    sold: u64,
}

impl Cont {
    fn new(titular: &str) -> Self {
        Cont { titular: titular.to_string(), sold: 0 }
    }

    fn depune(&mut self, suma: u64) {
        self.sold += suma;
    }

    fn sold(&self) -> u64 {
        self.sold
    }
}

fn main() {
    let mut cont = Cont::new("Ana");
    cont.depune(150);
    println!("{}: {}", cont.titular, cont.sold());
}
```

Alegi tipul lui `self` după aceleași reguli ca la orice parametru:

| Metoda | Folosește |
|---|---|
| doar citește | `&self` |
| modifică obiectul | `&mut self` |
| consumă obiectul (îl transformă sau îl distruge) | `self` |

## Documentarea funcțiilor

Comentariile cu `///` devin documentație, generată cu `cargo doc`. Într-o bibliotecă, exemplele de cod din documentația funcțiilor publice sunt compilate și rulate ca teste de `cargo test` (*doc tests*):

````rust
/// Calculează media aritmetică.
///
/// Returnează `None` dacă lista e goală.
///
/// ```
/// assert_eq!(media(&[2.0, 4.0]), Some(3.0));
/// ```
fn media(valori: &[f64]) -> Option<f64> {
    if valori.is_empty() {
        return None;
    }
    Some(valori.iter().sum::<f64>() / valori.len() as f64)
}

fn main() {
    println!("{:?}", media(&[1.0, 2.0, 6.0]));
}
````

## Funcții mici, cu un singur scop

- Ține funcțiile scurte. Dacă ai nevoie de un comentariu ca să explici ce face o porțiune din ea, mut-o într-o funcție separată cu un nume clar.
- Pentru parametri, preferă tipurile mai generale (`&str`, `&[T]`) în locul celor mai restrictive (`&String`, `&Vec<T>`). Vezi capitolul Ownership.
- Evită mulți parametri `bool`: `trimite(true, false)` nu spune nimic la citire. Un `enum` cu nume clare e mai bun.

> **De reținut:** returnează un tuplu sau un struct pentru valori multiple și `Option` când rezultatul poate lipsi. Metodele primesc `self` / `&self` / `&mut self`, iar funcțiile asociate, ca `new`, se apelează cu `::`.
