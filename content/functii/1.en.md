# Functions — Fundamentals

A function groups code under a name so you can use it more than once. You've already used one: `main`, the starting point of every program.

## Defining and calling

A function is defined with `fn`. By convention, its name is written in lowercase with underscores (`snake_case`):

```rust
fn greet() {
    println!("Hello!");
}

fn main() {
    greet();
    greet();
}
```

The order in the file doesn't matter: you can call a function defined further down.

## Parameters

Every parameter **must** have a type. The compiler doesn't infer parameter types:

```rust
fn rectangle_area(width: u32, height: u32) {
    println!("The area is {}", width * height);
}

fn main() {
    rectangle_area(3, 4);
}
```

## The return value

The return type is written after `->`. The returned value is the **last expression** in the function body, without `;`:

```rust
fn square(x: i32) -> i32 {
    x * x // no `;`: this is what the function returns
}

fn main() {
    let result = square(7);
    println!("{result}");
}
```

If you put `;` after the last expression, the function no longer returns anything, and the compiler tells you exactly where the problem is:

```rust,compile_fail
fn square(x: i32) -> i32 {
    x * x; // error E0308: `;` turns the expression into a statement
}

fn main() {
    println!("{}", square(7));
}
```

## `return` for an early exit

`return` leaves the function immediately. It's useful when you want to handle a special case at the start:

```rust
fn divide(a: f64, b: f64) -> f64 {
    if b == 0.0 {
        return 0.0;
    }
    a / b
}

fn main() {
    println!("{} {}", divide(10.0, 4.0), divide(1.0, 0.0));
}
```

## Statements and expressions

- An **expression** produces a value: `5`, `x + 1`, `square(3)`, even a block `{ ... }`.
- A **statement** performs an action and produces no value: `let x = 5;`, or any expression followed by `;`.

This difference explains why `;` matters at the end of a function.

## Functions that return nothing

A function without `->` returns `()`, the "empty" type. `fn greet()` and `fn greet() -> ()` mean the same thing.

> **Key takeaway:** parameters always have an explicit type, and the return type comes after `->`. The last expression without `;` is the returned value, and `return` exits early.
