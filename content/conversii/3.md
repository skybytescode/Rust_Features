# Conversii și tipuri dinamice — Avansat

Conversiile pe care compilatorul le face singur (coercițiile), diferența dintre `AsRef` și `Borrow` și tipurile dinamice: `Any` și downcasting.

## Coerciții: conversii implicite permise

Deși Rust nu face conversii numerice implicite, câteva conversii **între tipuri de pointeri** sunt automate, în anumite locuri: argumente de funcții, `let` cu tip explicit, valori returnate.

```rust
use std::fmt::Display;

fn lungime(s: &str) -> usize { s.len() }
fn suma(v: &[i32]) -> i32 { v.iter().sum() }
fn arata(x: &dyn Display) -> String { x.to_string() }

fn main() {
    let text = String::from("salut");
    let boxed: Box<String> = Box::new(String::from("cutie"));

    // 1. Deref coercion: &String → &str, &Box<String> → &String → &str
    println!("{} {}", lungime(&text), lungime(&boxed));

    // 2. Unsizing: &[i32; 3] → &[i32], &i32 → &dyn Display
    println!("{} {}", suma(&[1, 2, 3]), arata(&42));

    // 3. &mut T → &T
    let mut v = vec![1, 2];
    let r: &Vec<i32> = &mut v;
    println!("{r:?}");

    // 4. Box<T> → Box<dyn Trait>
    let forme: Vec<Box<dyn Display>> = vec![Box::new(1), Box::new("doi"), Box::new(3.0)];
    for f in &forme {
        print!("{f} ");
    }
    println!();
}
```

Deref coercion se aplică **în lanț**, de câte ori e nevoie, până tipurile se potrivesc. De aceea `&Box<String>` ajunge la `&str` fără nicio conversie scrisă.

## Regulile lui `as`, pe categorii

| Din | În | Comportament |
|---|---|---|
| întreg | întreg | trunchiere sau extensie de semn |
| real | întreg | saturează, iar NaN devine 0 |
| întreg / real | real | cea mai apropiată valoare |
| `bool` / `char` | întreg | `false = 0`, `true = 1` / codul Unicode |
| `u8` | `char` | doar din `u8`; pentru `u32` folosești `char::from_u32` |
| enum fără date | întreg | discriminantul |
| `&T` / `*const T` | `*const T` / `*const U` / `usize` | conversii de pointeri |

```rust
#[derive(Clone, Copy)]
enum Directie { Nord = 1, Sud = 2 }

fn main() {
    println!("{}", Directie::Sud as i32);
    println!("{:?}", char::from_u32(0x1F980));    // Some('🦀')
    println!("{:?}", char::from_u32(0xD800));     // None: surogat, nu e caracter valid
    let x = 5;
    let adresa = &x as *const i32 as usize;       // pointer → număr
    println!("{}", adresa % std::mem::align_of::<i32>() == 0);
    let _ = Directie::Nord;
}
```

## `AsRef` vs. `Borrow`

Ambele trait-uri dau o „privire” `&T` asupra unei valori, dar promit lucruri diferite:

- `AsRef<T>`: o conversie ieftină, fără alte garanții. `String: AsRef<[u8]>`, `String: AsRef<Path>`, `String: AsRef<str>`.
- `Borrow<T>`: în plus, `Hash`, `Eq` și `Ord` dau **același** rezultat pe valoarea originală și pe privire. De aceea `HashMap::get` cere `Borrow`, nu `AsRef`. Altfel, căutarea unei chei prin forma împrumutată ar putea da alt hash.

```rust
use std::borrow::Borrow;
use std::collections::HashMap;

fn cauta<Q>(m: &HashMap<String, u32>, cheie: &Q) -> Option<u32>
where
    String: Borrow<Q>,
    Q: std::hash::Hash + Eq + ?Sized,
{
    m.get(cheie).copied()
}

fn main() {
    let mut m = HashMap::new();
    m.insert("ana".to_string(), 30);
    println!("{:?}", cauta(&m, "ana"));               // cu &str
    println!("{:?}", cauta(&m, &"ana".to_string()));  // cu &String
}
```

## Tipuri dinamice: `Any`

`std::any::Any` permite întrebarea „ce tip concret e în spatele acestui `dyn`?” la runtime:

```rust
use std::any::{Any, type_name_of_val};

fn descrie(valoare: &dyn Any) -> String {
    if let Some(n) = valoare.downcast_ref::<i32>() {
        format!("un i32: {n}")
    } else if let Some(s) = valoare.downcast_ref::<String>() {
        format!("un String de {} caractere", s.len())
    } else {
        "un tip necunoscut".to_string()
    }
}

fn main() {
    let lista: Vec<Box<dyn Any>> = vec![Box::new(7), Box::new(String::from("rust")), Box::new(2.5)];
    for v in &lista {
        println!("{}", descrie(v.as_ref()));
    }

    // Box<dyn Any> se poate transforma înapoi în tipul concret
    let b: Box<dyn Any> = Box::new(String::from("recuperat"));
    match b.downcast::<String>() {
        Ok(s) => println!("{s}"),
        Err(_) => println!("alt tip"),
    }

    println!("{}", type_name_of_val(&lista)); // numele tipului, pentru depanare
}
```

`Any` funcționează doar pentru tipuri `'static`. Folosește-l cu măsură: un `enum` sau un trait cu metode e aproape întotdeauna un design mai bun decât testarea tipului la runtime.

> **De reținut:** coercițiile automate sunt deref (în lanț), unsizing (`[T; N]` → `[T]`, `T` → `dyn Trait`) și `&mut` → `&`. `Borrow` garantează un `Hash` și un `Eq` identice, pe când `AsRef` nu. `Any` + `downcast_ref` recuperează tipul concret la runtime, dar doar pentru tipuri `'static`.
