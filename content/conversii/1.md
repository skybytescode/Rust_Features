# Conversii și tipuri dinamice — Fundamente

În Rust, conversiile între tipuri sunt **explicite**: compilatorul nu transformă singur un `i32` într-un `f64` sau un număr în text. Aici vezi cele mai folosite unelte: `as`, `From` / `Into`, `parse` și `to_string`.

## `as` pentru numere

`as` convertește între tipurile numerice primitive:

```rust
fn main() {
    let intreg: i32 = 7;
    let real = intreg as f64 / 2.0;       // 3.5
    let rotunjit = 3.99_f64 as i32;       // 3: partea zecimală e tăiată
    let mic = 300_i32 as u8;              // 44: biții în plus sunt pierduți
    let litera = 65_u8 as char;           // 'A'
    let cod = 'A' as u32;                 // 65
    println!("{real} {rotunjit} {mic} {litera} {cod}");
}
```

`as` nu dă niciodată eroare, dar poate pierde informație în tăcere, ca la `300 → 44`. Pentru conversii care pot eșua există variante mai sigure, la nivelul următor.

## `From` și `Into`

`From` descrie o conversie care **reușește mereu**. Dacă ai `From`, primești automat și `Into`, în sens invers:

```rust
fn main() {
    let s1 = String::from("salut");      // &str → String
    let s2: String = "salut".into();     // aceeași conversie, prin Into
    let mare = i64::from(42_i32);        // i32 → i64: nu se pierde nimic
    let v = Vec::from([1, 2, 3]);        // array → Vec
    let real: f64 = 3_i32.into();        // i32 → f64
    println!("{s1} {s2} {mare} {v:?} {real}");
}
```

Cu `into()`, tipul destinație trebuie să fie clar din context, de exemplu dintr-o adnotare `: String`.

## Din text în număr și invers

```rust
fn main() {
    let n: u32 = "42".parse().unwrap();
    let x = "3.5".parse::<f64>().unwrap();
    let ok: bool = "true".parse().unwrap();

    let text = n.to_string();
    let altul = format!("{x:.1}");
    println!("{} {x} {ok} {text} {altul}", n * 2);

    match "abc".parse::<i32>() {
        Ok(v) => println!("număr {v}"),
        Err(e) => println!("nu e număr: {e}"),
    }
}
```

`parse` poate eșua, deci returnează un `Result`. `to_string` merge pe orice tip care implementează `Display`.

## Conversii între `Option` și `Result`

```rust
fn main() {
    let poate: Option<u8> = Some(3);
    let rezultat: Result<u8, &str> = poate.ok_or("lipsește");   // Option → Result
    let inapoi: Option<u8> = rezultat.ok();                     // Result → Option
    println!("{rezultat:?} {inapoi:?}");

    let gol: Option<u8> = None;
    println!("{:?}", gol.ok_or("lipsește"));
}
```

## Ce nu se convertește singur

Nici măcar două tipuri de numere întregi nu se combină automat:

```rust,compile_fail
fn main() {
    let a: i32 = 5;
    let b: i64 = 10;
    let c = a + b; // eroare E0308: i32 și i64 sunt tipuri diferite
}
```

Soluția e o conversie explicită: `i64::from(a) + b`.

> **De reținut:** conversiile sunt explicite. `as` convertește numere, dar poate pierde informație. `From` / `Into` sunt pentru conversii care reușesc mereu, iar `parse` și `to_string` fac legătura dintre text și valori.
