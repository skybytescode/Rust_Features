# Conversii și tipuri dinamice — Practician

Cum implementezi conversiile pentru tipurile tale și cum scrii funcții care acceptă mai multe tipuri de argumente.

## `From` pentru tipurile tale

```rust
#[derive(Debug)]
struct Celsius(f64);

#[derive(Debug)]
struct Fahrenheit(f64);

impl From<Celsius> for Fahrenheit {
    fn from(c: Celsius) -> Self {
        Fahrenheit(c.0 * 9.0 / 5.0 + 32.0)
    }
}

fn main() {
    let f = Fahrenheit::from(Celsius(100.0));
    let g: Fahrenheit = Celsius(-40.0).into(); // Into vine gratuit
    println!("{f:?} {g:?}");
}
```

Implementează mereu `From`, niciodată `Into` direct: implementarea blanket din biblioteca standard îți dă `Into` automat.

## `TryFrom` pentru conversii care pot eșua

```rust
use std::convert::TryFrom;

#[derive(Debug)]
struct Procent(u8);

impl TryFrom<i32> for Procent {
    type Error = String;

    fn try_from(v: i32) -> Result<Self, Self::Error> {
        if (0..=100).contains(&v) {
            Ok(Procent(v as u8))
        } else {
            Err(format!("{v} nu e între 0 și 100"))
        }
    }
}

fn main() {
    println!("{:?}", Procent::try_from(42));
    let r: Result<Procent, _> = 150.try_into();
    println!("{r:?}");

    // Biblioteca standard are TryFrom între toate tipurile întregi:
    println!("{:?}", u8::try_from(300_i32));
    println!("{:?}", u8::try_from(200_i32));
}
```

## `FromStr`: propriul tip compatibil cu `parse`

```rust
use std::str::FromStr;

#[derive(Debug)]
struct Punct {
    x: i32,
    y: i32,
}

impl FromStr for Punct {
    type Err = String;

    fn from_str(s: &str) -> Result<Self, Self::Err> {
        let (x, y) = s
            .trim_matches(|c| c == '(' || c == ')')
            .split_once(',')
            .ok_or("lipsește virgula")?;
        let x = x.trim().parse().map_err(|_| "x invalid")?;
        let y = y.trim().parse().map_err(|_| "y invalid")?;
        Ok(Punct { x, y })
    }
}

fn main() {
    let p: Punct = "(3, -4)".parse().unwrap();
    println!("{p:?}");
    println!("{:?}", "(3 -4)".parse::<Punct>());
}
```

## `Display` îți dă `to_string`

Orice tip cu `Display` primește automat `to_string()`:

```rust
use std::fmt;

struct Versiune(u32, u32, u32);

impl fmt::Display for Versiune {
    fn fmt(&self, f: &mut fmt::Formatter) -> fmt::Result {
        write!(f, "v{}.{}.{}", self.0, self.1, self.2)
    }
}

fn main() {
    let text: String = Versiune(1, 4, 2).to_string();
    println!("{text}");
}
```

## Parametri flexibili cu `AsRef` și `Into`

`AsRef<T>` înseamnă „pot fi privit ieftin ca un `&T`”. E ideal pentru funcții care doar citesc:

```rust
use std::path::Path;

fn are_extensia(cale: impl AsRef<Path>, ext: &str) -> bool {
    cale.as_ref().extension().is_some_and(|e| e == ext)
}

fn numara_litere(text: impl AsRef<str>) -> usize {
    text.as_ref().chars().filter(|c| c.is_alphabetic()).count()
}

fn main() {
    println!("{}", are_extensia("poza.jpg", "jpg"));                  // &str
    println!("{}", are_extensia(String::from("doc.pdf"), "jpg"));     // String
    println!("{}", are_extensia(Path::new("/tmp/a.jpg"), "jpg"));     // &Path
    println!("{} {}", numara_litere("ab1c"), numara_litere(String::from("xyz")));
}
```

`Into<T>` e potrivit când funcția **păstrează** valoarea, de exemplu într-un struct:

```rust
struct Utilizator {
    nume: String,
}

impl Utilizator {
    fn new(nume: impl Into<String>) -> Self {
        Utilizator { nume: nume.into() } // alocă doar dacă e nevoie
    }
}

fn main() {
    let a = Utilizator::new("Ana");               // &str → String
    let b = Utilizator::new(String::from("Ion")); // String: mutat, fără copie
    println!("{} {}", a.nume, b.nume);
}
```

| Funcția ta… | Primește |
|---|---|
| doar citește | `&str` / `&[T]`, sau `impl AsRef<...>` pentru flexibilitate |
| păstrează valoarea | `impl Into<String>` sau direct `String` |
| poate eșua la conversie | `impl TryInto<...>` |

> **De reținut:** implementează `From`, iar `Into` vine automat. `TryFrom` e pentru conversiile care pot eșua, iar `FromStr` face tipul compatibil cu `parse`. `AsRef` e potrivit pentru parametri doar citiți, `Into` pentru valori păstrate.
