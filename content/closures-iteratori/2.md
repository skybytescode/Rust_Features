# Closures și iteratori — Practician

Cum capturează closures variabilele, ce înseamnă `Fn`, `FnMut` și `FnOnce`, plus adaptoarele de iteratori pe care le vei folosi cel mai des.

## Cele trei moduri de captură

Un closure capturează fiecare variabilă în modul **minim** de care are nevoie:

- prin referință `&` dacă doar o citește: closure-ul este `Fn`;
- prin referință mutabilă `&mut` dacă o modifică: closure-ul este `FnMut`;
- prin valoare (move) dacă o consumă: closure-ul este `FnOnce`.

```rust
fn main() {
    let nume = String::from("Ana");
    let saluta = || println!("Salut, {nume}"); // Fn: doar citește
    saluta();
    saluta();

    let mut contor = 0;
    let mut incrementeaza = || contor += 1; // FnMut: modifică
    incrementeaza();
    incrementeaza();
    println!("contor = {contor}");

    let mesaj = String::from("o singură dată");
    let consuma = move || mesaj; // FnOnce: returnează String-ul capturat
    let m = consuma();
    // consuma(); // eroare: closure-ul a fost deja consumat
    println!("{m}");
}
```

## `move`: preia ownership-ul

Cu `move`, closure-ul preia toate variabilele capturate prin valoare. E obligatoriu când closure-ul trăiește mai mult decât funcția curentă, de exemplu într-un thread sau într-un closure returnat:

```rust
fn creeaza_contor() -> impl FnMut() -> u32 {
    let mut n = 0;
    move || {
        n += 1; // `n` aparține acum closure-ului
        n
    }
}

fn main() {
    let mut c = creeaza_contor();
    println!("{} {} {}", c(), c(), c());
}
```

## Funcții care primesc closures

Alege cea mai **permisivă** constrângere care îți ajunge. `FnOnce` acceptă orice closure, `FnMut` acceptă și `Fn`, iar `Fn` le acceptă doar pe cele care nu modifică nimic:

```rust
fn de_trei_ori<F: FnMut()>(mut f: F) {
    f();
    f();
    f();
}

fn o_data<F: FnOnce() -> String>(f: F) -> String {
    f()
}

fn main() {
    let mut log = Vec::new();
    de_trei_ori(|| log.push("pas"));
    println!("{log:?}");

    let s = String::from("mutat");
    println!("{}", o_data(move || s));
}
```

## `iter`, `iter_mut`, `into_iter`

| Metodă | Elemente | Colecția după |
|---|---|---|
| `iter()` | `&T` | neschimbată |
| `iter_mut()` | `&mut T` | modificată pe loc |
| `into_iter()` | `T` | consumată |

```rust
fn main() {
    let mut v = vec![String::from("a"), String::from("b")];

    for s in v.iter_mut() {
        s.push('!');
    }
    let lungimi: Vec<usize> = v.iter().map(|s| s.len()).collect();
    let mari: Vec<String> = v.into_iter().map(|s| s.to_uppercase()).collect();
    // `v` nu mai poate fi folosit aici
    println!("{lungimi:?} {mari:?}");
}
```

## Adaptoare frecvente

```rust
fn main() {
    let a = [1, 2, 3, 4, 5];
    let b = ["unu", "doi", "trei"];

    let perechi: Vec<_> = a.iter().zip(b.iter()).collect();      // perechi
    let primele: Vec<_> = a.iter().take(2).collect();             // primele N
    let fara_primele: Vec<_> = a.iter().skip(3).collect();        // sare peste N
    let pana_la: Vec<_> = a.iter().take_while(|&&x| x < 4).collect();
    let lipite: Vec<_> = a.iter().chain([10, 20].iter()).collect();
    let pasi: Vec<_> = (0..20).step_by(5).collect();

    println!("{perechi:?}\n{primele:?} {fara_primele:?} {pana_la:?}\n{lipite:?} {pasi:?}");
}
```

## `fold`: agregare generală

`fold` pornește de la o valoare inițială și o actualizează cu fiecare element. Este forma generală din care derivă `sum`, `count` și `max`:

```rust
fn main() {
    let cuvinte = ["rust", "este", "expresiv"];
    let total_litere = cuvinte.iter().fold(0, |acc, c| acc + c.len());
    let propozitie = cuvinte.iter().fold(String::new(), |mut acc, c| {
        if !acc.is_empty() {
            acc.push(' ');
        }
        acc.push_str(c);
        acc
    });
    println!("{total_litere} — {propozitie}");
}
```

## `filter_map` și `flat_map`

```rust
fn main() {
    let intrari = ["3", "x", "7", "", "10"];
    let numere: Vec<i32> = intrari.iter().filter_map(|s| s.parse().ok()).collect();
    println!("{numere:?}"); // doar cele valide

    let propozitii = ["unu doi", "trei"];
    let cuvinte: Vec<&str> = propozitii.iter().flat_map(|p| p.split(' ')).collect();
    println!("{cuvinte:?}"); // aplatizat
}
```

> **De reținut:** un closure capturează prin `&`, `&mut` sau prin valoare, după nevoie, iar `move` forțează captura prin valoare. Cere `FnOnce` / `FnMut` / `Fn` în ordinea asta a preferinței. `iter`, `iter_mut` și `into_iter` decid dacă elementele sunt împrumutate sau mutate.
