# Closures and iterators — Practitioner

How closures capture variables, what `Fn`, `FnMut` and `FnOnce` mean, plus the iterator adapters you'll use most often.

## The three capture modes

A closure captures each variable in the **minimal** mode it needs:

- by reference `&` if it only reads it: the closure is `Fn`;
- by mutable reference `&mut` if it modifies it: the closure is `FnMut`;
- by value (move) if it consumes it: the closure is `FnOnce`.

```rust
fn main() {
    let name = String::from("Ana");
    let greet = || println!("Hello, {name}"); // Fn: only reads
    greet();
    greet();

    let mut counter = 0;
    let mut increment = || counter += 1; // FnMut: modifies
    increment();
    increment();
    println!("counter = {counter}");

    let message = String::from("just once");
    let consume = move || message; // FnOnce: returns the captured String
    let m = consume();
    // consume(); // error: the closure has already been consumed
    println!("{m}");
}
```

## `move`: take ownership

With `move`, the closure takes all captured variables by value. It's required when the closure lives longer than the current function, for example in a thread or in a returned closure:

```rust
fn make_counter() -> impl FnMut() -> u32 {
    let mut n = 0;
    move || {
        n += 1; // `n` now belongs to the closure
        n
    }
}

fn main() {
    let mut c = make_counter();
    println!("{} {} {}", c(), c(), c());
}
```

## Functions that take closures

Choose the most **permissive** constraint that's enough for you. `FnOnce` accepts any closure, `FnMut` also accepts `Fn`, and `Fn` accepts only the ones that modify nothing:

```rust
fn three_times<F: FnMut()>(mut f: F) {
    f();
    f();
    f();
}

fn once<F: FnOnce() -> String>(f: F) -> String {
    f()
}

fn main() {
    let mut log = Vec::new();
    three_times(|| log.push("step"));
    println!("{log:?}");

    let s = String::from("moved");
    println!("{}", once(move || s));
}
```

## `iter`, `iter_mut`, `into_iter`

| Method | Elements | The collection afterwards |
|---|---|---|
| `iter()` | `&T` | unchanged |
| `iter_mut()` | `&mut T` | modified in place |
| `into_iter()` | `T` | consumed |

```rust
fn main() {
    let mut v = vec![String::from("a"), String::from("b")];

    for s in v.iter_mut() {
        s.push('!');
    }
    let lengths: Vec<usize> = v.iter().map(|s| s.len()).collect();
    let upper: Vec<String> = v.into_iter().map(|s| s.to_uppercase()).collect();
    // `v` can no longer be used here
    println!("{lengths:?} {upper:?}");
}
```

## Common adapters

```rust
fn main() {
    let a = [1, 2, 3, 4, 5];
    let b = ["one", "two", "three"];

    let pairs: Vec<_> = a.iter().zip(b.iter()).collect();     // pairs
    let first: Vec<_> = a.iter().take(2).collect();            // the first N
    let without_first: Vec<_> = a.iter().skip(3).collect();    // skips N
    let until: Vec<_> = a.iter().take_while(|&&x| x < 4).collect();
    let joined: Vec<_> = a.iter().chain([10, 20].iter()).collect();
    let steps: Vec<_> = (0..20).step_by(5).collect();

    println!("{pairs:?}\n{first:?} {without_first:?} {until:?}\n{joined:?} {steps:?}");
}
```

## `fold`: general aggregation

`fold` starts from an initial value and updates it with each element. It's the general form from which `sum`, `count` and `max` derive:

```rust
fn main() {
    let words = ["rust", "is", "expressive"];
    let total_letters = words.iter().fold(0, |acc, w| acc + w.len());
    let sentence = words.iter().fold(String::new(), |mut acc, w| {
        if !acc.is_empty() {
            acc.push(' ');
        }
        acc.push_str(w);
        acc
    });
    println!("{total_letters} — {sentence}");
}
```

## `filter_map` and `flat_map`

```rust
fn main() {
    let inputs = ["3", "x", "7", "", "10"];
    let numbers: Vec<i32> = inputs.iter().filter_map(|s| s.parse().ok()).collect();
    println!("{numbers:?}"); // only the valid ones

    let sentences = ["one two", "three"];
    let words: Vec<&str> = sentences.iter().flat_map(|s| s.split(' ')).collect();
    println!("{words:?}"); // flattened
}
```

> **Key takeaway:** a closure captures by `&`, `&mut` or by value, as needed, and `move` forces capture by value. Ask for `FnOnce` / `FnMut` / `Fn`, in that order of preference. `iter`, `iter_mut` and `into_iter` decide whether elements are borrowed or moved.
