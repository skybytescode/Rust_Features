# Closures and iterators — Fundamentals

A **closure** is a short, anonymous function that you can store in a variable. An **iterator** produces elements one at a time. Together, they let you process collections clearly and concisely.

## Closure syntax

The parameters go between vertical bars `|...|`, and the body follows them:

```rust
fn main() {
    let double = |x| x * 2;
    let add = |a: i32, b: i32| -> i32 { a + b }; // types written explicitly

    println!("{}", double(21));
    println!("{}", add(2, 3));
}
```

The parameter types are usually inferred automatically.

## Closures "see" the surrounding variables

Unlike ordinary functions, a closure can use the variables from the place where it was created:

```rust
fn main() {
    let threshold = 10;
    let above_threshold = |x: i32| x > threshold; // uses `threshold` from outside

    println!("{} {}", above_threshold(5), above_threshold(15));
}
```

## Iterators: elements one at a time

Every collection can produce an iterator with `.iter()`. You chain operations on top of it:

```rust
fn main() {
    let numbers = vec![1, 2, 3, 4, 5, 6];

    let even_squares: Vec<i32> = numbers
        .iter()
        .filter(|&&x| x % 2 == 0) // keeps only the even numbers
        .map(|&x| x * x)          // squares them
        .collect();               // gathers the result into a Vec

    println!("{even_squares:?}");
}
```

## The most used operations

| Method | What it does |
|---|---|
| `map(f)` | transforms each element |
| `filter(f)` | keeps the elements for which `f` returns `true` |
| `collect()` | gathers the elements into a collection |
| `sum()`, `count()` | adds up / counts |
| `min()`, `max()` | the smallest / largest element |
| `find(f)` | the first element that meets the condition |
| `any(f)`, `all(f)` | does any / do all meet the condition? |

```rust
fn main() {
    let prices = [12.5, 3.0, 45.0, 7.25];

    let total: f64 = prices.iter().sum();
    let expensive = prices.iter().filter(|&&p| p > 10.0).count();
    let first_cheap = prices.iter().find(|&&p| p < 5.0);
    let all_positive = prices.iter().all(|&p| p > 0.0);

    println!("total {total}, expensive {expensive}, cheap {first_cheap:?}, positive {all_positive}");
}
```

## Iterators are "lazy"

A chain of operations does nothing until you ask for the result with `collect`, `sum`, a `for` loop, and so on:

```rust
fn main() {
    let v = vec![1, 2, 3];
    let chain = v.iter().map(|x| {
        println!("processing {x}");
        x * 10
    });
    println!("nothing has been processed yet");
    let result: Vec<_> = chain.collect(); // only now does it run
    println!("{result:?}");
}
```

## `for` uses an iterator

The `for` loop also works with iterators, so you can combine the two:

```rust
fn main() {
    let names = ["Ana", "Mike", "Joan"];
    for (i, n) in names.iter().enumerate() {
        println!("{}. {n}", i + 1);
    }
}
```

> **Key takeaway:** `|x| expression` is a closure, and it can use the variables around it. `.iter()` produces an iterator on which you chain `map`, `filter` and others, and at the end you ask for the result with `collect` or `sum`. Without that final step, nothing runs.
