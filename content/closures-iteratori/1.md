# Closures și iteratori — Fundamente

Un **closure** este o funcție anonimă, scurtă, pe care o poți păstra într-o variabilă. Un **iterator** produce elemente unul câte unul. Împreună, îți permit să prelucrezi colecții clar și concis.

## Sintaxa unui closure

Parametrii stau între bare verticale `|...|`, iar corpul urmează după ele:

```rust
fn main() {
    let dublu = |x| x * 2;
    let aduna = |a: i32, b: i32| -> i32 { a + b }; // tipuri scrise explicit

    println!("{}", dublu(21));
    println!("{}", aduna(2, 3));
}
```

Tipurile parametrilor sunt de obicei deduse automat.

## Closures „văd” variabilele din jur

Spre deosebire de funcțiile obișnuite, un closure poate folosi variabilele din locul unde a fost creat:

```rust
fn main() {
    let prag = 10;
    let peste_prag = |x: i32| x > prag; // folosește `prag` din exterior

    println!("{} {}", peste_prag(5), peste_prag(15));
}
```

## Iteratori: elemente unul câte unul

Orice colecție poate produce un iterator cu `.iter()`. Peste el aplici operații în lanț:

```rust
fn main() {
    let numere = vec![1, 2, 3, 4, 5, 6];

    let pare_la_patrat: Vec<i32> = numere
        .iter()
        .filter(|&&x| x % 2 == 0) // păstrează doar numerele pare
        .map(|&x| x * x)          // ridică la pătrat
        .collect();               // adună rezultatul într-un Vec

    println!("{pare_la_patrat:?}");
}
```

## Cele mai folosite operații

| Metodă | Ce face |
|---|---|
| `map(f)` | transformă fiecare element |
| `filter(f)` | păstrează elementele pentru care `f` returnează `true` |
| `collect()` | adună elementele într-o colecție |
| `sum()`, `count()` | adună / numără |
| `min()`, `max()` | cel mai mic / cel mai mare element |
| `find(f)` | primul element care respectă condiția |
| `any(f)`, `all(f)` | există vreunul / toate respectă condiția? |

```rust
fn main() {
    let preturi = [12.5, 3.0, 45.0, 7.25];

    let total: f64 = preturi.iter().sum();
    let scumpe = preturi.iter().filter(|&&p| p > 10.0).count();
    let primul_ieftin = preturi.iter().find(|&&p| p < 5.0);
    let toate_pozitive = preturi.iter().all(|&p| p > 0.0);

    println!("total {total}, scumpe {scumpe}, ieftin {primul_ieftin:?}, pozitive {toate_pozitive}");
}
```

## Iteratorii sunt „leneși”

Un lanț de operații nu face nimic până nu ceri rezultatul cu `collect`, `sum`, o buclă `for` etc.:

```rust
fn main() {
    let v = vec![1, 2, 3];
    let lant = v.iter().map(|x| {
        println!("procesez {x}");
        x * 10
    });
    println!("încă nu s-a procesat nimic");
    let rezultat: Vec<_> = lant.collect(); // abia acum rulează
    println!("{rezultat:?}");
}
```

## `for` folosește un iterator

Bucla `for` lucrează tot cu iteratori, așa că poți combina cele două:

```rust
fn main() {
    let nume = ["Ana", "Mihai", "Ioana"];
    for (i, n) in nume.iter().enumerate() {
        println!("{}. {n}", i + 1);
    }
}
```

> **De reținut:** `|x| expresie` este un closure, iar el poate folosi variabilele din jur. `.iter()` produce un iterator, peste care înlănțuiești `map`, `filter` și altele, iar la final ceri rezultatul cu `collect` sau `sum`. Fără acest pas final, nu se execută nimic.
