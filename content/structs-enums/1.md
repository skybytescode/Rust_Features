# Structs și enums — Fundamente

Cu `struct` și `enum` îți definești propriile tipuri. Un **struct** grupează mai multe valori care merg împreună. Un **enum** descrie o valoare care poate fi una dintre mai multe variante.

## Definirea unui struct

```rust
struct Utilizator {
    nume: String,
    email: String,
    varsta: u32,
    activ: bool,
}

fn main() {
    let ana = Utilizator {
        nume: String::from("Ana"),
        email: String::from("ana@exemplu.ro"),
        varsta: 28,
        activ: true,
    };
    println!("{} are {} ani", ana.nume, ana.varsta);
}
```

Accesezi un câmp cu punct: `ana.nume`. Ca să modifici câmpuri, întreaga variabilă trebuie să fie `mut`. Nu există câmpuri mutabile individual.

## Prescurtări la creare

Când o variabilă are același nume ca un câmp, poți scrie numele o singură dată. Cu `..` copiezi restul câmpurilor dintr-o altă instanță:

```rust
struct Punct {
    x: i32,
    y: i32,
    z: i32,
}

fn main() {
    let x = 5;
    let p1 = Punct { x, y: 10, z: 0 }; // `x` în loc de `x: x`
    let p2 = Punct { z: 7, ..p1 };     // restul câmpurilor vin din p1
    println!("({}, {}, {})", p2.x, p2.y, p2.z);
}
```

## Tuple structs și unit structs

Un **tuple struct** are câmpuri fără nume. E util când numele tipului spune deja tot:

```rust
struct Culoare(u8, u8, u8);
struct Metri(f64);

fn main() {
    let rosu = Culoare(255, 0, 0);
    let distanta = Metri(42.5);
    println!("R = {}, distanța = {}", rosu.0, distanta.0);
}
```

Un **unit struct** nu are câmpuri: `struct Marcaj;`. Îl folosești când ai nevoie de un tip, dar nu și de date.

## Metode

Funcțiile care lucrează cu un struct se pun într-un bloc `impl`:

```rust
struct Dreptunghi {
    latime: u32,
    inaltime: u32,
}

impl Dreptunghi {
    fn aria(&self) -> u32 {
        self.latime * self.inaltime
    }

    fn este_patrat(&self) -> bool {
        self.latime == self.inaltime
    }
}

fn main() {
    let d = Dreptunghi { latime: 4, inaltime: 3 };
    println!("aria {}, pătrat: {}", d.aria(), d.este_patrat());
}
```

## Enums: una dintre mai multe variante

Un enum enumeră variantele posibile ale unei valori:

```rust
enum Directie {
    Nord,
    Sud,
    Est,
    Vest,
}

fn descrie(d: Directie) -> &'static str {
    match d {
        Directie::Nord => "sus",
        Directie::Sud => "jos",
        Directie::Est => "dreapta",
        Directie::Vest => "stânga",
    }
}

fn main() {
    println!("{}", descrie(Directie::Est));
}
```

## Variante cu date

Spre deosebire de multe alte limbaje, în Rust fiecare variantă a unui enum poate avea date proprii:

```rust
enum Forma {
    Cerc(f64),                       // raza
    Dreptunghi { lat: f64, inalt: f64 },
    Punct,
}

fn aria(f: &Forma) -> f64 {
    match f {
        Forma::Cerc(r) => 3.14159 * r * r,
        Forma::Dreptunghi { lat, inalt } => lat * inalt,
        Forma::Punct => 0.0,
    }
}

fn main() {
    let forme = [Forma::Cerc(1.0), Forma::Dreptunghi { lat: 2.0, inalt: 3.0 }, Forma::Punct];
    for f in &forme {
        println!("{:.2}", aria(f));
    }
}
```

## `Option`: un enum din biblioteca standard

Rust nu are `null`. Când o valoare poate lipsi, folosești `Option<T>`, care are două variante: `Some(valoare)` și `None`:

```rust
fn main() {
    let gasit: Option<u32> = Some(7);
    let lipsa: Option<u32> = None;

    for o in [gasit, lipsa] {
        match o {
            Some(n) => println!("am găsit {n}"),
            None => println!("nimic"),
        }
    }
}
```

Compilatorul nu te lasă să folosești un `Option<u32>` ca pe un `u32`. Trebuie să tratezi explicit cazul `None`, așa că erorile de tip „null pointer” nu pot apărea.

> **De reținut:** un `struct` grupează câmpuri, iar un `enum` alege una dintre variante, fiecare putând avea propriile date. Metodele se scriu în `impl`, iar `Option` înlocuiește `null`.
