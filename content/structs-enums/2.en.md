# Structs și enums — Practician

Cum faci ca tipurile tale să se comporte ca tipurile din biblioteca standard: le afișezi, le compari, le copiezi și le protejezi invarianții.

## `#[derive]`: comportament gata făcut

Multe trait-uri standard pot fi implementate automat:

```rust
#[derive(Debug, Clone, PartialEq, Default)]
struct Setari {
    volum: u8,
    limba: String,
    notificari: bool,
}

fn main() {
    let implicit = Setari::default();       // toate câmpurile au valoarea implicită
    let mut ale_mele = implicit.clone();
    ale_mele.volum = 80;

    println!("{implicit:?}");               // Debug
    println!("{ale_mele:#?}");              // Debug, afișat pe mai multe rânduri
    println!("egale? {}", implicit == ale_mele); // PartialEq
}
```

| Trait | Ce îți dă |
|---|---|
| `Debug` | afișare cu `{:?}`, pentru depanare |
| `Clone` | `.clone()` |
| `Copy` | copiere implicită (doar dacă toate câmpurile sunt `Copy`) |
| `PartialEq`, `Eq` | `==` și `!=` |
| `PartialOrd`, `Ord` | `<`, `>`, sortare |
| `Hash` | folosire ca cheie în `HashMap` |
| `Default` | `T::default()` |

## Câmpuri private și constructori

Câmpurile sunt **private** implicit: în afara modulului unde e definit struct-ul nu le poți citi direct. Un constructor `new` îți garantează că orice instanță e validă:

```rust
mod temperatura {
    pub struct Celsius {
        grade: f64, // privat: nu poate fi setat direct din afară
    }

    impl Celsius {
        pub fn new(grade: f64) -> Option<Celsius> {
            if grade < -273.15 {
                None // sub zero absolut: invalid
            } else {
                Some(Celsius { grade })
            }
        }

        pub fn grade(&self) -> f64 {
            self.grade
        }
    }
}

fn main() {
    use temperatura::Celsius;
    println!("{:?}", Celsius::new(21.5).map(|t| t.grade()));
    println!("{}", Celsius::new(-300.0).is_none());
}
```

## Enums în loc de combinații de `bool`

Un tip cu mai multe `bool` poate ajunge în stări fără sens. Un enum descrie exact stările posibile:

```rust
// Problematic: ce înseamnă incarcat = true și eroare = true în același timp?
#[allow(dead_code)]
struct DescarcareProasta {
    incarcat: bool,
    eroare: bool,
    procent: u8,
}

// Mai bine: o singură stare la un moment dat, fiecare cu datele ei
#[derive(Debug)]
enum Descarcare {
    InAsteptare,
    InCurs { procent: u8 },
    Terminata { octeti: u64 },
    Esuata(String),
}

fn main() {
    let stari = [
        Descarcare::InAsteptare,
        Descarcare::InCurs { procent: 40 },
        Descarcare::Terminata { octeti: 1024 },
        Descarcare::Esuata("timeout".into()),
    ];
    for s in &stari {
        println!("{s:?}");
    }
}
```

## Metode pe enums

Enum-urile pot avea metode, la fel ca structurile:

```rust
#[derive(Debug, Clone, Copy, PartialEq)]
enum Semafor {
    Rosu,
    Galben,
    Verde,
}

impl Semafor {
    fn urmator(self) -> Semafor {
        match self {
            Semafor::Rosu => Semafor::Verde,
            Semafor::Verde => Semafor::Galben,
            Semafor::Galben => Semafor::Rosu,
        }
    }

    fn poti_trece(self) -> bool {
        self == Semafor::Verde
    }
}

fn main() {
    let mut s = Semafor::Rosu;
    for _ in 0..4 {
        println!("{s:?}: poți trece? {}", s.poti_trece());
        s = s.urmator();
    }
}
```

## Metode utile pe `Option`

În loc de `match` peste tot, `Option` are metode pentru cazurile frecvente:

```rust
fn main() {
    let port: Option<u16> = None;
    println!("{}", port.unwrap_or(8080));          // valoare implicită

    let nume: Option<&str> = Some("ana");
    println!("{:?}", nume.map(|n| n.to_uppercase())); // transformă dacă există

    let varsta: Option<u32> = Some(17);
    println!("{:?}", varsta.filter(|&v| v >= 18));    // păstrează doar dacă respectă condiția

    if let Some(n) = nume {
        println!("salut, {n}");
    }
}
```

> **De reținut:** `#[derive]` îți dă `Debug`, `Clone`, `PartialEq` și alte trait-uri gratuit. Câmpurile private plus un constructor garantează că instanțele sunt valide. Un enum descrie stările posibile mai sigur decât o combinație de `bool`-uri.
