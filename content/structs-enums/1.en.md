# Structs and enums — Fundamentals

With `struct` and `enum` you define your own types. A **struct** groups several values that belong together. An **enum** describes a value that can be one of several variants.

## Defining a struct

```rust
struct User {
    name: String,
    email: String,
    age: u32,
    active: bool,
}

fn main() {
    let ana = User {
        name: String::from("Ana"),
        email: String::from("ana@example.com"),
        age: 28,
        active: true,
    };
    println!("{} is {} years old", ana.name, ana.age);
}
```

You access a field with a dot: `ana.name`. To modify fields, the whole variable must be `mut`. There are no individually mutable fields.

## Creation shortcuts

When a variable has the same name as a field, you can write the name only once. With `..` you copy the remaining fields from another instance:

```rust
struct Point {
    x: i32,
    y: i32,
    z: i32,
}

fn main() {
    let x = 5;
    let p1 = Point { x, y: 10, z: 0 }; // `x` instead of `x: x`
    let p2 = Point { z: 7, ..p1 };     // the other fields come from p1
    println!("({}, {}, {})", p2.x, p2.y, p2.z);
}
```

## Tuple structs and unit structs

A **tuple struct** has unnamed fields. It's useful when the type's name already says it all:

```rust
struct Color(u8, u8, u8);
struct Meters(f64);

fn main() {
    let red = Color(255, 0, 0);
    let distance = Meters(42.5);
    println!("R = {}, distance = {}", red.0, distance.0);
}
```

A **unit struct** has no fields: `struct Marker;`. You use it when you need a type, but no data.

## Methods

Functions that work with a struct go in an `impl` block:

```rust
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn area(&self) -> u32 {
        self.width * self.height
    }

    fn is_square(&self) -> bool {
        self.width == self.height
    }
}

fn main() {
    let r = Rectangle { width: 4, height: 3 };
    println!("area {}, square: {}", r.area(), r.is_square());
}
```

## Enums: one of several variants

An enum lists the possible variants of a value:

```rust
enum Direction {
    North,
    South,
    East,
    West,
}

fn describe(d: Direction) -> &'static str {
    match d {
        Direction::North => "up",
        Direction::South => "down",
        Direction::East => "right",
        Direction::West => "left",
    }
}

fn main() {
    println!("{}", describe(Direction::East));
}
```

## Variants with data

Unlike many other languages, in Rust each variant of an enum can carry its own data:

```rust
enum Shape {
    Circle(f64),                       // the radius
    Rectangle { width: f64, height: f64 },
    Point,
}

fn area(s: &Shape) -> f64 {
    match s {
        Shape::Circle(r) => 3.14159 * r * r,
        Shape::Rectangle { width, height } => width * height,
        Shape::Point => 0.0,
    }
}

fn main() {
    let shapes = [Shape::Circle(1.0), Shape::Rectangle { width: 2.0, height: 3.0 }, Shape::Point];
    for s in &shapes {
        println!("{:.2}", area(s));
    }
}
```

## `Option`: an enum from the standard library

Rust has no `null`. When a value can be missing, you use `Option<T>`, which has two variants: `Some(value)` and `None`:

```rust
fn main() {
    let found: Option<u32> = Some(7);
    let missing: Option<u32> = None;

    for o in [found, missing] {
        match o {
            Some(n) => println!("found {n}"),
            None => println!("nothing"),
        }
    }
}
```

The compiler won't let you use an `Option<u32>` as a `u32`. You must handle the `None` case explicitly, so "null pointer" errors can't happen.

> **Key takeaway:** a `struct` groups fields, and an `enum` picks one of several variants, each of which can have its own data. Methods are written in `impl`, and `Option` replaces `null`.
