# Structs și enums — Avansat

Modele de design care folosesc sistemul de tipuri ca să facă stările invalide imposibil de construit.

## Structuri generice

Un struct poate fi generic peste unul sau mai multe tipuri. Poți implementa metode pentru toate tipurile sau doar pentru unele:

```rust
#[derive(Debug)]
struct Pereche<T> {
    a: T,
    b: T,
}

impl<T: PartialOrd> Pereche<T> {
    fn maxim(&self) -> &T {
        if self.a >= self.b { &self.a } else { &self.b }
    }
}

impl Pereche<f64> {
    fn media(&self) -> f64 {
        (self.a + self.b) / 2.0
    }
}

fn main() {
    let numere = Pereche { a: 3, b: 9 };
    let reale = Pereche { a: 1.5, b: 2.5 };
    println!("{} {} {}", numere.maxim(), reale.maxim(), reale.media());
    // numere.media() nu există: metoda e definită doar pentru Pereche<f64>
}
```

## Builder pattern

Când un tip are multe câmpuri opționale, un **builder** e mai clar decât un constructor cu zece parametri:

```rust
#[derive(Debug)]
struct Cerere {
    url: String,
    metoda: String,
    timeout_s: u32,
    reincercari: u8,
}

struct CerereBuilder {
    cerere: Cerere,
}

impl CerereBuilder {
    fn new(url: &str) -> Self {
        CerereBuilder {
            cerere: Cerere { url: url.into(), metoda: "GET".into(), timeout_s: 30, reincercari: 0 },
        }
    }
    fn metoda(mut self, m: &str) -> Self { self.cerere.metoda = m.into(); self }
    fn timeout(mut self, s: u32) -> Self { self.cerere.timeout_s = s; self }
    fn reincercari(mut self, n: u8) -> Self { self.cerere.reincercari = n; self }
    fn build(self) -> Cerere { self.cerere }
}

fn main() {
    let c = CerereBuilder::new("https://exemplu.ro").metoda("POST").timeout(5).build();
    println!("{c:?}");
}
```

Fiecare metodă primește `self` prin valoare și îl returnează, așa că apelurile se pot înlănțui fără `mut` la apelant.

## Typestate: starea codificată în tip

Poți face ca anumite operații să fie disponibile **doar** în anumite stări, verificat la compilare. Fiecare stare e un tip separat:

```rust,compile_fail
struct Deconectat;
struct Conectat;

struct Conexiune<Stare> {
    adresa: String,
    _stare: Stare,
}

impl Conexiune<Deconectat> {
    fn new(adresa: &str) -> Self {
        Conexiune { adresa: adresa.into(), _stare: Deconectat }
    }
    fn conecteaza(self) -> Conexiune<Conectat> {
        Conexiune { adresa: self.adresa, _stare: Conectat }
    }
}

impl Conexiune<Conectat> {
    fn trimite(&self, mesaj: &str) {
        println!("către {}: {mesaj}", self.adresa);
    }
}

fn main() {
    let c = Conexiune::new("server:80");
    c.trimite("salut"); // eroare E0599: `trimite` nu există pentru Conexiune<Deconectat>
}
```

Cu `let c = Conexiune::new("server:80").conecteaza();`, apelul compilează. Cum `conecteaza` consumă `self`, vechea conexiune „deconectată” nu mai poate fi folosită după aceea.

## Discriminanți expliciți

Un enum fără date poate avea valori numerice explicite, iar `as` le convertește în întregi:

```rust
#[derive(Debug, Clone, Copy)]
#[repr(u16)]
enum CodHttp {
    Ok = 200,
    NotFound = 404,
    Eroare = 500,
}

impl TryFrom<u16> for CodHttp {
    type Error = u16;
    fn try_from(cod: u16) -> Result<Self, u16> {
        match cod {
            200 => Ok(CodHttp::Ok),
            404 => Ok(CodHttp::NotFound),
            500 => Ok(CodHttp::Eroare),
            alt => Err(alt),
        }
    }
}

fn main() {
    println!("{}", CodHttp::NotFound as u16);
    println!("{:?} {:?}", CodHttp::try_from(500), CodHttp::try_from(418));
}
```

Conversia inversă, din întreg în enum, nu poate fi făcută cu `as`, pentru că nu orice număr e o variantă validă. De aceea ai nevoie de `TryFrom`.

## `#[non_exhaustive]`: loc pentru variante viitoare

Într-o bibliotecă, adăugarea unei variante noi strică orice `match` exhaustiv scris de utilizatori. Cu `#[non_exhaustive]`, codul **din alte crate-uri** e obligat să aibă o ramură `_`, așa că poți adăuga variante fără breaking change:

```rust
#[non_exhaustive]
#[derive(Debug)]
pub enum Eroare {
    Retea,
    Permisiune,
}

fn main() {
    // În crate-ul care definește enum-ul, match-ul exhaustiv e permis.
    // Într-un alt crate, `_ => ...` ar fi obligatoriu.
    let e = Eroare::Retea;
    match e {
        Eroare::Retea => println!("rețea"),
        Eroare::Permisiune => println!("permisiune"),
    }
}
```

Atributul merge și pe structuri: împiedică crearea lor cu sintaxa `Struct { ... }` din alte crate-uri și te lasă să adaugi câmpuri.

> **De reținut:** genericele cu `impl` specializat adaugă metode doar pentru unele tipuri. Builder-ul și typestate-ul mută verificările la compilare. `#[repr(u16)]` fixează discriminanții, iar `#[non_exhaustive]` îți lasă loc de evoluție.
