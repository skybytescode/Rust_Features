# Colecții — Fundamente

Colecțiile păstrează mai multe valori și, spre deosebire de array-uri, pot crește sau scădea în timpul rulării. Cele mai folosite trei sunt `Vec`, `String` și `HashMap`.

## `Vec<T>`: o listă care crește

```rust
fn main() {
    let mut numere: Vec<i32> = Vec::new();
    numere.push(10);
    numere.push(20);
    numere.push(30);

    let culori = vec!["roșu", "verde", "albastru"]; // macro-ul vec! creează direct

    println!("{numere:?}, are {} elemente", numere.len());
    println!("prima culoare: {}", culori[0]);
}
```

## Citirea unui element

Ai două moduri: indexul `v[i]`, care dă **panic** dacă elementul nu există, și metoda `get(i)`, care returnează un `Option`:

```rust
fn main() {
    let v = vec![1, 2, 3];
    println!("{}", v[1]);       // 2
    println!("{:?}", v.get(1));  // Some(2)
    println!("{:?}", v.get(99)); // None: nu dă panic
}
```

## Parcurgere și modificare

```rust
fn main() {
    let mut note = vec![7, 8, 10];

    for n in &note {
        print!("{n} ");
    }
    println!();

    for n in &mut note {
        *n += 1; // `*` accesează valoarea din spatele referinței
    }
    println!("{note:?}");

    let ultima = note.pop(); // scoate ultimul element
    println!("scos: {ultima:?}, rămas: {note:?}");
}
```

## `String`: text care poate crește

```rust
fn main() {
    let mut salut = String::from("Bună");
    salut.push_str(", lume");
    salut.push('!');
    println!("{salut}");

    let nume = "Ana";
    let mesaj = format!("{salut} Sunt {nume}."); // format! creează un String nou
    println!("{mesaj}");
    println!("lungime în octeți: {}", mesaj.len());
}
```

`String` e textul tău, pe care îl poți modifica. `&str` e o „privire” spre un text care aparține altcuiva, de exemplu un literal `"..."`.

## `HashMap<K, V>`: perechi cheie–valoare

```rust
use std::collections::HashMap;

fn main() {
    let mut stoc: HashMap<String, u32> = HashMap::new();
    stoc.insert(String::from("mere"), 50);
    stoc.insert(String::from("pere"), 20);

    match stoc.get("mere") {
        Some(n) => println!("mere: {n}"),
        None => println!("nu avem mere"),
    }

    stoc.insert(String::from("mere"), 45); // suprascrie valoarea veche

    for (fruct, cantitate) in &stoc {
        println!("{fruct}: {cantitate}");
    }
}
```

Ordinea elementelor dintr-un `HashMap` nu e garantată și poate diferi de la o rulare la alta.

## Numărarea cuvintelor

Un exemplu clasic care combină `String`, `HashMap` și iterarea:

```rust
use std::collections::HashMap;

fn main() {
    let text = "rust e rapid și rust e sigur";
    let mut frecventa = HashMap::new();
    for cuvant in text.split_whitespace() {
        *frecventa.entry(cuvant).or_insert(0) += 1;
    }
    println!("„rust” apare de {} ori", frecventa["rust"]);
}
```

`entry(...).or_insert(0)` înseamnă „ia valoarea pentru cheia asta sau pune 0 dacă nu există”. Detaliile sunt la nivelul următor.

> **De reținut:** `Vec` este lista care crește, `String` este textul modificabil, iar `HashMap` asociază chei cu valori. `get` returnează `Option`, pe când indexarea dă panic dacă elementul lipsește.
