# Colecții — Practician

Operațiile pe care le vei folosi zilnic și cum alegi colecția potrivită.

## Operații frecvente pe `Vec`

```rust
fn main() {
    let mut v = vec![5, 3, 8, 3, 1, 8];

    v.sort();                    // [1, 3, 3, 5, 8, 8]
    v.dedup();                   // elimină duplicatele consecutive: [1, 3, 5, 8]
    v.retain(|&x| x != 5);       // păstrează doar ce respectă condiția: [1, 3, 8]
    v.insert(1, 2);              // inserează la poziția 1: [1, 2, 3, 8]
    let scos = v.remove(0);      // scoate de la poziția 0
    v.extend([9, 10]);           // adaugă mai multe elemente

    println!("{v:?}, scos: {scos}");
    println!("conține 8? {}", v.contains(&8));
    println!("primele două: {:?}", &v[..2]); // slice
}
```

`insert` și `remove` mută toate elementele de după poziție, deci sunt O(n). Dacă ordinea nu contează, `swap_remove` e O(1).

## Capacitate

Un `Vec` rezervă mai mult spațiu decât folosește, ca să nu realoce la fiecare `push`. Dacă știi dinainte câte elemente vor fi, rezervă de la început:

```rust
fn main() {
    let mut v = Vec::with_capacity(1000);
    for i in 0..1000 {
        v.push(i); // nicio realocare
    }
    println!("len {}, capacitate {}", v.len(), v.capacity());
}
```

## `String` și `&str`

| | `String` | `&str` |
|---|---|---|
| Deține datele | da | nu, e un împrumut |
| Poate fi modificat | da (`push_str`, `clear`…) | nu |
| Folosit pentru | rezultate noi, câmpuri în structuri | parametri, literali |

Textul e stocat ca UTF-8, așa că o literă poate ocupa mai mulți octeți. De aceea nu poți indexa direct un `String`. Parcurgi caracterele cu `.chars()`:

```rust
fn main() {
    let s = String::from("Brașov");
    println!("{} octeți, {} caractere", s.len(), s.chars().count());

    let primele_trei: String = s.chars().take(3).collect();
    println!("{primele_trei}");

    for (i, c) in s.char_indices() {
        print!("{i}:{c} ");
    }
    println!();

    println!("{}", s.to_uppercase());
    println!("{:?}", "a,b,,c".split(',').collect::<Vec<_>>());
}
```

## Entry API pentru `HashMap`

`entry` evită două căutări (una pentru „există?” și una pentru „inserează”):

```rust
use std::collections::HashMap;

fn main() {
    let elevi = [("Ana", 9), ("Mihai", 7), ("Ana", 10), ("Ioana", 8), ("Mihai", 6)];

    let mut note: HashMap<&str, Vec<u32>> = HashMap::new();
    for (nume, nota) in elevi {
        note.entry(nume).or_default().push(nota);
    }

    let mut nume: Vec<_> = note.keys().collect();
    nume.sort();
    for n in nume {
        let lista = &note[n];
        let media = lista.iter().sum::<u32>() as f64 / lista.len() as f64;
        println!("{n}: {lista:?}, media {media:.2}");
    }
}
```

## Alte colecții standard

| Colecție | Când o folosești |
|---|---|
| `Vec<T>` | implicit, pentru aproape orice listă |
| `VecDeque<T>` | adaugi și scoți la ambele capete (cozi) |
| `HashMap<K, V>` | căutare rapidă după cheie |
| `BTreeMap<K, V>` | ai nevoie de chei sortate sau de căutare pe intervale |
| `HashSet<T>` / `BTreeSet<T>` | valori unice, fără asocieri |
| `BinaryHeap<T>` | scoți mereu cel mai mare element (cozi cu priorități) |

```rust
use std::collections::{BTreeMap, HashSet, VecDeque};

fn main() {
    let mut coada = VecDeque::new();
    coada.push_back("client 1");
    coada.push_back("client 2");
    coada.push_front("urgent");
    println!("{:?}", coada.pop_front());

    let vizitati: HashSet<&str> = ["Cluj", "Iași", "Cluj"].into_iter().collect();
    println!("{} orașe unice", vizitati.len());

    let mut clasament = BTreeMap::new();
    clasament.insert(3, "bronz");
    clasament.insert(1, "aur");
    clasament.insert(2, "argint");
    println!("{clasament:?}"); // mereu sortat după cheie
}
```

> **De reținut:** `sort`, `dedup`, `retain` și `extend` acoperă majoritatea nevoilor. Folosește `with_capacity` când știi mărimea. Textul se parcurge cu `chars()`, nu prin indexare, iar `entry` inserează sau actualizează dintr-o singură căutare.
