# Collections — Fundamentals

Collections hold several values and, unlike arrays, can grow or shrink while the program runs. The three most used are `Vec`, `String` and `HashMap`.

## `Vec<T>`: a list that grows

```rust
fn main() {
    let mut numbers: Vec<i32> = Vec::new();
    numbers.push(10);
    numbers.push(20);
    numbers.push(30);

    let colors = vec!["red", "green", "blue"]; // the vec! macro creates it directly

    println!("{numbers:?}, has {} elements", numbers.len());
    println!("first color: {}", colors[0]);
}
```

## Reading an element

There are two ways: the index `v[i]`, which **panics** if the element doesn't exist, and the `get(i)` method, which returns an `Option`:

```rust
fn main() {
    let v = vec![1, 2, 3];
    println!("{}", v[1]);       // 2
    println!("{:?}", v.get(1));  // Some(2)
    println!("{:?}", v.get(99)); // None: no panic
}
```

## Iterating and modifying

```rust
fn main() {
    let mut grades = vec![7, 8, 10];

    for g in &grades {
        print!("{g} ");
    }
    println!();

    for g in &mut grades {
        *g += 1; // `*` accesses the value behind the reference
    }
    println!("{grades:?}");

    let last = grades.pop(); // removes the last element
    println!("removed: {last:?}, left: {grades:?}");
}
```

## `String`: text that can grow

```rust
fn main() {
    let mut greeting = String::from("Hello");
    greeting.push_str(", world");
    greeting.push('!');
    println!("{greeting}");

    let name = "Ana";
    let message = format!("{greeting} I'm {name}."); // format! creates a new String
    println!("{message}");
    println!("length in bytes: {}", message.len());
}
```

`String` is your own text, which you can modify. `&str` is a "view" of text that belongs to someone else, for example a literal `"..."`.

## `HashMap<K, V>`: key–value pairs

```rust
use std::collections::HashMap;

fn main() {
    let mut stock: HashMap<String, u32> = HashMap::new();
    stock.insert(String::from("apples"), 50);
    stock.insert(String::from("pears"), 20);

    match stock.get("apples") {
        Some(n) => println!("apples: {n}"),
        None => println!("no apples"),
    }

    stock.insert(String::from("apples"), 45); // overwrites the old value

    for (fruit, quantity) in &stock {
        println!("{fruit}: {quantity}");
    }
}
```

The order of the elements in a `HashMap` isn't guaranteed and can differ from one run to the next.

## Counting words

A classic example combining `String`, `HashMap` and iteration:

```rust
use std::collections::HashMap;

fn main() {
    let text = "rust is fast and rust is safe";
    let mut frequency = HashMap::new();
    for word in text.split_whitespace() {
        *frequency.entry(word).or_insert(0) += 1;
    }
    println!("\"rust\" appears {} times", frequency["rust"]);
}
```

`entry(...).or_insert(0)` means "take the value for this key, or insert 0 if it doesn't exist". The details are in the next level.

> **Key takeaway:** `Vec` is the list that grows, `String` is modifiable text, and `HashMap` associates keys with values. `get` returns an `Option`, while indexing panics if the element is missing.
