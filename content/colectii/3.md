# Colecții — Avansat

Complexitatea operațiilor, căutările fără alocări, cheile personalizate și câteva tehnici mai puțin cunoscute.

## Complexitate

| Operație | `Vec` | `VecDeque` | `HashMap` | `BTreeMap` |
|---|---|---|---|---|
| acces după index / cheie | O(1) | O(1) | O(1) mediu | O(log n) |
| adăugare la final | O(1) amortizat | O(1) amortizat | O(1) mediu | O(log n) |
| adăugare la început | O(n) | O(1) amortizat | — | — |
| inserare la mijloc | O(n) | O(n) | — | — |
| parcurgere ordonată | — | — | nu | da |

„Amortizat” înseamnă că, deși o realocare costă O(n), capacitatea crește geometric, așa că media pe operație rămâne O(1).

## Căutare cu `&str` într-un `HashMap<String, _>`

Nu trebuie să creezi un `String` ca să cauți. `get` acceptă orice tip `Q` pentru care cheia implementează `Borrow<Q>`, iar `String: Borrow<str>`:

```rust
use std::collections::HashMap;

fn main() {
    let mut capitale: HashMap<String, String> = HashMap::new();
    capitale.insert("România".to_string(), "București".to_string());

    let tara: &str = "România";
    println!("{:?}", capitale.get(tara)); // fără alocare
}
```

Contractul lui `Borrow` cere ca `Hash`, `Eq` și `Ord` să dea același rezultat pentru `String` și pentru `str`. De aceea există `Borrow` separat de `AsRef`.

## Chei personalizate

Pentru `HashMap`, cheia trebuie să implementeze `Hash + Eq`. Pentru `BTreeMap`, trebuie să implementeze `Ord`. Cel mai simplu e cu `derive`:

```rust
use std::collections::{BTreeMap, HashMap};

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, PartialOrd, Ord)]
struct Pozitie {
    rand: u8,
    coloana: u8,
}

fn main() {
    let mut tabla = HashMap::new();
    tabla.insert(Pozitie { rand: 0, coloana: 4 }, "rege");

    let mut ordonat = BTreeMap::new();
    ordonat.insert(Pozitie { rand: 1, coloana: 0 }, "pion");
    ordonat.insert(Pozitie { rand: 0, coloana: 7 }, "turn");

    println!("{:?}", tabla.get(&Pozitie { rand: 0, coloana: 4 }));
    println!("{ordonat:?}"); // ordonat după `rand`, apoi după `coloana`
}
```

`derive(PartialOrd, Ord)` compară câmpurile **în ordinea declarării**.

## Interogări pe intervale

`BTreeMap` și `BTreeSet` răspund rapid la întrebări de tipul „toate cheile dintre A și B” sau „cea mai apropiată cheie”:

```rust
use std::collections::BTreeMap;

fn main() {
    let mut evenimente = BTreeMap::new();
    for (ora, ce) in [(9, "ședință"), (12, "prânz"), (14, "demo"), (18, "sport")] {
        evenimente.insert(ora, ce);
    }

    let dupa_amiaza: Vec<_> = evenimente.range(12..18).collect();
    println!("{dupa_amiaza:?}");

    let urmatorul = evenimente.range(13..).next();
    println!("după ora 13: {urmatorul:?}");
}
```

## Coadă cu priorități

`BinaryHeap` scoate mereu **cel mai mare** element. Pentru un min-heap, învelește valorile în `std::cmp::Reverse`:

```rust
use std::cmp::Reverse;
use std::collections::BinaryHeap;

fn main() {
    let mut sarcini = BinaryHeap::new();
    sarcini.push((2, "scrie raportul"));
    sarcini.push((5, "repară serverul"));
    sarcini.push((1, "cafea"));
    while let Some((prioritate, sarcina)) = sarcini.pop() {
        println!("[{prioritate}] {sarcina}");
    }

    let mut min = BinaryHeap::from([Reverse(7), Reverse(3), Reverse(9)]);
    println!("cel mai mic: {:?}", min.pop().map(|Reverse(x)| x));
}
```

## `drain`, `split_off` și căutare binară

```rust
fn main() {
    let mut v: Vec<i32> = (1..=10).collect();

    let primele: Vec<_> = v.drain(..3).collect(); // scoate și returnează un interval
    let coada = v.split_off(4);                    // împarte vectorul în două
    println!("{primele:?} {v:?} {coada:?}");

    let sortat = [1, 3, 5, 7, 9];
    println!("{:?}", sortat.binary_search(&7)); // Ok(3): găsit la indexul 3
    println!("{:?}", sortat.binary_search(&4)); // Err(2): s-ar insera la indexul 2
}
```

## Ordonarea după o cheie

```rust
fn main() {
    let mut oameni = vec![("Mihai", 34), ("Ana", 28), ("Ioana", 34)];

    oameni.sort_by_key(|&(_, varsta)| varsta);
    println!("{oameni:?}"); // stabil: Mihai rămâne înaintea Ioanei

    oameni.sort_by(|a, b| b.1.cmp(&a.1).then(a.0.cmp(b.0)));
    println!("{oameni:?}"); // vârstă descrescător, apoi nume crescător
}
```

`sort` / `sort_by` sunt **stabile**: elementele egale își păstrează ordinea relativă. `sort_unstable` e puțin mai rapidă și nu alocă memorie suplimentară.

> **De reținut:** alege colecția după operațiile dominante. Caută cu `&str` în chei `String` datorită lui `Borrow`. `BTreeMap::range` oferă interogări pe intervale, iar `BinaryHeap` cu `Reverse` îți dă un min-heap.
