# Advanced generics — Practitioner

Three tools that make generics much more expressive: associated constants, generic parameters with default values, and *const generics*, meaning generics over values, not just over types.

## Associated constants

A trait or an `impl` can contain constants, just like methods:

```rust
trait Shape {
    const SIDES: u32;
    const NAME: &'static str;

    fn description(&self) -> String {
        format!("a {} with {} sides", Self::NAME, Self::SIDES)
    }
}

struct Triangle;
struct Square;

impl Shape for Triangle {
    const SIDES: u32 = 3;
    const NAME: &'static str = "triangle";
}

impl Shape for Square {
    const SIDES: u32 = 4;
    const NAME: &'static str = "square";
}

struct Circle {
    radius: f64,
}

impl Circle {
    const PI: f64 = 3.141592653589793; // a constant associated with a type, no trait

    fn area(&self) -> f64 {
        Self::PI * self.radius * self.radius
    }
}

fn main() {
    println!("{}", Triangle.description());
    println!("{}", Square.description());
    println!("{:.2}", Circle { radius: 2.0 }.area());
    println!("{}", u8::MAX); // the standard library uses associated constants too
}
```

## Generic parameters with a default value

A generic parameter can have a default type. `Add` from the standard library is defined as `trait Add<Rhs = Self>`: unless you say otherwise, you add a type to itself.

```rust
use std::ops::Add;

#[derive(Debug, Clone, Copy)]
struct Meters(f64);
#[derive(Debug, Clone, Copy)]
struct Centimeters(f64);

impl Add for Meters {               // Rhs = Self, the default
    type Output = Meters;
    fn add(self, other: Meters) -> Meters { Meters(self.0 + other.0) }
}

impl Add<Centimeters> for Meters {  // Rhs chosen explicitly
    type Output = Meters;
    fn add(self, other: Centimeters) -> Meters { Meters(self.0 + other.0 / 100.0) }
}

fn main() {
    println!("{:?}", Meters(1.0) + Meters(2.0));
    println!("{:?}", Meters(1.0) + Centimeters(50.0));
}
```

Default parameters are used to evolve an API: you can add a new parameter without breaking existing code. `HashMap<K, V, S = RandomState>` is built exactly this way.

## Const generics: generics over values

A `const N: usize` parameter makes a type or a function generic over a **number**. The classic example: functions that work for arrays of any length.

```rust
fn sum<const N: usize>(values: [i32; N]) -> i32 {
    values.iter().sum()
}

fn first_and_last<T: Copy, const N: usize>(a: [T; N]) -> Option<(T, T)> {
    if N == 0 { None } else { Some((a[0], a[N - 1])) }
}

fn main() {
    println!("{}", sum([1, 2, 3]));          // N = 3
    println!("{}", sum([10; 8]));            // N = 8
    println!("{:?}", first_and_last(['a', 'b', 'c']));
    println!("{:?}", first_and_last::<u8, 0>([]));
}
```

## Structs with fixed dimensions

With const generics, the dimension is part of the type. The compiler checks the dimensions, with no runtime checks:

```rust
#[derive(Debug, Clone, Copy)]
struct Matrix<const R: usize, const C: usize> {
    data: [[i32; C]; R],
}

impl<const R: usize, const C: usize> Matrix<R, C> {
    fn transpose(&self) -> Matrix<C, R> {
        let mut t = [[0; R]; C];
        for i in 0..R {
            for j in 0..C {
                t[j][i] = self.data[i][j];
            }
        }
        Matrix { data: t }
    }
}

fn main() {
    let m = Matrix { data: [[1, 2, 3], [4, 5, 6]] }; // Matrix<2, 3>
    let t = m.transpose();                          // Matrix<3, 2>
    println!("{:?}", t.data);
}
```

```rust,compile_fail
struct Vector<const N: usize>([f64; N]);

fn dot<const N: usize>(a: &Vector<N>, b: &Vector<N>) -> f64 {
    a.0.iter().zip(&b.0).map(|(x, y)| x * y).sum()
}

fn main() {
    let a = Vector([1.0, 2.0, 3.0]);
    let b = Vector([1.0, 2.0]);
    dot(&a, &b); // error E0308: Vector<3> and Vector<2> are different types
}
```

## Complex `where` clauses

```rust
use std::collections::HashMap;
use std::fmt::Debug;
use std::hash::Hash;

fn frequencies<I, T>(items: I) -> Vec<(T, usize)>
where
    I: IntoIterator<Item = T>,
    T: Hash + Eq + Ord + Debug,
{
    let mut m = HashMap::new();
    for e in items {
        *m.entry(e).or_insert(0) += 1;
    }
    let mut v: Vec<_> = m.into_iter().collect();
    v.sort();
    v
}

fn main() {
    println!("{:?}", frequencies("abracadabra".chars()));
    println!("{:?}", frequencies(vec![3, 1, 3, 3]));
}
```

> **Key takeaway:** associated constants (`const X: T`) go in traits and in `impl` blocks. Default parameters (`<Rhs = Self>`) let APIs evolve. With const generics (`<const N: usize>`), dimensions are part of the type and are checked at compile time.
