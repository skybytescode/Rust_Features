# Advanced generics — Fundamentals

Generics let you write a type or a function once, for several types. You've already met them in `Vec<T>`, `Option<T>` and `Result<T, E>`. Here you'll see how to build your own generic types.

## Generic types you already use

`Option` and `Result` are simple generic enums from the standard library:

```rust
// This is essentially how they're defined:
// enum Option<T> { Some(T), None }
// enum Result<T, E> { Ok(T), Err(E) }

fn main() {
    let a: Option<i32> = Some(5);
    let b: Option<&str> = Some("text");
    let c: Result<f64, String> = Ok(2.5);
    println!("{a:?} {b:?} {c:?}");
}
```

The same enum works for any type: `T` is a placeholder, filled in when it's used.

## Your own generic struct

```rust
#[derive(Debug)]
struct Boxed<T> {
    contents: T,
}

impl<T> Boxed<T> {
    fn new(contents: T) -> Self {
        Boxed { contents }
    }

    fn open(self) -> T {
        self.contents
    }
}

fn main() {
    let number = Boxed::new(42);
    let text = Boxed::new("hello");
    println!("{number:?} {text:?}");
    println!("{}", number.open() + 1);
}
```

`impl<T>` says: "these methods exist for `Boxed<T>`, whatever `T` is".

## Several generic parameters

```rust
#[derive(Debug)]
struct Pair<A, B> {
    left: A,
    right: B,
}

impl<A, B> Pair<A, B> {
    fn swap(self) -> Pair<B, A> {
        Pair { left: self.right, right: self.left }
    }
}

fn main() {
    let p = Pair { left: "age", right: 30 };
    println!("{:?}", p.swap());
}
```

## Your own generic enums

```rust
#[derive(Debug)]
enum Answer<T> {
    Found(T),
    Missing,
    Error(String),
}

fn search(id: u32) -> Answer<&'static str> {
    match id {
        1 => Answer::Found("Ana"),
        0 => Answer::Error("invalid id".into()),
        _ => Answer::Missing,
    }
}

fn main() {
    for id in [1, 2, 0] {
        println!("{:?}", search(id));
    }
}
```

## When the compiler can't guess the type

The generic type is usually inferred from the values. When there aren't enough hints, you write it explicitly, in the declaration or with the *turbofish* `::<>`:

```rust
fn main() {
    let empty: Vec<String> = Vec::new();       // in the declaration
    let also_empty = Vec::<u8>::new();         // turbofish on the type
    let n = "12".parse::<u64>().unwrap();      // turbofish on the function
    let sum = [1, 2, 3].iter().sum::<i32>();
    println!("{} {} {n} {sum}", empty.len(), also_empty.len());
}
```

## Constraints: what `T` must be able to do

A generic without constraints can do almost nothing with `T`. With `T: Trait` you require the type to have a certain capability:

```rust
use std::fmt::Display;

fn show_twice<T: Display>(x: T) {
    println!("{x} {x}");
}

fn main() {
    show_twice(7);
    show_twice("echo");
}
```

> **Key takeaway:** `struct Name<T>` and `enum Name<T>` declare generic types, and `impl<T>` adds methods to them. You can have several parameters (`<A, B>`). When the type can't be inferred, you write it with `::<>`. `T: Trait` constraints say what `T` can do.
