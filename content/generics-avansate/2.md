# Generics avansate — Practician

Trei unelte care fac genericele mult mai expresive: constante asociate, parametri generici cu valori implicite și *const generics*, adică generice peste valori, nu doar peste tipuri.

## Constante asociate

Un trait sau un `impl` poate conține constante, la fel ca metode:

```rust
trait Forma {
    const LATURI: u32;
    const NUME: &'static str;

    fn descriere(&self) -> String {
        format!("{} cu {} laturi", Self::NUME, Self::LATURI)
    }
}

struct Triunghi;
struct Patrat;

impl Forma for Triunghi {
    const LATURI: u32 = 3;
    const NUME: &'static str = "triunghi";
}

impl Forma for Patrat {
    const LATURI: u32 = 4;
    const NUME: &'static str = "pătrat";
}

struct Cerc {
    raza: f64,
}

impl Cerc {
    const PI: f64 = 3.141592653589793; // constantă asociată unui tip, fără trait

    fn arie(&self) -> f64 {
        Self::PI * self.raza * self.raza
    }
}

fn main() {
    println!("{}", Triunghi.descriere());
    println!("{}", Patrat.descriere());
    println!("{:.2}", Cerc { raza: 2.0 }.arie());
    println!("{}", u8::MAX); // și biblioteca standard folosește constante asociate
}
```

## Parametri generici cu valoare implicită

Un parametru generic poate avea un tip implicit. `Add` din biblioteca standard e definit ca `trait Add<Rhs = Self>`: dacă nu spui altfel, aduni un tip cu el însuși.

```rust
use std::ops::Add;

#[derive(Debug, Clone, Copy)]
struct Metri(f64);
#[derive(Debug, Clone, Copy)]
struct Centimetri(f64);

impl Add for Metri {              // Rhs = Self, implicit
    type Output = Metri;
    fn add(self, alt: Metri) -> Metri { Metri(self.0 + alt.0) }
}

impl Add<Centimetri> for Metri {  // Rhs ales explicit
    type Output = Metri;
    fn add(self, alt: Centimetri) -> Metri { Metri(self.0 + alt.0 / 100.0) }
}

fn main() {
    println!("{:?}", Metri(1.0) + Metri(2.0));
    println!("{:?}", Metri(1.0) + Centimetri(50.0));
}
```

Parametrii impliciți se folosesc la evoluția unui API: poți adăuga un parametru nou fără să strici codul existent. `HashMap<K, V, S = RandomState>` e construit exact așa.

## Const generics: generice peste valori

Un parametru `const N: usize` face ca un tip sau o funcție să fie generică peste un **număr**. Exemplul clasic: funcții care merg pentru array-uri de orice lungime.

```rust
fn suma<const N: usize>(valori: [i32; N]) -> i32 {
    valori.iter().sum()
}

fn primul_si_ultimul<T: Copy, const N: usize>(a: [T; N]) -> Option<(T, T)> {
    if N == 0 { None } else { Some((a[0], a[N - 1])) }
}

fn main() {
    println!("{}", suma([1, 2, 3]));         // N = 3
    println!("{}", suma([10; 8]));           // N = 8
    println!("{:?}", primul_si_ultimul(['a', 'b', 'c']));
    println!("{:?}", primul_si_ultimul::<u8, 0>([]));
}
```

## Structuri cu dimensiuni fixe

Cu const generics, dimensiunea face parte din tip. Compilatorul verifică dimensiunile, fără verificări la runtime:

```rust
#[derive(Debug, Clone, Copy)]
struct Matrice<const R: usize, const C: usize> {
    date: [[i32; C]; R],
}

impl<const R: usize, const C: usize> Matrice<R, C> {
    fn transpusa(&self) -> Matrice<C, R> {
        let mut t = [[0; R]; C];
        for i in 0..R {
            for j in 0..C {
                t[j][i] = self.date[i][j];
            }
        }
        Matrice { date: t }
    }
}

fn main() {
    let m = Matrice { date: [[1, 2, 3], [4, 5, 6]] }; // Matrice<2, 3>
    let t = m.transpusa();                           // Matrice<3, 2>
    println!("{:?}", t.date);
}
```

```rust,compile_fail
struct Vector<const N: usize>([f64; N]);

fn produs_scalar<const N: usize>(a: &Vector<N>, b: &Vector<N>) -> f64 {
    a.0.iter().zip(&b.0).map(|(x, y)| x * y).sum()
}

fn main() {
    let a = Vector([1.0, 2.0, 3.0]);
    let b = Vector([1.0, 2.0]);
    produs_scalar(&a, &b); // eroare E0308: Vector<3> și Vector<2> sunt tipuri diferite
}
```

## Clauze `where` complexe

```rust
use std::collections::HashMap;
use std::fmt::Debug;
use std::hash::Hash;

fn frecvente<I, T>(elemente: I) -> Vec<(T, usize)>
where
    I: IntoIterator<Item = T>,
    T: Hash + Eq + Ord + Debug,
{
    let mut m = HashMap::new();
    for e in elemente {
        *m.entry(e).or_insert(0) += 1;
    }
    let mut v: Vec<_> = m.into_iter().collect();
    v.sort();
    v
}

fn main() {
    println!("{:?}", frecvente("abracadabra".chars()));
    println!("{:?}", frecvente(vec![3, 1, 3, 3]));
}
```

> **De reținut:** constantele asociate (`const X: T`) se pun în trait-uri și în `impl`. Parametrii impliciți (`<Rhs = Self>`) permit evoluția API-urilor. Cu const generics (`<const N: usize>`), dimensiunile fac parte din tip și sunt verificate la compilare.
