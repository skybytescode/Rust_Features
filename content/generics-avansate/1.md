# Generics avansate — Fundamente

Genericele îți permit să scrii un tip sau o funcție o singură dată, pentru mai multe tipuri. Le-ai întâlnit deja în `Vec<T>`, `Option<T>` și `Result<T, E>`. Aici vezi cum îți construiești propriile tipuri generice.

## Tipuri generice pe care le folosești deja

`Option` și `Result` sunt simple enum-uri generice din biblioteca standard:

```rust
// Așa sunt definite, în esență:
// enum Option<T> { Some(T), None }
// enum Result<T, E> { Ok(T), Err(E) }

fn main() {
    let a: Option<i32> = Some(5);
    let b: Option<&str> = Some("text");
    let c: Result<f64, String> = Ok(2.5);
    println!("{a:?} {b:?} {c:?}");
}
```

Același enum funcționează pentru orice tip: `T` e un loc liber, completat la folosire.

## Propriul struct generic

```rust
#[derive(Debug)]
struct Cutie<T> {
    continut: T,
}

impl<T> Cutie<T> {
    fn new(continut: T) -> Self {
        Cutie { continut }
    }

    fn deschide(self) -> T {
        self.continut
    }
}

fn main() {
    let numar = Cutie::new(42);
    let text = Cutie::new("salut");
    println!("{numar:?} {text:?}");
    println!("{}", numar.deschide() + 1);
}
```

`impl<T>` spune: „aceste metode există pentru `Cutie<T>`, oricare ar fi `T`”.

## Mai mulți parametri generici

```rust
#[derive(Debug)]
struct Pereche<A, B> {
    stanga: A,
    dreapta: B,
}

impl<A, B> Pereche<A, B> {
    fn inverseaza(self) -> Pereche<B, A> {
        Pereche { stanga: self.dreapta, dreapta: self.stanga }
    }
}

fn main() {
    let p = Pereche { stanga: "vârstă", dreapta: 30 };
    println!("{:?}", p.inverseaza());
}
```

## Enum-uri generice proprii

```rust
#[derive(Debug)]
enum Raspuns<T> {
    Gasit(T),
    Lipsa,
    Eroare(String),
}

fn cauta(id: u32) -> Raspuns<&'static str> {
    match id {
        1 => Raspuns::Gasit("Ana"),
        0 => Raspuns::Eroare("id invalid".into()),
        _ => Raspuns::Lipsa,
    }
}

fn main() {
    for id in [1, 2, 0] {
        println!("{:?}", cauta(id));
    }
}
```

## Când compilatorul nu poate ghici tipul

De obicei, tipul generic e dedus din valori. Când nu există suficiente indicii, îl scrii explicit, în declarație sau cu *turbofish* `::<>`:

```rust
fn main() {
    let gol: Vec<String> = Vec::new();         // în declarație
    let tot_gol = Vec::<u8>::new();            // turbofish pe tip
    let n = "12".parse::<u64>().unwrap();      // turbofish pe funcție
    let suma = [1, 2, 3].iter().sum::<i32>();
    println!("{} {} {n} {suma}", gol.len(), tot_gol.len());
}
```

## Constrângeri: ce trebuie să știe `T`

Un generic fără constrângeri nu poate face aproape nimic cu `T`. Cu `T: Trait` ceri ca tipul să aibă o anumită capacitate:

```rust
use std::fmt::Display;

fn arata_de_doua_ori<T: Display>(x: T) {
    println!("{x} {x}");
}

fn main() {
    arata_de_doua_ori(7);
    arata_de_doua_ori("ecou");
}
```

> **De reținut:** `struct Nume<T>` și `enum Nume<T>` declară tipuri generice, iar `impl<T>` le adaugă metode. Poți avea mai mulți parametri (`<A, B>`). Când tipul nu poate fi dedus, îl scrii cu `::<>`. Constrângerile `T: Trait` spun ce poate face `T`.
