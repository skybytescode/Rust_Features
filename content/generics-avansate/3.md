# Generics avansate — Avansat

Limitele actuale ale const generics, tehnici de design pentru biblioteci (sealed traits, extension traits) și tipurile asociate cu constrângeri.

## Ce acceptă const generics astăzi

Pe stable, un parametru `const` poate avea doar tipul unui întreg, `bool` sau `char`. Expresiile care depind de parametru **nu** pot apărea în tipuri:

```rust,compile_fail
fn dubleaza<const N: usize>(a: [u8; N]) -> [u8; N * 2] { // eroare: N * 2 nu e permis aici
    let mut r = [0; N * 2];
    r[..N].copy_from_slice(&a);
    r[N..].copy_from_slice(&a);
    r
}

fn main() {}
```

Funcționalitatea se numește `generic_const_exprs` și e încă instabilă. Pe stable ai două variante: îi ceri apelantului dimensiunea rezultatului ca parametru separat, sau calculezi în corpul funcției, unde expresiile sunt permise:

```rust
fn dubleaza<const N: usize, const M: usize>(a: [u8; N]) -> [u8; M] {
    assert!(M == 2 * N, "M trebuie să fie 2 * N"); // verificare la runtime (sau la compilare, cu const)
    let mut r = [0; M];
    r[..N].copy_from_slice(&a);
    r[N..].copy_from_slice(&a);
    r
}

struct Buffer<const N: usize>;

impl<const N: usize> Buffer<N> {
    const OCTETI: usize = N * 8; // în constante asociate, expresiile sunt permise
}

fn main() {
    let d: [u8; 4] = dubleaza([1, 2]);
    println!("{d:?} {}", Buffer::<16>::OCTETI);
}
```

O valoare `const` folosită ca argument trebuie pusă între acolade dacă nu e un literal sau un nume simplu: `Matrice::<{ 2 + 1 }, 3>`.

## Parametri const cu valori implicite

Din Rust 1.59, un parametru `const` poate avea o valoare implicită. Trebuie să apară după parametrii fără valoare implicită:

```rust
#[derive(Debug)]
struct Istoric<T, const MAX: usize = 4> {
    elemente: Vec<T>,
}

impl<T, const MAX: usize> Istoric<T, MAX> {
    fn new() -> Self {
        Istoric { elemente: Vec::with_capacity(MAX) }
    }

    fn adauga(&mut self, x: T) {
        if self.elemente.len() == MAX {
            self.elemente.remove(0);
        }
        self.elemente.push(x);
    }
}

fn main() {
    let mut implicit: Istoric<i32> = Istoric::new(); // MAX = 4
    let mut scurt: Istoric<i32, 2> = Istoric::new();
    for i in 1..=6 {
        implicit.adauga(i);
        scurt.adauga(i);
    }
    println!("{:?} {:?}", implicit.elemente, scurt.elemente);
}
```

## Sealed traits: trait-uri pe care nimeni altcineva nu le poate implementa

Uneori vrei ca un trait public să poată fi **folosit** din afara crate-ului, dar nu și **implementat**. Așa poți adăuga mai târziu metode noi fără breaking change. Tehnica se bazează pe un supertrait privat:

```rust
mod formate {
    mod privat {
        pub trait Sigiliu {} // trait public, dar într-un modul privat: inaccesibil din afară
    }

    pub trait Format: privat::Sigiliu {
        fn extensie(&self) -> &'static str;
    }

    pub struct Json;
    pub struct Csv;

    impl privat::Sigiliu for Json {}
    impl privat::Sigiliu for Csv {}

    impl Format for Json { fn extensie(&self) -> &'static str { "json" } }
    impl Format for Csv { fn extensie(&self) -> &'static str { "csv" } }
}

use formate::Format;

fn main() {
    let lista: [&dyn Format; 2] = [&formate::Json, &formate::Csv];
    for f in lista {
        println!("{}", f.extensie());
    }
    // Din afara modulului `formate`, `impl Format for TipulMeu` nu compilează:
    // trait-ul `Sigiliu` nu poate fi numit, deci nici implementat.
}
```

## Extension traits: metode noi pe tipuri străine

Nu poți adăuga metode inerente pe un tip din alt crate, dar poți defini un trait nou și îl poți implementa pentru acel tip:

```rust
trait TextExt {
    fn numara_vocale(&self) -> usize;
    fn titlu(&self) -> String;
}

impl TextExt for str {
    fn numara_vocale(&self) -> usize {
        self.chars().filter(|c| "aeiouăâîAEIOU".contains(*c)).count()
    }

    fn titlu(&self) -> String {
        self.split_whitespace()
            .map(|c| {
                let mut litere = c.chars();
                match litere.next() {
                    Some(prima) => prima.to_uppercase().chain(litere).collect::<String>(),
                    None => String::new(),
                }
            })
            .collect::<Vec<_>>()
            .join(" ")
    }
}

fn main() {
    println!("{}", "programare în rust".numara_vocale());
    println!("{}", "programare în rust".titlu());
}
```

Convenția de nume este `NumeExt`. Ecosistemul o folosește peste tot: `itertools::Itertools`, `futures::StreamExt` și altele.

## Tipuri asociate cu constrângeri

Un tip asociat poate avea propriile constrângeri, iar cine folosește trait-ul se poate baza pe ele:

```rust
use std::fmt::Display;

trait Sursa {
    type Element: Display + Clone;
    fn urmatorul(&mut self) -> Option<Self::Element>;
}

struct Numere(u32);

impl Sursa for Numere {
    type Element = u32;
    fn urmatorul(&mut self) -> Option<u32> {
        self.0 += 1;
        (self.0 <= 3).then_some(self.0)
    }
}

fn afiseaza_tot<S: Sursa>(mut s: S) {
    while let Some(e) = s.urmatorul() {
        print!("{e} "); // Display e garantat de trait
    }
    println!();
}

fn main() {
    afiseaza_tot(Numere(0));
}
```

Poți constrânge un tip asociat și la locul folosirii: `fn f<I: Iterator<Item = u8>>(...)` sau `where I::Item: Debug`.

> **De reținut:** expresiile pe parametri const (`N * 2`) nu sunt încă permise în tipuri, dar sunt permise în corpuri și în constante asociate. Parametrii const pot avea valori implicite. Sealed traits blochează implementările externe, iar extension traits adaugă metode pe tipuri străine.
