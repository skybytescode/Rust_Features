# Testare — Fundamente

Rust are testarea integrată în limbaj și în Cargo. Nu ai nevoie de biblioteci externe ca să începi: scrii o funcție marcată `#[test]` și rulezi `cargo test`.

## Primul test

```rust
fn aduna(a: i32, b: i32) -> i32 {
    a + b
}

#[test]
fn aduna_doua_numere() {
    assert_eq!(aduna(2, 3), 5);
}

#[test]
fn aduna_numere_negative() {
    assert_eq!(aduna(-4, 1), -3);
}
```

```bash
cargo test
```

```text
running 2 tests
test aduna_doua_numere ... ok
test aduna_numere_negative ... ok

test result: ok. 2 passed; 0 failed
```

În Rust Playground, butonul „Rulează” execută testele automat când programul nu are funcția `main`.

## Macro-urile de verificare

| Macro | Testul pică dacă |
|---|---|
| `assert!(cond)` | `cond` e `false` |
| `assert_eq!(a, b)` | `a != b`; afișează ambele valori |
| `assert_ne!(a, b)` | `a == b` |

Toate acceptă un mesaj suplimentar, cu formatare:

```rust
fn este_par(n: u32) -> bool {
    n % 2 == 0
}

#[test]
fn verifica_pare() {
    for n in [0, 2, 10, 100] {
        assert!(este_par(n), "{n} ar trebui să fie par");
    }
}
```

## Ce se întâmplă când un test pică

Un test pică atunci când dă **panic**. `assert_eq!` îți arată exact ce valori au fost comparate:

```rust,should_panic
fn dublu(x: i32) -> i32 {
    x * 3 // bug!
}

#[test]
fn dublu_functioneaza() {
    assert_eq!(dublu(4), 8);
}
```

```text
---- dublu_functioneaza stdout ----
assertion `left == right` failed
  left: 12
 right: 8
```

Celelalte teste continuă să ruleze: un test picat nu le oprește pe celelalte.

## Modulul de teste

Convenția este să pui testele într-un modul `tests`, la finalul aceluiași fișier, marcat cu `#[cfg(test)]`. Așa, codul de test e compilat **doar** la `cargo test`, nu și în programul final:

```rust
pub fn salut(nume: &str) -> String {
    format!("Salut, {nume}!")
}

#[cfg(test)]
mod tests {
    use super::*; // aduce în scope tot din modulul părinte

    #[test]
    fn salut_contine_numele() {
        let s = salut("Ana");
        assert!(s.contains("Ana"));
    }

    #[test]
    fn salut_exact() {
        assert_eq!(salut("Mihai"), "Salut, Mihai!");
    }
}
```

## Rularea selectivă

```bash
cargo test salut            # doar testele care conțin „salut” în nume
cargo test -- --nocapture   # afișează și println! din teste
```

Implicit, ce afișează un test cu `println!` e ascuns, cu excepția testelor care pică.

> **De reținut:** un test e o funcție `#[test]` care pică la panic. `assert!`, `assert_eq!` și `assert_ne!` sunt instrumentele de bază. Testele stau într-un `mod tests` marcat `#[cfg(test)]` și se rulează cu `cargo test`.
