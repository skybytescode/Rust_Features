# Variables and types — Fundamentals

Every program works with values. In Rust, every value has a **type** that is known at compile time, and you can store it in a **variable**.

## Variables are immutable by default

You declare a variable with `let`. Once assigned, its value cannot change:

```rust,compile_fail
fn main() {
    let x = 5;
    x = 6; // error E0384: cannot assign twice to an immutable variable
    println!("{x}");
}
```

To be able to change it, add `mut`:

```rust
fn main() {
    let mut x = 5;
    println!("x = {x}");
    x = 6;
    println!("x = {x}");
}
```

Immutability by default is a deliberate choice: when you read code, you know that a variable without `mut` has the same value everywhere.

## Shadowing: same name, new variable

You can declare a variable with the same name again. The new one "shadows" the old one and can even have a different type:

```rust
fn main() {
    let spaces = "   ";
    let spaces = spaces.len(); // now it is a number
    println!("{spaces}");
}
```

Shadowing is not the same as `mut`: it creates a new variable instead of modifying the existing one.

## Constants

A constant is declared with `const`, **must** have its type written out, and needs a value known at compile time. By convention, its name is written in uppercase:

```rust
const SECONDS_PER_HOUR: u32 = 60 * 60;

fn main() {
    println!("An hour has {SECONDS_PER_HOUR} seconds");
}
```

## Scalar types

A scalar type represents a single value.

| Category | Types | Example |
|---|---|---|
| Signed integers | `i8`, `i16`, `i32`, `i64`, `i128`, `isize` | `-42` |
| Unsigned integers | `u8`, `u16`, `u32`, `u64`, `u128`, `usize` | `42` |
| Floating-point numbers | `f32`, `f64` | `3.14` |
| Boolean | `bool` | `true`, `false` |
| Character | `char` | `'a'`, `'é'`, `'🦀'` |

The number in the name tells you how many bits the type takes. `isize` and `usize` are the size of a pointer: 64 bits on a 64-bit computer.

```rust
fn main() {
    let age: u8 = 30;
    let temperature: f64 = -3.5;
    let active: bool = true;
    let letter: char = 'ß';
    println!("{age} {temperature} {active} {letter}");
}
```

## Compound types: tuples and arrays

A **tuple** groups values of different types. Its length is fixed:

```rust
fn main() {
    let point: (i32, f64, char) = (10, 2.5, 'x');
    let (a, b, c) = point;        // destructuring
    println!("{a} {b} {c}");
    println!("first: {}", point.0); // access by position
}
```

An **array** holds values of the same type, also with a fixed length:

```rust
fn main() {
    let days = ["Monday", "Tuesday", "Wednesday"];
    let zeros = [0; 5]; // five elements, all 0
    println!("{} {:?}", days[0], zeros);
}
```

If you need a list that grows, use `Vec`, covered in the Collections chapter.

## Type inference

Most of the time you don't have to write the type: the compiler infers it from the value. An integer with no other hint becomes `i32`, and a number with a decimal point becomes `f64`:

```rust
fn main() {
    let a = 5;      // i32
    let b = 2.0;    // f64
    let c: u64 = 7; // type written explicitly
    println!("{a} {b} {c}");
}
```

> **Key takeaway:** variables are immutable unless you add `mut`. Every value has a fixed type, often inferred automatically. The basic types are numbers, `bool`, `char`, tuples and arrays.
