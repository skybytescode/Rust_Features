# Variabile și tipuri — Avansat

Cum deduce compilatorul tipurile, ce înseamnă exact `as` și ce tipuri „speciale” există dincolo de numere și text.

## Deducerea tipurilor merge în ambele direcții

Compilatorul nu deduce tipul doar din valoarea atribuită, ci și din **folosirea ulterioară** a variabilei:

```rust
fn main() {
    let mut v = Vec::new();  // Vec<?>: încă necunoscut
    v.push(1_u16);           // de aici reiese Vec<u16>
    println!("{v:?}");

    let x = 5;               // necunoscut încă...
    let y: u64 = x * 2;      // ...deci `x` devine u64
    println!("{y}");
}
```

Abia când nu există niciun indiciu, un literal întreg cade pe `i32`, iar unul real pe `f64`.

Uneori trebuie să-i spui compilatorului doar o parte din tip. `_` înseamnă „deduce tu restul”:

```rust
fn main() {
    let cuvinte = "a b c".split(' ').collect::<Vec<_>>();
    println!("{cuvinte:?}");
}
```

## Ce face exact `as`

`as` nu dă niciodată panic. Are reguli precise pentru fiecare combinație:

| Conversie | Regulă | Exemplu |
|---|---|---|
| întreg → întreg mai mic | păstrează biții de jos (trunchiere) | `300_i32 as u8 == 44` |
| cu semn → fără semn | reinterpretează biții | `-1_i32 as u32 == 4294967295` |
| real → întreg | **saturează** la limite, NaN devine 0 | `300.7_f32 as u8 == 255` |
| întreg → real | rotunjește la cel mai apropiat | `u64::MAX as f32` |

```rust
fn main() {
    assert_eq!(300_i32 as u8, 44);
    assert_eq!(-1_i32 as u32, u32::MAX);
    assert_eq!(300.7_f32 as u8, 255);
    assert_eq!(-5.0_f64 as u8, 0);
    assert_eq!(f64::NAN as i32, 0);
    println!("toate conversiile se comportă cum scrie în tabel");
}
```

Saturarea la conversia din real în întreg există din Rust 1.45. Înainte, conversiile în afara intervalului erau comportament nedefinit.

## Tipuri fără valori „interesante”

**Unit `()`** este tipul cu o singură valoare, tot `()`. Îl returnează funcțiile care „nu returnează nimic” și instrucțiunile terminate cu `;`.

**Never `!`** este tipul expresiilor care nu se termină niciodată: `panic!`, `loop {}` fără `break`, `return`, `continue`. Fiindcă nu produce nicio valoare, se potrivește cu orice tip:

```rust
fn main() {
    let text = "17";
    let n: u32 = match text.parse() {
        Ok(n) => n,
        Err(_) => panic!("nu e număr"), // `!` se potrivește cu u32
    };
    println!("{n}");
}
```

## `let ... else`

Când o variabilă poate fi obținută doar dacă un pattern se potrivește, `let-else` o declară sau iese din funcție. Ramura `else` trebuie să aibă tipul `!`:

```rust
fn prima_cifra(text: &str) -> Option<u32> {
    let Some(c) = text.chars().next() else {
        return None;
    };
    c.to_digit(10)
}

fn main() {
    println!("{:?} {:?}", prima_cifra("7ab"), prima_cifra(""));
}
```

## `char` nu este un octet

Un `char` ocupă 4 octeți și reprezintă un **Unicode scalar value**. Un `String` e stocat ca UTF-8, unde un caracter ocupă între 1 și 4 octeți:

```rust
fn main() {
    let s = "mâță";
    println!("octeți: {}", s.len());              // 7
    println!("caractere: {}", s.chars().count()); // 4
    println!("mărimea unui char: {}", size_of::<char>()); // 4
}
```

De aceea `s[0]` nu compilează pe un `String`: indexarea după octet ar putea tăia un caracter în două.

## Alias de tip vs. newtype

Un **alias** dă doar alt nume aceluiași tip. Compilatorul nu te protejează dacă le amesteci:

```rust
type Metri = f64;
type Secunde = f64;

fn main() {
    let d: Metri = 100.0;
    let t: Secunde = 9.58;
    let gresit = d + t; // compilează, deși n-are sens
    println!("{gresit}");
}
```

Un **newtype** e un struct cu un singur câmp. E un tip cu adevărat nou, fără cost la runtime:

```rust,compile_fail
struct Metri(f64);
struct Secunde(f64);

fn main() {
    let d = Metri(100.0);
    let t = Secunde(9.58);
    let gresit = d.0 + t; // eroare: nu poți aduna f64 cu Secunde
}
```

## Stare globală mutabilă

`static mut` există, dar e aproape întotdeauna alegerea greșită: orice acces cere `unsafe`, iar în ediția 2024 referințele la un `static mut` sunt refuzate implicit. Folosește tipuri care sincronizează accesul:

```rust
use std::sync::atomic::{AtomicU32, Ordering};
use std::sync::LazyLock;

static CONTOR: AtomicU32 = AtomicU32::new(0);
static CONFIG: LazyLock<String> = LazyLock::new(|| "inițializat la prima folosire".to_string());

fn main() {
    CONTOR.fetch_add(1, Ordering::Relaxed);
    println!("{} — {}", CONTOR.load(Ordering::Relaxed), *CONFIG);
}
```

> **De reținut:** deducerea tipurilor folosește tot contextul. `as` are reguli fixe, care trunchiază sau saturează, dar nu dau panic. `!` și `()` sunt tipuri reale, iar newtype-urile îți dau siguranță de tip gratuit.
