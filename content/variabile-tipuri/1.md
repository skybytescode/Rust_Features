# Variabile și tipuri — Fundamente

Orice program lucrează cu valori. În Rust, fiecare valoare are un **tip**, cunoscut la compilare, și o poți păstra într-o **variabilă**.

## Variabilele sunt imutabile implicit

Declari o variabilă cu `let`. Odată atribuită, valoarea nu se mai poate schimba:

```rust,compile_fail
fn main() {
    let x = 5;
    x = 6; // eroare E0384: nu poți atribui de două ori unei variabile imutabile
    println!("{x}");
}
```

Ca să o poți modifica, adaugă `mut`:

```rust
fn main() {
    let mut x = 5;
    println!("x = {x}");
    x = 6;
    println!("x = {x}");
}
```

Imutabilitatea implicită e o alegere deliberată: când citești cod, știi că o variabilă fără `mut` are aceeași valoare peste tot.

## Shadowing: aceeași denumire, variabilă nouă

Poți declara din nou o variabilă cu același nume. Cea nouă o „acoperă” pe cea veche și poate avea chiar alt tip:

```rust
fn main() {
    let spatii = "   ";
    let spatii = spatii.len(); // acum e un număr
    println!("{spatii}");
}
```

Shadowing-ul nu e același lucru cu `mut`: creează o variabilă nouă, nu o modifică pe cea existentă.

## Constante

O constantă se declară cu `const`, are **obligatoriu** tipul scris explicit și o valoare cunoscută la compilare. Prin convenție, numele se scrie cu majuscule:

```rust
const SECUNDE_PE_ORA: u32 = 60 * 60;

fn main() {
    println!("O oră are {SECUNDE_PE_ORA} secunde");
}
```

## Tipurile scalare

Un tip scalar reprezintă o singură valoare.

| Categorie | Tipuri | Exemplu |
|---|---|---|
| Numere întregi cu semn | `i8`, `i16`, `i32`, `i64`, `i128`, `isize` | `-42` |
| Numere întregi fără semn | `u8`, `u16`, `u32`, `u64`, `u128`, `usize` | `42` |
| Numere reale | `f32`, `f64` | `3.14` |
| Boolean | `bool` | `true`, `false` |
| Caracter | `char` | `'a'`, `'ă'`, `'🦀'` |

Cifra din nume spune câți biți ocupă tipul. `isize` și `usize` au mărimea unui pointer: 64 de biți pe un calculator pe 64 de biți.

```rust
fn main() {
    let varsta: u8 = 30;
    let temperatura: f64 = -3.5;
    let activ: bool = true;
    let litera: char = 'ș';
    println!("{varsta} {temperatura} {activ} {litera}");
}
```

## Tipurile compuse: tupluri și array-uri

Un **tuplu** grupează valori de tipuri diferite. Lungimea lui e fixă:

```rust
fn main() {
    let punct: (i32, f64, char) = (10, 2.5, 'x');
    let (a, b, c) = punct;        // destructurare
    println!("{a} {b} {c}");
    println!("primul: {}", punct.0); // acces după poziție
}
```

Un **array** conține valori de același tip, tot cu lungime fixă:

```rust
fn main() {
    let zile = ["luni", "marți", "miercuri"];
    let zerouri = [0; 5]; // cinci elemente, toate 0
    println!("{} {:?}", zile[0], zerouri);
}
```

Dacă ai nevoie de o listă care crește, folosește `Vec`, pe care îl tratăm în capitolul Colecții.

## Deducerea tipului

De cele mai multe ori nu trebuie să scrii tipul: compilatorul îl deduce din valoare. Un număr întreg fără alt indiciu devine `i32`, iar unul cu zecimale devine `f64`:

```rust
fn main() {
    let a = 5;      // i32
    let b = 2.0;    // f64
    let c: u64 = 7; // tip scris explicit
    println!("{a} {b} {c}");
}
```

> **De reținut:** variabilele sunt imutabile dacă nu adaugi `mut`. Fiecare valoare are un tip fix, deseori dedus automat. Tipurile de bază sunt numerele, `bool`, `char`, tuplurile și array-urile.
