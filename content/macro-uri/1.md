# Macro-uri — Fundamente

Un **macro** este cod care scrie cod. Îl recunoști după `!`: `println!`, `vec!`, `format!`. Macro-urile sunt expandate la compilare, înainte ca programul să ruleze.

## Macro-uri pe care le folosești deja

```rust
fn main() {
    let nume = "Ana";
    println!("Salut, {nume}!");               // afișează cu newline
    print!("fără newline");                   // afișează fără newline
    println!();

    let mesaj = format!("{nume} are {} ani", 30); // creează un String
    eprintln!("eroare: {mesaj}");             // afișează pe stderr

    let v = vec![1, 2, 3];                    // creează un Vec
    let zerouri = vec![0; 5];                 // cinci zerouri
    println!("{v:?} {zerouri:?}");
}
```

## De ce `println!` nu e o funcție

O funcție Rust are un număr fix de parametri, cu tipuri fixe. `println!` acceptă oricâte argumente, de orice tip care se poate afișa, și **verifică la compilare** că textul de formatare se potrivește cu argumentele:

```rust,compile_fail
fn main() {
    let x = 5;
    println!("{} și {}", x); // eroare: 2 locuri, dar un singur argument
}
```

## Macro-uri pentru verificări

```rust
fn main() {
    let a = 2 + 2;
    assert!(a > 3);                      // panic dacă e false
    assert_eq!(a, 4);                    // panic dacă valorile diferă
    assert_ne!(a, 5);                    // panic dacă valorile sunt egale
    debug_assert!(a < 100);              // verificat doar în debug
    println!("toate verificările au trecut");
}
```

`dbg!` afișează expresia, valoarea ei, fișierul și linia, apoi returnează valoarea. E foarte util la depanare:

```rust
fn main() {
    let x = 7;
    let y = dbg!(x * 2) + 1; // pe stderr: [src/main.rs:3:13] x * 2 = 14
    println!("{y}");
}
```

## Marcarea codului neterminat

```rust,should_panic
fn calcul_complicat() -> u32 {
    todo!("implementez mâine") // compilează, dar dă panic dacă e apelat
}

fn main() {
    println!("pornesc");
    let _ = calcul_complicat();
}
```

`todo!()` și `unimplemented!()` îți permit să compilezi un program neterminat, iar `unreachable!()` marchează un cod la care nu ar trebui să ajungi niciodată.

## Primul tău macro

Cu `macro_rules!` îți definești propriile macro-uri. Fiecare regulă are forma `(pattern) => { cod generat }`:

```rust
macro_rules! salut {
    () => {
        println!("Salut, lume!")
    };
    ($nume:expr) => {
        println!("Salut, {}!", $nume)
    };
}

fn main() {
    salut!();
    salut!("Ana");
}
```

`$nume:expr` înseamnă „orice expresie, pe care o numesc `$nume`”. La compilare, `salut!("Ana")` este înlocuit cu `println!("Salut, {}!", "Ana")`.

> **De reținut:** macro-urile se termină cu `!` și generează cod la compilare. Pot primi oricâte argumente și pot verifica lucruri pe care o funcție nu le poate verifica. `dbg!`, `assert!` și `todo!` te ajută zilnic, iar `macro_rules!` îți definește propriile macro-uri.
