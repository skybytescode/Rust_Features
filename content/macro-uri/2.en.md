# Macro-uri — Practician

Cum scrii macro-uri `macro_rules!` utile: fragmente de sintaxă, repetiții, mai multe reguli și igiena numelor.

## Tipuri de fragmente

După `$nume:` scrii ce fel de sintaxă accepți:

| Fragment | Potrivește | Exemplu |
|---|---|---|
| `expr` | o expresie | `2 + x`, `f(1)` |
| `ident` | un identificator | `contor`, `Punct` |
| `ty` | un tip | `Vec<u8>`, `&str` |
| `pat` | un pattern | `Some(x)`, `1..=5` |
| `literal` | un literal | `42`, `"text"` |
| `block` | un bloc `{ ... }` | `{ a + b }` |
| `stmt` | o instrucțiune | `let x = 1` |
| `tt` | un singur *token tree* (orice) | `+`, `(a b c)` |
| `path` | o cale | `std::mem::swap` |

```rust
macro_rules! creeaza_functie {
    ($nume:ident, $tip:ty, $valoare:expr) => {
        fn $nume() -> $tip {
            $valoare
        }
    };
}

creeaza_functie!(raspuns, u32, 42);
creeaza_functie!(salut, &'static str, "salut");

fn main() {
    println!("{} {}", raspuns(), salut());
}
```

## Repetiții: `$(...),*`

`$( ... ),*` înseamnă „zero sau mai multe repetiții, separate prin virgulă”. `+` cere cel puțin una, iar `?` înseamnă zero sau una:

```rust
macro_rules! suma {
    ($($x:expr),+ $(,)?) => {   // `$(,)?` acceptă și o virgulă finală
        0 $(+ $x)+
    };
}

macro_rules! hashmap {
    ($($cheie:expr => $valoare:expr),* $(,)?) => {{
        let mut m = std::collections::HashMap::new();
        $( m.insert($cheie, $valoare); )*
        m
    }};
}

fn main() {
    println!("{}", suma!(1, 2, 3, 4));
    let capitale = hashmap! {
        "România" => "București",
        "Franța" => "Paris",
    };
    println!("{:?}", capitale.get("Franța"));
}
```

Observă acoladele duble `{{ ... }}`: cele exterioare delimitează corpul regulii, iar cele interioare creează un bloc, ca macro-ul să poată fi folosit ca expresie.

## Mai multe reguli

Regulile sunt încercate **în ordine**, iar prima care se potrivește câștigă:

```rust
macro_rules! log {
    (eroare: $($arg:tt)*) => {
        eprintln!("[EROARE] {}", format!($($arg)*))
    };
    (info: $($arg:tt)*) => {
        println!("[INFO] {}", format!($($arg)*))
    };
    ($($arg:tt)*) => {
        println!("[LOG] {}", format!($($arg)*))
    };
}

fn main() {
    let utilizator = "ana";
    log!(info: "{utilizator} s-a conectat");
    log!(eroare: "parolă greșită de {} ori", 3);
    log!("mesaj simplu");
}
```

`$($arg:tt)*` captează „tot restul”, ca să poată fi pasat mai departe lui `format!`.

## Igiena: variabilele macro-ului nu se amestecă cu ale tale

Variabilele definite **în interiorul** unui macro nu intră în conflict cu cele din codul apelantului:

```rust
macro_rules! dublu {
    ($e:expr) => {{
        let x = $e; // acest `x` aparține macro-ului
        x * 2
    }};
}

fn main() {
    let x = 10;
    println!("{}", dublu!(x + 1)); // 22: `x` din exterior rămâne neatins
    println!("{x}");
}
```

## Evaluare multiplă: o capcană

Dacă folosești `$e` de mai multe ori, expresia e **evaluată de mai multe ori**:

```rust
macro_rules! patrat_gresit {
    ($e:expr) => {
        $e * $e
    };
}

macro_rules! patrat_corect {
    ($e:expr) => {{
        let v = $e;
        v * v
    }};
}

fn main() {
    let mut n = 0;
    let mut urmatorul = || { n += 1; n };
    println!("{}", patrat_gresit!(urmatorul())); // 1 * 2 = 2, nu 1
    println!("{}", patrat_corect!(urmatorul())); // 3 * 3 = 9
}
```

## Exportul unui macro

Un macro definit într-o bibliotecă devine vizibil în alte crate-uri cu `#[macro_export]`. Utilizatorii îl importă apoi ca pe orice element: `use biblioteca::numele_macro;`.

> **De reținut:** fragmentele (`expr`, `ident`, `ty`, `tt`…) descriu ce acceptă macro-ul, `$(...),*` exprimă repetiții, iar regulile se încearcă în ordine. Variabilele din macro sunt igienice. Leagă `$e` de o variabilă ca să nu-l evaluezi de mai multe ori.
