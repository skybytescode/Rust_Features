# Macros — Fundamentals

A **macro** is code that writes code. You recognize it by the `!`: `println!`, `vec!`, `format!`. Macros are expanded at compile time, before the program runs.

## Macros you already use

```rust
fn main() {
    let name = "Ana";
    println!("Hello, {name}!");               // prints with a newline
    print!("no newline");                     // prints without a newline
    println!();

    let message = format!("{name} is {} years old", 30); // creates a String
    eprintln!("error: {message}");            // prints to stderr

    let v = vec![1, 2, 3];                    // creates a Vec
    let zeros = vec![0; 5];                   // five zeros
    println!("{v:?} {zeros:?}");
}
```

## Why `println!` isn't a function

A Rust function has a fixed number of parameters, with fixed types. `println!` accepts any number of arguments, of any type that can be printed, and **checks at compile time** that the format string matches the arguments:

```rust,compile_fail
fn main() {
    let x = 5;
    println!("{} and {}", x); // error: 2 placeholders, but only one argument
}
```

## Macros for checks

```rust
fn main() {
    let a = 2 + 2;
    assert!(a > 3);                      // panics if false
    assert_eq!(a, 4);                    // panics if the values differ
    assert_ne!(a, 5);                    // panics if the values are equal
    debug_assert!(a < 100);              // checked only in debug
    println!("all checks passed");
}
```

`dbg!` prints the expression, its value, the file and the line, then returns the value. It's very useful when debugging:

```rust
fn main() {
    let x = 7;
    let y = dbg!(x * 2) + 1; // on stderr: [src/main.rs:3:13] x * 2 = 14
    println!("{y}");
}
```

## Marking unfinished code

```rust,should_panic
fn complicated_calculation() -> u32 {
    todo!("I'll implement it tomorrow") // compiles, but panics if called
}

fn main() {
    println!("starting");
    let _ = complicated_calculation();
}
```

`todo!()` and `unimplemented!()` let you compile an unfinished program, and `unreachable!()` marks code you should never reach.

## Your first macro

With `macro_rules!` you define your own macros. Each rule has the form `(pattern) => { generated code }`:

```rust
macro_rules! greet {
    () => {
        println!("Hello, world!")
    };
    ($name:expr) => {
        println!("Hello, {}!", $name)
    };
}

fn main() {
    greet!();
    greet!("Ana");
}
```

`$name:expr` means "any expression, which I'll call `$name`". At compile time, `greet!("Ana")` is replaced with `println!("Hello, {}!", "Ana")`.

> **Key takeaway:** macros end in `!` and generate code at compile time. They can take any number of arguments and check things a function can't. `dbg!`, `assert!` and `todo!` help you every day, and `macro_rules!` defines your own macros.
