# Macro-uri — Avansat

Tehnici pentru macro-uri declarative complexe și o introducere în macro-urile procedurale: `derive`, atribut și function-like.

## Recursivitate și „tt munchers”

Un macro se poate apela pe sine. Un **tt muncher** consumă intrarea bucată cu bucată, câte un token tree odată, și se reapelează cu restul:

```rust
macro_rules! numara {
    () => { 0usize };
    ($primul:tt $($rest:tt)*) => { 1usize + numara!($($rest)*) };
}

macro_rules! max {
    ($x:expr) => { $x };
    ($x:expr, $($rest:expr),+) => {{
        let a = $x;
        let b = max!($($rest),+);
        if a > b { a } else { b }
    }};
}

fn main() {
    println!("{}", numara!(a b c d e)); // 5
    println!("{}", max!(3, 9, 2, 7));   // 9
}
```

Fiecare nivel de recursivitate e o expansiune nouă. Limita implicită este 128, iar `#![recursion_limit = "256"]` o crește.

## Acumulatori interni

O convenție frecventă e o regulă „internă”, marcată cu `@`, care acumulează rezultatul înainte de a-l emite:

```rust
macro_rules! inverseaza {
    // punctul de intrare
    ($($x:expr),*) => { inverseaza!(@acc [] $($x),*) };
    // gata: emitem acumulatorul
    (@acc [$($acc:expr),*]) => { [$($acc),*] };
    // mutăm primul element în fața acumulatorului
    (@acc [$($acc:expr),*] $primul:expr $(, $rest:expr)*) => {
        inverseaza!(@acc [$primul $(, $acc)*] $($rest),*)
    };
}

fn main() {
    println!("{:?}", inverseaza!(1, 2, 3, 4));
}
```

## `$crate`: căi corecte din orice crate

Într-un macro exportat, folosește `$crate::` pentru elementele din propria bibliotecă. Calea rămâne corectă indiferent cum e redenumit crate-ul la utilizator:

```rust
pub mod util {
    pub fn formateaza(s: &str) -> String {
        format!("<<{s}>>")
    }
}

#[macro_export]
macro_rules! evidentiaza {
    ($s:expr) => {
        $crate::util::formateaza($s)
    };
}

fn main() {
    println!("{}", evidentiaza!("important"));
}
```

## Generarea de cod repetitiv

Un caz de folosire foarte frecvent este implementarea aceluiași trait pentru mai multe tipuri:

```rust
trait Descriere {
    fn descriere() -> &'static str;
}

macro_rules! impl_descriere {
    ($($tip:ty => $text:literal),* $(,)?) => {
        $(
            impl Descriere for $tip {
                fn descriere() -> &'static str { $text }
            }
        )*
    };
}

impl_descriere! {
    u8 => "întreg pe 8 biți",
    f64 => "real în dublă precizie",
    bool => "valoare logică",
}

fn main() {
    println!("{} / {}", u8::descriere(), bool::descriere());
}
```

Biblioteca standard folosește aceeași tehnică pentru a implementa trait-uri pe toate tipurile numerice.

## Macro-uri procedurale

Un **macro procedural** este o funcție Rust care primește cod sub formă de `TokenStream` și returnează alt cod. Există trei tipuri:

| Tip | Folosire | Exemplu cunoscut |
|---|---|---|
| derive | `#[derive(MeuTrait)]` pe struct / enum | `serde::Serialize` |
| atribut | `#[atributul_meu]` pe orice element | `#[tokio::main]` |
| function-like | `macro_meu!(...)` | `sqlx::query!` |

Trăiesc obligatoriu într-un crate separat, de tip `proc-macro`:

```toml
# my_macros/Cargo.toml
[lib]
proc-macro = true

[dependencies]
syn = "2"
quote = "1"
```

Un derive care generează o metodă `nume_tip()`:

```rust,ignore
// my_macros/src/lib.rs
use proc_macro::TokenStream;
use quote::quote;
use syn::{parse_macro_input, DeriveInput};

#[proc_macro_derive(NumeTip)]
pub fn derive_nume_tip(input: TokenStream) -> TokenStream {
    let ast = parse_macro_input!(input as DeriveInput); // parsează struct-ul
    let nume = &ast.ident;
    let text = nume.to_string();
    quote! {
        impl #nume {
            pub fn nume_tip() -> &'static str { #text }
        }
    }
    .into()
}
```

```rust,ignore
// în crate-ul care îl folosește
use my_macros::NumeTip;

#[derive(NumeTip)]
struct Comanda;

fn main() {
    println!("{}", Comanda::nume_tip()); // "Comanda"
}
```

**`syn`** parsează token-urile într-un arbore sintactic, iar **`quote!`** construiește cod nou, cu `#variabila` pentru interpolare.

## Când să nu folosești macro-uri

Macro-urile îngreunează citirea codului, mesajele de eroare și autocompletarea din editor. Folosește-le doar când o funcție, un generic sau un trait nu poate face același lucru: număr variabil de argumente, generare de elemente (`impl`, `fn`, `struct`), sintaxă specifică unui domeniu.

> **De reținut:** macro-urile recursive și tt munchers procesează intrarea pas cu pas. Regulile `@intern` acumulează rezultate, iar `$crate::` dă căi robuste. Macro-urile procedurale (derive, atribut, function-like) stau într-un crate `proc-macro` și folosesc de obicei `syn` și `quote`.
